# 📤 导出功能详细说明

## ✨ 新功能特性

### 核心改进
导出功能已完全重构，实现了智能数据处理：

1. ✅ **自动读取JSON** - 读取 `data/raw/` 目录下所有JSON文件
2. ✅ **按新闻时间筛选** - 根据新闻的时间字段（而非文件修改时间）精确筛选
3. ✅ **智能去重** - 基于"时间+标题"去重，避免重复数据
4. ✅ **自动合并** - 将多个JSON文件的数据合并为单一文件
5. ✅ **多格式生成** - 同时生成JSON、Markdown、TXT三种格式

---

## 🔧 工作流程

### 步骤1: 时间筛选
```
用户选择: 2025-12-20 09:00 至 2025-12-21 18:00
    ↓
读取所有JSON文件
    ↓
解析每条新闻的时间字段
    ↓
筛选出时间范围内的新闻
```

### 步骤2: 数据去重
```
新闻A: "12-20 10:00 | 美联储加息"
新闻B: "12-20 10:00 | 美联储加息"  ← 重复，丢弃
新闻C: "12-20 11:00 | 美联储加息"  ← 不同时间，保留
    ↓
生成唯一标识: "时间_标题"
    ↓
使用OrderedDict去重
```

### 步骤3: 排序与合并
```
按新闻时间降序排序（最新的在前）
    ↓
合并为单一列表
```

### 步骤4: 生成文件
```
生成3种格式:
1. JSON - 完整数据（时间、标题、内容、来源）
2. Markdown - 格式化摘要（便于阅读）
3. TXT - 极简标题（节省Token）
```

## 📄 文件格式详解

### 1. JSON 格式
```json
[
  {
    "time": "12-20 10:30",
    "title": "美联储宣布加息25个基点",
    "content": "美国联邦储备委员会今日宣布...",
    "source": "路透社"
  },
  ...

```

**特点**: 完整数据，便于程序处理

---

### 2. Markdown 格式
```markdown
# 新闻摘要

**导出时间**: 2025-12-21 15:30:00

**新闻总数**: 156 条

**时间**: 12-20 10:30
**来源**: 路透社

**内容**:
美国联邦储备委员会今日宣布...

---

## 2. ...
```

**特点**: 格式化排版，便于人类阅读

---

### 3. TXT 格式
```
12-20 10:30 | 美联储宣布加息25个基点

12-20 13:45 | 日本央行调整货币政策
...
```

**特点**: 极简格式，节省AI Token

## 🔍 去重逻辑

### 唯一标识生成
```python
unique_key = f"{新闻时间}_{新闻标题}"
```

### 示例
```
新闻A: "12-20 10:00_美联储加息"  ← 保留
新闻B: "12-20 10:00_美联储加息"  ← 重复，丢弃
新闻C: "12-20 10:01_美联储加息"  ← 时间不同，保留
新闻D: "12-20 10:00_欧洲央行"    ← 标题不同，保留
```

**原则**: 同一时间的同一标题只保留一次

## 🚨 注意事项

