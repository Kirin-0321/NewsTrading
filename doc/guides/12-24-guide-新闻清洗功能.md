# 🧹 新闻清洗功能使用指南

## 功能概述

新闻清洗功能是一个AI驱动的智能新闻筛选系统，用于从大量新闻中筛选出有投资价值的内容，解决token数量限制导致无法一次性分析过多新闻的问题。

### 主要特点

✅ **智能筛选** - 使用AI根据预设标准自动判断新闻价值
✅ **批量处理** - 自动分批处理，每批500条（可调整）
✅ **自动去重** - 处理前自动合并去重，避免重复新闻
✅ **双文件保存** - 保留和去除的新闻分别保存，便于审查
✅ **无缝集成** - 清洗后的数据可直接用于AI分析
✅ **多源支持** - 支持原始数据和导出数据

## 使用流程

### 1️⃣ 准备工作

**配置AI服务商（首次使用）**
- 前往【🤖 AI分析】页面
- 配置AI服务商（DeepSeek/OpenAI等）
- 输入并保存API Key
- 清洗功能会自动使用该配置

### 2️⃣ 选择数据源

**打开清洗页面**
1. 点击左侧导航栏【🧹 新闻清洗】
2. 选择数据类型：
   - **原始数据** - `data/raw/` 目录下的JSON文件
   - **导出数据** - `data/exports/` 目录下的导出文件

**选择文件**
- 点击【📁 选择文件...】
- 可多选文件（Ctrl+点击）
- 系统会自动合并去重
- 已选文件显示在列表中

### 3️⃣ 配置清洗参数

**每批数量**
- 默认：500条/批
- 建议范围：100-1000条
- 数量越大，速度越快，但单批token消耗越多

**清洗标准**
- 默认使用"投资价值优先"模板
- 显示前300字符预览
- 可在 `config/cleaning_criteria.json` 中修改

**自动合并去重**
- 默认启用
- 多文件会自动合并并去除重复新闻
- 基于标题+时间判断重复

### 4️⃣ 开始清洗

点击【🚀 开始清洗】按钮

**进度显示**
```
[21:08:36] 文件数量: 1
[21:08:36] AI服务商: deepseek
[21:08:37] 已加载 2420 条新闻
[21:08:37] 去重完成：2420 → 2269 条（去除 151 条重复）
[21:09:53] 批次 1/5: 已处理 500/2269，本批保留 291 条，去除 209 条
...
```

**处理时间**
- DeepSeek：约 1-2 分钟/500条
- OpenAI GPT-4：约 2-3 分钟/500条
- 2000条新闻预计 5-10 分钟

### 5️⃣ 查看结果

**统计信息**
```
清洗完成！

📊 统计信息
────────────────────────
原始数量: 2269 条
已保留:   1039 条 (45.8%)
已去除:   1230 条 (54.2%)

💾 保存文件
────────────────────────
已保留: 12-19-13_12-23-20_clear.json
已去除: 12-19-13_12-23-20_removed.json

文件位置: data/cleaned/
```

**操作按钮**
- 📄 **查看保留新闻** - 打开 `_clear.json` 文件
- 📄 **查看去除新闻** - 打开 `_removed.json` 文件
- 🤖 **用于AI分析** - 直接跳转到AI分析页面

## 文件命名规则

### 单次清洗
- **保留文件**: `起始月-日-时_结束月-日-时_clear.json`
- **去除文件**: `起始月-日-时_结束月-日-时_removed.json`
- 示例: `12-19-13_12-23-20_clear.json`

### 合并后
- **合并文件**: `起始月-日_结束月-日_clear.json`
- 示例: `12-19_12-23_clear.json`
- 注意：仅合并 `_clear.json` 文件

## 数据管理

### 查看清洗数据

**在数据管理页面**
1. 打开【📁 数据管理】
2. 文件类型选择【清洗后数据】
3. 显示所有 `_clear.json` 和 `_removed.json` 文件
4. 可查看、删除文件（原始数据仍保留）

### 合并清洗数据

**合并多个清洗结果**
1. 确保有多个 `_clear.json` 文件
2. 点击【🔀 合并去重（清洗数据）】
3. 自动合并并去重
4. 生成 `起始月-日_结束月-日_clear.json`

**特点**
- ✅ 仅合并 `_clear.json` 文件
- ✅ 自动去除重复新闻
- ✅ 保持时间顺序
- ❌ 不合并 `_removed.json` 文件

---

## 导出与分析

### 导出清洗数据

**在数据导出页面**
1. 打开【📤 数据导出】
2. 选择导出格式（JSON/Markdown/TXT）
3. 文件来源选择【清洗后数据】
4. 支持导出合并后的 `_clear.json`

### 用于AI分析

**直接分析**
1. 清洗完成后点击【🤖 用于AI分析】
2. 自动跳转到AI分析页面
3. 自动填充清洗后的文件路径

**手动选择**
1. 打开【🤖 AI分析】页面
2. 数据来源选择文件
3. 浏览到 `data/cleaned/` 目录
4. 选择 `_clear.json` 文件

## 清洗标准说明

### 默认标准："投资价值优先"

**保留标准**
1. ✅ 政策性新闻（财政、货币、产业政策）
2. ✅ 行业突破性进展（技术、产品、市场）
3. ✅ 重大投融资事件（IPO、并购、融资）
4. ✅ 上市公司重要公告（业绩、合作、变动）
5. ✅ 宏观经济关键数据
6. ✅ 国际重大事件影响A股

**去除标准**
1. ❌ 纯事实陈述无分析价值
2. ❌ 历史回顾、人物采访
3. ❌ 过于宏观无具体标的
4. ❌ 重复、琐碎的行业动态
5. ❌ 与投资决策无关的社会新闻

### 自定义标准

**修改配置文件**
```json
// config/cleaning_criteria.json
{
  "default": {
    "name": "投资价值优先",
    "criteria": "你的自定义标准..."
  }
}
```

**修改后**
- 重启程序生效
- 或在清洗页面切换页面后重新进入

## 常见问题

### Q1: 清洗失败怎么办？

**检查清单**
1. ✅ AI服务商配置正确？
2. ✅ API Key有效？
3. ✅ 账户余额充足？
4. ✅ 网络连接正常？

**错误处理**
- 批次失败时，该批新闻会全部保留
- 可查看控制台获取详细错误信息

### Q2: 清洗需要多长时间？

**参考时间**（以DeepSeek为例）
- 500条：约1-2分钟
- 1000条：约2-4分钟
- 2000条：约5-10分钟
- 5000条：约15-25分钟

**影响因素**
- AI服务商响应速度
- 网络质量
- 新闻内容长度

### Q3: 清洗会消耗多少token？

**预估（DeepSeek）**
- 每条新闻：约200-500 tokens（含标题、时间、内容预览）
- 系统prompt：约1000 tokens
- 每批500条：约10万-15万 tokens
- 成本：约0.01-0.02元/批（DeepSeek）

**省钱建议**
- ✅ 使用DeepSeek（最便宜）
- ✅ 先导出缩小范围再清洗
- ✅ 调整每批数量为500-800条

### Q4: 保留率多少算正常？

**典型保留率**
- 高质量数据源：40-60%
- 一般数据源：30-50%
- 低质量数据源：20-40%

**异常情况**
- 保留率 > 80%：标准可能过宽松
- 保留率 < 20%：标准可能过严格

### Q5: 清洗后还能恢复吗？

**答案：可以！**
- ✅ 原始文件完全保留
- ✅ 去除的新闻保存在 `_removed.json`
- ✅ 可随时查看和重新处理

### Q6: 可以清洗AI分析报告吗？

**答案：不可以**
- 清洗功能仅支持JSON格式的新闻数据
- Markdown/TXT格式不支持清洗

## 最佳实践

### 📌 建议工作流程

**方案一：直接清洗原始数据**
```
爬取新闻 → 清洗 → AI分析
```
- 适合：数据量 < 5000条
- 优点：流程简单
- 缺点：清洗时间较长

**方案二：先导出再清洗**
```
爬取新闻 → 数据导出（按时间/标题过滤）→ 清洗 → AI分析
```
- 适合：数据量 > 5000条
- 优点：清洗更精准，速度更快
- 缺点：多一步操作

**方案三：定期清洗归档**
```
爬取新闻 → 清洗 → 合并清洗数据 → 导出/分析
```
- 适合：长期积累大量数据
- 优点：数据管理清晰
- 缺点：需要定期维护

### 📌 清洗标准优化

**迭代优化步骤**
1. 使用默认标准清洗
2. 查看 `_removed.json`，找出误删的重要新闻
3. 调整 `cleaning_criteria.json`
4. 重新清洗测试
5. 重复2-4直到满意

### 📌 性能优化

**提升清洗速度**
- ✅ 使用DeepSeek（响应最快）
- ✅ 提高每批数量至800-1000条
- ✅ 避免高峰期使用

**降低成本**
- ✅ 使用DeepSeek（最便宜，1元≈60万tokens）
- ✅ 先用数据导出功能缩小范围
- ✅ 定期清理不需要的原始数据

## 技术细节

### 数据结构

**输入格式**
```json
{
  "news": [
    {
      "title": "新闻标题",
      "time": "2025-12-23 20:00:00",
      "content": "新闻内容...",
      "source": "来源",
      "url": "链接"
    }
  ]
}
```

**输出格式（_clear.json）**
```json
{
  "metadata": {
    "type": "cleaned_single",
    "source_files": ["原始文件名"],
    "source_count": 2269,
    "kept_count": 1039,
    "removed_count": 1230,
    "cleaning_time": "2025-12-23 21:14:13",
    "time_range": {
      "start": "2025-12-19 13:00:00",
      "end": "2025-12-23 20:00:00"
    }
  },
  "news": [...]
}
```

### AI Prompt结构

**System Prompt**
```
你是一个专业的金融新闻筛选助手...
【清洗标准】
{cleaning_criteria}
```

**User Prompt**
```
请判断以下新闻是否应该保留：

1. 【标题】...
   【时间】...
   【来源】...
   【内容】...

2. ...

请对每条新闻输出判断（仅输出序号和结果）：
1. keep
2. remove
...
```

### 批处理逻辑

1. **加载** - 读取所有选中文件
2. **去重** - 基于标题+时间去重
3. **分批** - 按batch_size分成多批
4. **调用AI** - 逐批发送给AI判断
5. **分类** - 根据AI结果分为kept/removed
6. **排序** - 按时间排序
7. **保存** - 生成两个JSON文件
