===============================================
  新闻爬虫管理系统 - PyQt5 桌面版
  快速使用指南
===============================================

📦 第一步：安装依赖
---------------
双击运行: install_pyqt.bat

或手动执行:
pip install -r requirements_pyqt.txt


🚀 第二步：启动程序
---------------
双击运行: start.bat

或手动执行:
python main.py


🎯 第三步：使用功能
---------------

1️⃣ 爬虫管理（首页）
   - 设置滚动次数（默认36）和等待时间（默认6秒）
   - 勾选"无头模式"（不显示浏览器窗口）
   - 点击"开始爬取"
   - 观察实时进度条和日志
   - 完成后查看生成的文件

2️⃣ 数据管理
   - 查看已爬取的所有文件
   - 可以查看文件内容
   - 可以删除不需要的文件
   - 切换文件类型（JSON/Markdown/TXT/分析报告）

3️⃣ 新闻分析
   - 选择要分析的JSON文件
   - 设置最小影响分数（默认8分）
   - 点击"开始分析"
   - 查看分析结果和报告

4️⃣ 数据导出
   - 选择日期范围
   - 勾选要导出的格式
   - 点击"导出数据"
   - 选择保存位置

5️⃣ 定时任务
   - 创建定时爬取任务
   - 设置执行时间
   - 启用/禁用任务
   注意：程序需要保持运行


💡 使用建议
---------------
- 首次使用建议设置较小的滚动次数（如5次）测试
- 爬取时建议使用"无头模式"以提高效率
- 定期导出重要数据进行备份
- 查看日志了解程序运行状态


⚙️ 配置文件
---------------
Chrome和ChromeDriver路径配置在:
core/config.py

默认路径为:
- Chrome: chrome-win64/chrome.exe
- ChromeDriver: chrome-win64/chromedriver.exe


📁 数据存储
---------------
所有数据保存在 data 目录:
- data/raw/          JSON原始数据
- data/summaries/    Markdown和TXT摘要
- data/analysis/     分析报告
- data/exports/      导出文件


🔧 故障排查
---------------
❌ 程序无法启动
   → 检查Python版本（需要3.7+）
   → 重新安装依赖

❌ ChromeDriver错误
   → 确保Chrome浏览器已安装
   → 检查ChromeDriver是否存在

❌ 爬虫运行失败
   → 检查网络连接
   → 查看日志中的详细错误
   → 尝试取消"无头模式"查看问题
