# 定时任务快速指南

## 🎯 快速开始

### 1. 启动程序
双击 `启动.bat` 或运行：
```bash
python main.py
```

### 2. 查看定时任务
- 在GUI左侧点击 **"⏰ 定时任务"**
- 查看当前配置的所有定时任务

### 3. 任务自动运行
✅ 程序启动后，定时任务会**自动**在后台运行  
✅ 到达指定时间后会**自动**启动爬虫  
✅ 不需要任何手动操作

## ⚙️ 管理任务

### 添加新任务
1. 点击"定时任务"页面
2. 点击"新增任务"按钮
3. 设置任务名称、执行时间和参数
4. 点击"保存"

### 修改任务
1. 在任务列表中选择要修改的任务
2. 点击"编辑"按钮
3. 修改相关参数
4. 点击"保存"

### 启用/禁用任务
1. 在任务列表中找到目标任务
2. 切换"启用"开关
3. 更改会立即生效

### 删除任务
1. 选择要删除的任务
2. 点击"删除"按钮
3. 确认删除操作

## 📝 任务参数说明

### 滚动次数 (scroll_times)
- **说明**: 页面向下滚动的次数
- **推荐值**: 36次
- **范围**: 1-100次
- **作用**: 滚动次数越多，加载的新闻越多

### 等待时间 (wait_seconds)
- **说明**: 每次滚动后等待页面加载的时间
- **推荐值**: 6秒
- **范围**: 1-60秒
- **作用**: 等待时间越长，加载越稳定，但爬取时间越长

### 无数据停止次数 (max_no_change)
- **说明**: 连续N次没有新数据时自动停止
- **推荐值**: 3次
- **范围**: 1-20次
- **作用**: 避免无意义的重复滚动

## ⚠️ 重要提示

### ✅ 必须保持程序运行
定时任务**只有在GUI程序运行时**才会执行，关闭程序会停止所有定时任务。

### ✅ 建议最小化而不是关闭
如果需要长时间运行定时任务，建议：
- 最小化窗口到任务栏
- 不要关闭程序

### ✅ 检查系统时间
确保系统时间正确，定时任务基于系统时间触发。

### ✅ 网络连接
定时任务执行时需要网络连接，确保网络稳定。

## 🔧 故障排除

### 问题1: 任务没有执行
**原因**: 
- 程序没有运行
- 任务被禁用
- 系统时间不正确

**解决方案**:
1. 确认GUI程序正在运行
2. 检查任务是否已启用
3. 核对系统时间

### 问题2: 爬虫启动失败
**原因**: 
- Chrome浏览器未安装
- chromedriver版本不匹配
- 网络连接问题

**解决方案**:
1. 检查Chrome浏览器是否正常
2. 查看日志文件中的详细错误
3. 尝试手动运行爬虫测试

### 问题3: 找不到定时任务页面
**原因**: GUI版本过旧

**解决方案**:
1. 确认使用的是最新版本
2. 检查左侧导航栏是否有"⏰ 定时任务"

## 📊 工作流程图

```
程序启动
    ↓
加载任务配置 (data/schedule_tasks.json)
    ↓
启动调度服务 (后台线程)
    ↓
每秒检查是否有任务需要执行
    ↓
到达任务时间
    ↓
触发任务回调函数
    ↓
在主线程中启动爬虫
    ↓
爬虫执行爬取任务
    ↓
保存结果到 data/raw/
    ↓
更新任务的 last_run 字段
    ↓
继续等待下一个任务
```
