# 提示词模板 - 新闻重要性分级功能说明

## 📌 功能概述

为了让AI更精准地识别投资机会，我们在所有提示词模板中加入了**新闻重要性分级机制**。AI现在会：

1. ✅ **先对新闻进行分级**（重点/一般）
2. ✅ **优先基于重点新闻**进行投资分析
3. ✅ **明确标注**每条新闻的重要性级别
4. ✅ **给出分级理由**和权重说明

---

## 🎯 各模板的新闻分级标准

### 1️⃣ 标准分析模板

#### 🔴 重点新闻（优先关注）
- **国家级政策**：中央、国务院、部委发布的重大政策文件
- **行业突破性技术**：颠覆性技术创新、填补国内空白、打破国外垄断
- **重大产业政策**：产业规划、扶持政策、准入门槛变化
- **关键数据发布**：GDP、CPI、PMI等宏观经济数据
- **重大事件**：国际局势重大变化、行业格局重塑事件

#### 🟡 一般行业新闻（辅助参考）
- 企业常规经营动态
- 一般性产品发布
- 行业会议活动
- 市场数据更新

---

### 2️⃣ 激进策略模板

#### 🔴 重点新闻（主攻方向）
- **政策催化**：国家级产业政策、扶持计划、准入放开
- **技术突破**：颠覆性创新、国产替代突破、行业首创
- **重大事件**：国际局势变化、行业格局重塑、市场爆发信号
- **资金动向**：大额投资、并购重组、IPO/融资动态

#### 🟡 一般新闻
- 常规经营动态、行业会议、市场数据

---

### 3️⃣ 稳健策略模板

#### 🔵 高确定性新闻（优先关注）
- **国家战略政策**：长期产业规划、国家战略方向
- **稳定性技术突破**：成熟技术升级、产能扩张、质量提升
- **基本面改善**：业绩超预期、行业景气度提升、市场份额扩大
- **长期趋势**：人口结构变化、消费升级、产业升级

#### ⚪ 不确定性新闻
- 短期题材炒作、未经验证的技术、预期不明的政策

---

### 4️⃣ 价值投资模板

#### 💎 高价值新闻（优先关注）
- **基本面改善**：业绩拐点、盈利能力提升、成本下降
- **政策支持**：行业扶持、税收优惠、补贴政策
- **资产重估**：并购重组、资产注入、分拆上市
- **行业复苏**：景气度回升、需求恢复、产能利用率提升
- **估值修复**：市场认知改善、机构增持、估值体系变化

#### 💤 一般新闻
- 短期炒作、题材概念、未验证消息

---

### 5️⃣ 短线交易模板

#### 🔥 高热度新闻（主攻方向）
- **政策突发**：突然出台的重磅政策、政策转向信号
- **技术爆点**：重大技术突破、首创性产品发布
- **事件驱动**：国际局势突变、行业重大事件、突发利好
- **市场情绪**：资金集中关注、媒体热议话题

#### 🌡️ 一般新闻
- 常规动态、预期内消息

## 📝 分析流程变化

### 优化前（旧版）
```
输入新闻 → AI直接分析 → 输出投资建议
```
所有新闻等权重，可能导致一般新闻干扰判断。

### 优化后（新版）
```
输入新闻 
  ↓
第一步：新闻分级（AI先识别重点新闻）
  ↓
第二步：基于重点新闻进行板块分析
  ↓
第三步：输出投资策略（标注新闻重要性）
```
重点新闻优先，分析更精准。

## 💻 使用方法

### 方法1：界面操作（推荐新手）

1. **打开AI分析页面**
2. **选择提示词模板**（标准分析/激进策略/稳健策略等）
3. **点击【编辑模板】按钮**
4. **查看或调整分级标准**（在system_prompt中）
5. **保存**后立即生效

### 方法2：编辑配置文件（推荐高级用户）

**配置文件位置**：`config/ai_config.json`

```json
{
  "prompt_templates": {
    "standard": {
      "name": "标准分析",
      "system_prompt": "你是一位资深的A股投资分析师...\n\n【新闻重要性分级标准】：\n🔴 **重点新闻**...",
      "user_prompt_template": "请基于以下新闻数据...\n\n**第一步：新闻分级**..."
    }
  }
}
```

**修改步骤**：
1. 打开 `config/ai_config.json`
2. 找到对应模板的 `system_prompt` 部分
3. 根据你的需求调整分级标准
4. 保存文件
5. 重启应用或重新选择模板

## 📊 实际效果示例

### 优化前的分析报告
```markdown
## 投资机会分析

### 板块1：AI大模型
基于新闻1, 3, 5, 12, 15, 18...

催化剂事件：某公司发布新产品（新闻1）、行业会议召开（新闻3）、
国务院发布AI产业政策（新闻5）...
```
❌ 问题：一般新闻和重点新闻混在一起，难以判断真正的催化剂。

### 优化后的分析报告
```markdown
## 第一步：新闻分级

### 🔴 重点新闻（6条）
- 新闻5：国务院发布AI产业扶持政策 ⭐ 国家级政策
- 新闻12：某公司AI芯片打破国外垄断 ⭐ 突破性技术
- 新闻28：国家发改委批准千亿AI算力建设 ⭐ 重大产业政策
...

### 🟡 一般新闻（34条）
- 新闻1, 3, 4, 6, 7... 常规产品发布和企业动态

---

## 第二步：板块机会分析

### 板块1：AI大模型与算力基础设施 ⭐⭐⭐⭐⭐

**核心催化剂**（来自重点新闻）：
1. 国务院发布AI产业扶持政策（[新闻5](#新闻5)）
2. 国家发改委批准千亿算力建设（[新闻28](#新闻28)）

**投资逻辑链条**：
国家级政策明确扶持方向 → 千亿资金投入算力基建 → 
AI应用场景快速扩张 → 相关企业业绩高增长

**新闻重要性说明**：
✅ 新闻5为国务院级别政策，确定性极高
✅ 新闻28为实际资金落地，非空谈概念
✅ 二者形成"政策+资金"双重催化
```
✅ 优势：清晰区分重点新闻，逻辑链条更清晰，投资依据更充分。

## ❓ 常见问题

### Q1：修改后什么时候生效？
**A**：
- 在界面修改：保存后立即生效
- 修改配置文件：需要重启应用或重新选择模板

### Q2：可以删除一般新闻吗？
**A**：不建议。一般新闻虽然权重低，但可以：
- 验证行业趋势的持续性
- 补充细节信息
- 作为重点新闻的背景支撑

### Q3：AI会严格按照分级标准执行吗？
**A**：AI会尽量遵循，但具有一定灵活性：
- 如果某条新闻虽属"一般新闻"类别，但内容重大，AI可能提升其权重
- 反之亦然
- 这种灵活性有助于避免机械化判断

### Q4：可以同时使用多个分级标准吗？
**A**：不建议。建议：
- 为不同投资风格创建不同的自定义模板
- 每个模板使用一套分级标准
- 根据当前需求切换模板

### Q5：分级标准写得越详细越好吗？
**A**：适度即可：
- ✅ 清晰：5-8条核心标准，易于AI理解
- ❌ 过度：20+条详细标准，可能让AI困惑
- 💡 建议：抓住最重要的3-5个维度

## 🚀 进阶技巧

### 技巧1：多维度分级
不仅按重要性，还可按时间维度：
```
🔴 短期催化（1-3个月）：政策突发、技术爆点
🟠 中期催化（3-12个月）：产业政策、技术突破
🟡 长期催化（1年以上）：国家战略、产业升级
```

### 技巧2：量化权重
给不同类型新闻赋予权重：
```
⭐⭐⭐⭐⭐ 国家级政策（权重5）
⭐⭐⭐⭐   突破性技术（权重4）
⭐⭐⭐     重大事件（权重3）
⭐⭐       一般动态（权重2）
⭐         常规消息（权重1）
```

### 技巧3：结合盘后总结
在盘后总结中补充市场反应：
```
盘后总结：
今日市场对新闻5（国务院AI政策）反应强烈，AI板块涨停20+家。
建议提升新闻5的权重，降低新闻12的权重（市场关注度低）。
```
