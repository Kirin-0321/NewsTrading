## ✅ 能够识别的重复类型

### 1. 高度相似的重复（相似度 ≥ 80%）

**示例**：
```
新闻1: 现货白银向上触及70美元/盎司
新闻2: 现货白银上破70美元/盎司关口
相似度: 80.00% ✅ 会去重
```

**特点**：
- 核心词汇相同
- 句式结构相似
- 仅有少量措辞差异

---

### 2. 中度相似的重复（相似度 60-80%）

**示例**：
```
新闻1: 谷歌母公司Alphabet将以 47.5 亿美元现金加债务的方式收购英特塞克特（Intersect）公司。
新闻2: 谷歌母公司Alphabet将以47.5亿美元收购数据中心的能源供应商Intersect
相似度: 68.75% ✅ 会去重
```

**特点**：
- 主要信息点相同（谷歌、收购、Intersect、47.5亿美元）
- 有明显的细节差异（"现金加债务" vs "数据中心能源供应商"）
- 但整体表述相近

---

## ⚠️ 难以识别的重复类型

### 1. 表述差异大的重复（相似度 < 60%）

**示例**：
```
新闻1: 美国银行首席执行官：美国银行预测2026年经济将保持强劲增长态势。
新闻2: 美国银行CEO：美银预计经济将在2026年强劲增长
新闻3: 美国银行首席执行官MOYNIHAN表示，预测美国2026年经济增长强劲。

相似度矩阵:
  新闻1 vs 新闻2: 58.62% ❌ 不会去重
  新闻1 vs 新闻3: 60.87% ✅ 会去重
  新闻2 vs 新闻3: 42.62% ❌ 不会去重
```

**问题分析**：
| 差异类型 | 新闻1 | 新闻2 | 新闻3 |
|----------|-------|-------|-------|
| 职位表述 | 首席执行官 | **CEO** | 首席执行官**MOYNIHAN** |
| 机构简称 | 美国银行 | **美银** | 美国银行 |
| 动词选择 | 预测 | **预计** | 预测 |
| 表述方式 | 将保持强劲增长**态势** | **强劲增长** | 经济**增长强劲** |

**为什么难以识别**：
- ✅ 核心事实相同（美国银行CEO、2026年、经济增长）
- ❌ 但字符串差异大（简称、同义词、句式不同）
- ❌ 字符串相似度算法无法理解语义

- 但仍有少量"深度重复"（相似度<60%）无法识别

## 💡 解决方案

### 当前方案：60%阈值 ⭐ **推荐**

**优点**：
- ✅ 可以去除大部分重复（约30%去重率）
- ✅ 不需要额外依赖
- ✅ 速度快，实时处理
- ✅ 对普通重复效果好

**局限**：
- ⚠️ 表述差异大的重复可能漏掉
- ⚠️ 需要AI清洗模块进一步处理

---

### 补充方案：AI新闻清洗模块

对于语义去重无法识别的"深度重复"，使用**AI新闻清洗模块**：

```

    ↓ 去除 30% 简单重复

    ↓ 总去重率 50-60%
```

**AI清洗的优势**：
- ✅ 理解语义，识别同义词和简称
- ✅ 识别不同表述的相同事件

## 🚀 未来优化方向

### 1. 关键词提取算法 🔜

在字符串相似度基础上增加关键词匹配：

```python
def is_duplicate(news1, news2):
    # 1. 字符串相似度
    if similarity >= 0.6:
        return True
    
    # 2. 关键词匹配
    keywords1 = extract_keywords(news1)  # ['美国银行', 'CEO', '2026', '经济增长']
    keywords2 = extract_keywords(news2)
    
    if keyword_overlap(keywords1, keywords2) >= 0.7:
        return True
    
    return False
```

**效果**：可识别上述"美国银行"案例

### 2. NLP语义理解 🔮

使用BERT等预训练模型计算语义相似度：

```python
from sentence_transformers import SentenceTransformer

model = SentenceTransformer('paraphrase-multilingual-MiniLM-L12-v2')

# 计算语义向量
vec1 = model.encode(news1['title'])
vec2 = model.encode(news2['title'])

# 余弦相似度
semantic_similarity = cosine_similarity(vec1, vec2)
```

**优点**：
- ✅ 理解深层语义

**缺点**：
- ❌ 需要额外依赖（较大的模型文件）
- ❌ 处理速度较慢
- ❌ 对硬件要求较高

## 📝 FAQ

### Q1: 为什么不直接降到50%阈值？
**A**: 50%阈值会导致误删风险大增。例如：
- "特斯拉股价上涨5%" vs "苹果股价上涨5%" (相似度 ~70%)
- 两条完全不同的新闻可能因句式相似被误删

### Q2: 语义去重会删除重要的不同角度报道吗？
**A**: 不会。例如：
- "央行降息影响房地产市场" vs "央行降息提振股市信心"
- 虽然都提到"央行降息"，但相似度<60%，会被保留

### Q3: 如何调整阈值？
**A**: 修改 `core/semantic_dedup.py` 第172-175行：
```python
default_deduplicator = SemanticDeduplicator(
    time_window_minutes=10,
    similarity_threshold=0.6  # 修改这里
)
```
