# 🔍 A股新闻分析工具使用说明

## 📚 工具包含

### 1. **分析指南** (`A股新闻影响分析指南.md`)
- 📊 完整的分析维度框架（9大维度）
- 🤖 5个AI提示词模板（可直接复制使用）
- 📈 实战使用流程
- 💡 高级技巧和注意事项
- 🎯 关键筛选标准

### 2. **自动分析工具** (`analyze_news_impact.py`)
- 🚀 自动识别重要新闻
- ⭐ 按重要性打分排序
- 🏷️ 自动分类（政策、经济、行业等）
- 📈📉 判断利好/利空
- 📄 生成分析报告

## 🚀 快速开始

### 方式一：使用AI分析（推荐用于深度分析）

#### Step 1：打开TXT文件
```
打开：data/summaries/[日期]_titles.txt
这是最简化的格式，节省AI token
```

#### Step 2：复制AI提示词
从 `A股新闻影响分析指南.md` 中复制以下模板之一：

**日常快速筛选** → 使用 **模板5**
**深度投资分析** → 使用 **模板1** 
**挖掘投资机会** → 使用 **模板2**
**风险预警** → 使用 **模板3**
**政策解读** → 使用 **模板4**

#### Step 3：粘贴到AI
```
1. 复制提示词
2. 将TXT文件内容粘贴到[新闻内容]位置
3. 发送给AI（ChatGPT/Claude/文心一言等）
```

#### Step 4：获得分析结果
AI会返回：
- 重要新闻TOP列表
- 受益板块和龙头股
- 具体操作建议
- 风险提示

### 方式二：使用自动分析工具（推荐用于快速筛选）

#### 运行方式1：交互式菜单
```bash
python analyze_news_impact.py
```

会显示菜单：
```
1. 分析所有文件
2. 分析最新文件
3. 退出
```

#### 运行方式2：直接指定文件
```bash
# 分析指定文件，最低得分5
python analyze_news_impact.py data/raw/12-20_00-18.json 5

# 分析指定文件，最低得分8（只看高影响）
python analyze_news_impact.py data/raw/12-20_00-18.json 8
```

#### 输出内容
1. **控制台输出**：
   - 重要新闻统计
   - 按影响级别分组的详细列表
   - 得分、分类、利好/利空判断

2. **生成报告**：
   - 位置：`data/analysis/[日期]_重点分析.md`
   - 内容：结构化的分析报告，可直接查看

## 📊 得分规则说明

### 重要性得分标准

| 得分范围 | 影响级别 | 说明 | 操作建议 |
|---------|---------|------|---------|
| ≥10 | 🔴 重大影响 | 全市场/多板块影响 | 必看！立即分析 |
| 7-9 | 🟠 高度影响 | 单个重要板块/政策 | 优先关注 |
| 5-6 | 🟡 中等影响 | 细分行业/个股 | 有空关注 |
| <5 | ⚪ 轻微影响 | 影响有限 | 可忽略 |

### 得分构成

不同类型新闻的基础得分：

| 类型 | 得分 | 示例 |
|-----|------|------|
| 货币政策 | 10 | 央行降准、降息 |
| 监管政策 | 10 | 证监会IPO政策、印花税 |
| 宏观经济 | 9 | GDP、PMI、CPI数据 |
| 产业政策 | 8 | 新能源补贴、芯片支持 |
| 房地产 | 8 | 房贷利率、限购政策 |
| 国际影响 | 8 | 美联储政策、关税 |
| 科技板块 | 7 | AI、半导体、新能源车 |
| 资金面 | 7 | 北上资金、ETF大额申赎 |
| 消费板块 | 6 | 白酒、医药、零售 |
| 金融板块 | 6 | 银行、保险、券商 |
| 周期板块 | 5 | 有色、钢铁、化工 |

**注意**：一条新闻可能匹配多个分类，总得分累加！

## 📈 提高准确率的技巧

### 1. 结合多日数据
```
不要只看一天的新闻，结合3-5天的趋势：

例如：
- 周一：央行官员表态"维持流动性"
- 周三：市场传言降准
- 周五：央行正式宣布降准
→ 这是一个完整的政策信号链条
```

### 2. 关注"非共识"
```
市场都在关注的新闻，往往已经反应在股价中。
重点找：
- 被忽视但重要的新闻
- 长期趋势的早期信号
- 政策转向的微妙变化
```

### 3. 观察市场反应
```
同样的新闻，不同市场环境下反应不同：
- 牛市：利好放大，利空缩小
- 熊市：利空放大，利好缩小
- 震荡市：短期影响为主

观察开盘后市场的实际反应，修正AI的判断
```

### 4. 建立自己的数据库
```
记录：
- 历史上类似新闻的市场反应
- 不同板块对政策的敏感度
- AI分析的准确率

例如：
"降准50bp → 券商平均涨幅3-5% → 持续时间3-5天"
```

## ⚠️ 常见误区

### ❌ 误区1：看到利好就买
```
错误：央行降准 → 立即满仓买入
正确：
1. 判断是否超预期（市场是否已提前反应）
2. 选择最受益的板块（券商>银行>地产）
3. 控制仓位（30-50%）
4. 设置止损（跌破支撑位）
```

### ❌ 误区2：只看单条新闻
```
错误：只看"茅台提价"就买白酒股
正确：
1. 结合宏观环境（消费是否复苏）
2. 结合行业趋势（高端消费是否回暖）
3. 结合公司基本面（业绩是否支撑）
```

### ❌ 误区3：过度交易
```
错误：每天根据新闻频繁买卖
正确：
1. 只对重大影响新闻采取行动
2. 中长期持有优质标的
3. 短期交易只用30%仓位
```
