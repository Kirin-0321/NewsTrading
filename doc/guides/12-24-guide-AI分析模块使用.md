# 🤖 AI分析模块 - 使用指南

**版本**: v1.0
**更新时间**: 2025-12-21

---

## 📋 快速开始

### 1. 安装依赖

```bash
# 安装AI分析所需的Python库
pip install openai zhipuai
```

### 2. 配置API Key

打开应用 → AI分析页面 → AI配置：

1. 选择AI服务商（OpenAI 或 智谱AI）
2. 输入API Key
3. 点击"保存"
4. 点击"测试连接"验证配置

### 3. 开始分析

1. 选择数据源（推荐使用导出文件）
2. 调整分析参数（可选）
3. 点击"开始分析"
4. 等待分析完成
5. 点击"打开报告"查看结果

3. 进入 API Keys 页面

**智谱AI:**
1. 访问 https://open.bigmodel.cn
2. 注册/登录账号
3. 进入控制台
4. 查看API Key

#### 模型选择

| 模型 | 特点 | 成本 | 推荐用途 |
|------|------|------|----------|
| **GPT-4** | 最强大 | 最贵 | 深度分析 |
| **GPT-4-Turbo** | 快速 | 较贵 | 日常分析 |
| **GPT-3.5** | 经济 | 便宜 | 快速扫描 |
| **GLM-4** | 均衡 | 适中 | 通用分析 |

### 数据源选择

#### 选项1: 使用导出文件（推荐）

**优势**:
- ✅ 数据已去重
- ✅ 时间范围灵活
- ✅ 支持多种格式（JSON/MD/TXT）

**操作步骤**:
1. 先在"数据导出"页面导出数据
2. 回到"AI分析"页面
3. 选择"使用导出文件"
4. 点击"浏览"选择导出的文件

**文件格式选择**:
- **JSON**: 完整分析（Token: ~18500）
- **Markdown**: 详细分析（Token: ~23000）
- **TXT**: 快速分析（Token: ~7200）

#### 选项2: 使用影响分析结果（节省token）

**优势**:
- ✅ 只分析重要新闻
- ✅ 大幅节省Token
- ✅ 分析更聚焦

**操作步骤**:
1. 先在"新闻分析"页面进行影响分析
2. 回到"AI分析"页面
3. 选择"使用影响分析结果"
4. 选择生成的分析报告文件（.md）

**成本对比**:
- 全部新闻（2000条）: ~18500 tokens
- 重点新闻（50条）: ~2000 tokens
- **节省**: ~90%

### 分析参数

#### 最多板块数

- 范围: 3-10
- 默认: 6
- 说明: AI将识别的投资板块数量

**建议**:
- 市场活跃时: 6-8个板块
- 市场平淡时: 3-5个板块

#### 每板块推荐股数

- 范围: 3-10
- 默认: 5
- 说明: 每个板块推荐的龙头股票数量

**建议**:
- 深度分析: 5-7只
- 快速浏览: 3-4只

#### 最大新闻数

- 范围: 100-5000
- 默认: 2000
- 说明: 限制分析的新闻数量，减少token消耗

**建议**:
- 完整分析: 2000-3000条
- 快速分析: 500-1000条
- 节省成本: 100-500条

## 🎨 使用技巧

### 技巧1: 分时段分析

```
不要一次性分析所有数据，而是：
1. 先分析最近24小时
2. 再分析最近3天
3. 最后分析最近一周

优势: 捕捉不同时间尺度的机会
```

### 技巧2: 对比分析

```
1. 今天用AI分析生成报告A
2. 明天用AI分析生成报告B
3. 对比两份报告，找出持续热点

优势: 提高判断准确性
```

### 技巧3: 多格式组合

```
1. 先用TXT快速扫描（$0.34）
2. 确定3个最热板块
3. 筛选出这3个板块的新闻
4. 用JSON深度分析（$0.35）

总成本: $0.69
质量: ⭐⭐⭐⭐⭐
```

### 技巧4: 影响分析预筛选

```
流程:
新闻分析 → 筛选重点新闻 → AI分析

成本:
- 直接分析2000条: $0.69
- 先筛选后分析50条: $0.18

节省: 74%
```

## ⚠️ 注意事项

### 1. API Key安全

❌ **不要做**:
- 不要分享你的API Key
- 不要在公开场合展示API Key
- 不要上传包含API Key的文件到Git

✅ **应该做**:
- 妥善保管API Key
- 定期更换API Key
- 设置使用额度限制

### 2. 成本控制

建议设置:
- OpenAI: 月度预算$20-50
- 智谱AI: 月度预算¥100-200

监控方式:
- 定期查看账单
- 设置低余额提醒
- 限制最大新闻数

### 3. 分析质量

⭐ **提高质量的方法**:
1. 使用影响分析预筛选
2. 选择更好的模型（GPT-4 > GPT-3.5）
3. 提供更完整的数据（JSON > TXT）
4. 增加板块数和推荐股数

### 4. 网络问题

如果使用OpenAI遇到网络问题:
- 方案1: 使用国内镜像（需要特殊配置）
- 方案2: 改用智谱AI等国产模型
- 方案3: 配置代理

## 🐛 常见问题

### Q1: 提示"未配置API Key"

**解决方案**:
1. 在AI配置区输入API Key
2. 点击"保存"
3. 点击"测试连接"验证

### Q2: 提示"连接测试失败"

**可能原因**:
- API Key错误
- 网络问题
- 账户余额不足

**解决方案**:
1. 检查API Key是否正确
2. 检查网络连接
3. 登录服务商查看余额

### Q3: 分析速度很慢

**原因**:
- 新闻数量太多
- 选择的模型较慢
- 网络延迟

**解决方案**:
1. 减少最大新闻数
2. 使用Turbo模型
3. 使用影响分析预筛选

### Q4: 分析结果不理想

**改进方法**:
1. 使用更好的模型（GPT-4）
2. 提供更完整的数据（JSON格式）
3. 增加板块数和推荐股数
4. 使用影响分析预筛选重点新闻

### Q5: 报告打不开

**解决方案**:
1. 检查报告文件是否存在
2. 安装Typora（推荐）
3. 使用系统默认Markdown查看器
