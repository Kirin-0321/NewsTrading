### 1.1 核心组件

```
主程序 (main.py)
    ↓
主窗口 (MainWindow)
    ↓
调度服务 (SchedulerService)
    ↓
定时任务 (schedule库)
    ↓
爬虫执行 (CrawlerPage)
```

### 1.2 工作流程

1. **程序启动**: 运行 `main.py` 启动GUI程序
2. **创建调度服务**: `MainWindow.__init__()` 创建 `SchedulerService` 实例
3. **设置回调函数**: 设置 `on_scheduled_task` 作为任务触发回调
4. **启动调度服务**: 调用 `scheduler_service.start()` 启动后台线程
5. **后台监控**: 调度器每秒检查是否有任务需要执行
6. **任务触发**: 到达设定时间时，触发回调函数
7. **执行爬虫**: 通过Qt信号槽机制在主线程中启动爬虫
8. **更新状态**: 任务执行完成后更新 `last_run` 字段
9. **程序关闭**: 窗口关闭时自动停止调度服务

### 4.2 任务回调实现

```python
def on_scheduled_task(self, task):
    """定时任务触发时的回调"""
    try:
        # 获取爬虫页面
        crawler_page = self.pages.get('crawler')
        
        # 获取任务参数
        scroll_times = task.get('scroll_times', 36)
        wait_seconds = task.get('wait_seconds', 6)
        max_no_change = task.get('max_no_change', 3)
        
        # 触发爬虫（在主线程中执行）
        QMetaObject.invokeMethod(
            crawler_page,
            'start_crawler_from_schedule',
            Qt.QueuedConnection,
            Q_ARG(int, scroll_times),
            Q_ARG(int, wait_seconds),
            Q_ARG(int, max_no_change)
        )
    except Exception as e:
        print(f"定时任务执行失败: {e}")
```

✅ 回调函数实现完整  
✅ 线程安全处理正确（使用QueuedConnection）  
✅ 异常处理完善

```python
@pyqtSlot(int, int, int)
def start_crawler_from_schedule(self, scroll_times, wait_seconds, max_no_change):
    """从定时任务启动爬虫"""
    # 设置参数
    self.scroll_times_spin.setValue(scroll_times)
    self.wait_seconds_spin.setValue(wait_seconds)
    self.max_no_change_spin.setValue(max_no_change)
    
    # 启动爬虫
    self.start_crawler()
```
