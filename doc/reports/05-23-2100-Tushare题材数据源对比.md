## 1. 背景

NewsTrading 从分析报告抽取的 `theme_name` 为自由文本（如「具身智能/人形机器人」「算力」），与行情侧板块名称不一致时，无法稳定做：

- 跨日题材热度追踪（`get_theme_history`）
- T+1 板块涨跌幅、涨停生态验证
- 与预测强度、情绪字段的量化回测

2026-05-22 对 Tushare Pro 多接口拉取同日全量数据并做关键词对比（机器人、半导体、电网、算力、AI 应用等），结论如下。

### 当日大盘（`market_indices_20260522.csv`）

| 指数 | 涨跌幅 |
|------|--------|
| 上证 | +0.87% |
| 深成指 | +2.30% |
| 创业板 | +2.84% |
| 沪深300 | +1.30% |

东财 `dc_index` 板块统计（`dc_index_summary_20260522.csv`）：共 1013 条，涨 875 / 跌 136，均涨约 **+1.44%**。  
其中 `idx_type`：**概念板块 486**、行业板块 496、地域 31。题材对齐建议筛 **`idx_type=概念板块`**。

## 3. 各平台优缺点

### 3.1 东财 `dc_index`（概念板块指数）

**优点**

- 含**概念 + 行业 + 地域**（2026-05-22 共 1013 条）；筛 `idx_type=概念板块` 后约 486 条，与「题材」最接近。
- `pct_change` 单位为**百分比**，直观（如多模态 AI +1.34%、人形机器人 +2.33%）。
- 字段丰富：`leading` / `leading_pct`（龙头）、`up_num` / `down_num`、`turnover_rate`、`total_mv`。
- 名称覆盖口语常见题材：算力概念、人形机器人、半导体概念、智能电网、多模态 AI 等。
- 可与 `dc_member` 拉成分股，便于与 `theme_stocks` 交叉验证。

**缺点**

- 名称粒度与 AI 不完全一致（如 AI 写「算力」，标准名为「算力概念」「东数西算」需映射）。
- 同一主题可能拆多个板块（机器人 → 人形机器人 / 机器人概念 / 执行器），需规则或人工选主映射。
- 与开盘啦、同花顺**无统一代码**，跨源需维护别名表。

**适用场景**：**题材标准名主数据源**、日涨跌幅回测、板块环境写入分析报告。

---

### 3.2 东财 `dc_daily`

**优点**

- 与 `dc_index` **同代码、同涨跌幅**，可互为校验。
- 与 `dc_index` 同批 1013 条，适合需要行业对照时。

**缺点**

- 默认需用 `dc_index` 补全 `name`（`dc_daily` 部分字段无名称列）。
- 概念与行业混在一起，直接当「题材全量」会污染统计。

**适用场景**：批量落库行情；题材对齐仍建议以 `dc_index` 筛 `idx_type=概念板块` 或仅概念 BK 段。

---

### 3.3 开盘啦 `kpl_concept`

**优点**

- 名称**最贴短线情绪**（核心城市算力、AI 算力基建、功率半导体、并购重组预期等）。
- `z_t_num`（涨停家数）、`up_num` 反映当日题材热度，与新闻驱动型预测互补。
- 条数少（约 136），维护别名成本低。

**缺点**

- **无板块日涨跌幅**，不能直接做「预测题材 T+1 涨跌」验证。
- 日更列表变动大，跨日追踪稳定性弱于东财/同花顺指数。
- 与东财/同花顺**命名体系独立**（`.KP` vs `.DC` / `.TI`）。

**适用场景**：情绪/涨停数辅助指标；**不宜**作为唯一标准名与涨跌主键。

---

### 3.4 同花顺概念指数 `ths_daily`（type=N）

**优点**

- 概念指数体系成熟，名称带注解（如「东数西算(算力)」「Sora概念(文生视频)」）。
- 可按 `trade_date` 一次拉取当日全部日线（约 1232，筛 N 后约 395 概念）。
- 与 `ths_index`、`concept` 名录、`limit_cpt_list` 代码一致（`.TI`）。

**缺点**

- 2026-05-22 实测与东财**方向、量级已较接近**（如第三代半导体东财 +3.62%、同花顺 +3.76%），但仍建议以单一数据源设阈值，跨源只做方向校验。
- 部分指数 `name` 为空，需 `ths_index` 反查补全。
- 混入样本股、连板表现等特殊指数（type=S），必须按 `type` 过滤。

**适用场景**：同花顺生态下的交叉验证；与东财映射后的第二行情源。

---

### 3.5 同花顺行业指数 `ths_daily`（type=I）

**优点**

- 适合「半导体」「电力」等**偏行业**宽口径回测。
- 层级清晰（如半导体 881121、电网设备 881278）。

**缺点**

- 与短线「题材」粒度不匹配（AI 预测的往往是概念级）。
- 行业涨跌与概念涨跌可能背离。

**适用场景**：行业景气背景；**不**建议作为 AI 题材对齐的主标准。

---

### 3.6 同花顺 `concept`（静态名录）

**优点**

- 879 条概念名录，`code`+`name` 稳定，适合建**本地注册表**底库。
- 可与 `concept_detail` 拉历史成分。

**缺点**

- **无交易日涨跌幅**，必须再 join `ths_daily` 或其它行情接口。
- 与东财板块**不是同一套 ID**，需名称/模糊匹配建桥。

**适用场景**：同花顺侧 ID 索引；需配合 `ths_daily` 才有行情。

---

### 3.7 涨停题材榜 `limit_cpt_list`

**优点**

- 聚焦当日**涨停生态最强**的约 20 个题材（连板、涨停家数、排名）。
- 适合验证「预测是否为当日主线」。

**缺点**

- **非全量**，大量中等热度题材缺失。
- 仅有少数头部题材，不能支撑全库对齐。

**适用场景**：单日主线校验；补充指标，非主数据。

---

### 3.8 其它（实测未纳入主表）

| 接口 | 说明 |
|------|------|
| `ths_hot` | 含热度与 `pct_change`，但有严格调用频次限制（约 1 次/分钟） |
| `stk_mins` | 分钟线，需单独付费且频次低 |
| `major_news` | 新闻包，与题材指数无关 |

## 4. 跨平台实测差异（摘要）

以 **2026-05-22** 为例（强势日，概念普涨）：

| 用户口语 | 东财代表板块 | 东财涨跌 | 同花顺概念代表 | 同花顺涨跌 | 开盘啦 |
|----------|--------------|----------|----------------|------------|--------|
| 机器人 | 人形机器人 | **+2.33%** | 人形机器人 | +2.29% | 无涨跌字段 |
| 半导体 | 半导体概念 | **+3.39%** | 第三代半导体 | +3.76% | 无 |
| 电网 | 特高压 | **+2.57%** | 特高压 | +2.77% | 无 |
| 算力 | 算力概念 | **+2.38%** | 算力租赁等 | 见 CSV | 无 |
| AI应用 | 人工智能 | **+1.67%** | 多模态AI | +1.34% | 无 |

**结论**：强势日各源**方向一致、均为上涨**；命名粒度仍不同（需映射）。对齐必须以**单一主标准 + 别名表**实现。  
**注意**：`trade_date` 必须用 8 位 `YYYYMMDD` 且核对年份，避免 `2025` / `2026` 混用。

## 5. 选型建议（本项目）

| 角色 | 推荐 | 理由 |
|------|------|------|
| **标准题材名 + 主键** | 东财 `dc_index` | 概念专用、有涨跌幅、字段全、与口语映射成本相对最低 |
| **别名/短线标签** | 开盘啦 `kpl_concept` | 补充 z_t_num，不做涨跌主键 |
| **交叉验证** | 同花顺 `ths_daily`(N) | 同主题方向校验，注意 pct 量纲 |
| **行业背景** | `ths_daily`(I) 或 `dc_daily` 行业段 | 非题材主表 |
| **静态索引** | `concept` + 本地 `theme_concept_registry` | 定期同步，支撑模糊匹配 |

建议入库字段（在 `theme_predictions` 扩展或旁表）：

- `theme_name`：保留 AI 原文
- `ts_code` / `ts_name` / `ts_source`：对齐后的东财标准（如 `dc` + `BK1184.DC` + `人形机器人`）
- `match_confidence` / `match_method`：exact | fuzzy | manual
