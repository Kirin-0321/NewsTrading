# AI报告新闻链接跳转功能说明

## 📋 功能概述

在AI分析报告的"📰 引用新闻详情"章节中，所有引用的新闻标题都会自动转换为**可点击的超链接**，点击后可直接跳转到原文网页。

---

## ✨ 功能特点

- ✅ **新闻标题自动转换为超链接**
- ✅ **一键跳转到原文网页**
- ✅ **同时显示原文URL地址**
- ✅ **支持所有Markdown阅读器**
- ✅ **完美适配Typora**

---

## 📊 效果对比

### ❌ 修改前（无法点击）

```markdown
### 新闻34
**时间**: 2025-12-22 10:30
**标题**: 阿里开源图像模型Qwen-Image-Layered发布
**来源**: 36氪
**内容**: 阿里巴巴今日宣布...
```

用户无法直接跳转，只能手动搜索。

### ✅ 修改后（可点击跳转）

```markdown
### 新闻34
**时间**: 2025-12-22 10:30
**标题**: [阿里开源图像模型Qwen-Image-Layered发布](https://36kr.com/p/2951234567890)
**来源**: 36氪
**原文链接**: https://36kr.com/p/2951234567890
**内容**: 阿里巴巴今日宣布...
```

用户可以：
- 点击标题中的蓝色链接直接跳转
- 复制原文链接在浏览器中打开
- 快速查看新闻详情

## 🎯 使用方法

### 方法1：Typora中点击跳转（推荐）

1. **打开AI分析报告**
   - 在AI分析页面点击"打开报告"按钮
   - 或直接双击`.md`文件用Typora打开

2. **定位到"📰 引用新闻详情"章节**
   - 滚动到报告末尾
   - 找到引用的新闻列表

3. **点击跳转**
   - **Windows**: `Ctrl` + 点击标题链接
   - **Mac**: `Command` + 点击标题链接
   - 自动在默认浏览器中打开原文

### 方法2：其他Markdown阅读器

支持的阅读器：
- **VSCode** (with Markdown Preview)
- **Obsidian**
- **Notion**
- **Bear**
- **任何支持Markdown的编辑器**

操作：
- 直接点击链接即可跳转（根据编辑器不同可能需要按住Ctrl）

### 方法3：复制链接手动打开

1. 找到"**原文链接**"行
2. 复制URL地址
3. 在浏览器中粘贴并打开

---

## 🔧 技术实现

### Markdown链接语法

```markdown
[显示文本](URL地址)
```

### 代码逻辑

1. **提取新闻数据中的URL字段**
   - 支持 `url` 字段
   - 支持 `link` 字段
   - 兼容多种数据格式

2. **生成Markdown链接**
   ```python
   if url:
       lines.append(f"**标题**: [{title}]({url})")
   else:
       lines.append(f"**标题**: {title}")
   ```

3. **添加原文链接**
   ```python
   if url:
       lines.append(f"**原文链接**: {url}")
   ```

## ⚠️ 注意事项

### 1. URL可用性

- ✅ 系统会自动从新闻数据中提取URL
- ⚠️ 如果新闻数据中没有URL，标题不会转换为链接
- ⚠️ 某些新闻网站的链接可能会过期

### 2. 链接访问

- ✅ 大部分新闻网站可以直接访问
- ⚠️ 部分网站可能需要登录或订阅
- ⚠️ 某些链接可能受到地域限制

### 3. Markdown阅读器

- ✅ Typora完美支持链接点击
- ✅ 大多数Markdown编辑器都支持
- ⚠️ 纯文本编辑器无法点击（但可以复制URL）

## 🆘 常见问题

### Q1: 标题没有变成链接？

**原因**：新闻数据中缺少URL字段

**解决**：
- 检查数据来源是否包含链接
- 使用原始新闻数据（包含URL）而非标题摘要
- 手动复制"原文链接"行的URL

### Q2: 点击链接没有反应？

**原因**：Markdown阅读器设置问题

**解决**：
- **Typora**: 确保按住 `Ctrl`（Windows）或 `Command`（Mac）后点击
- **VSCode**: 在Markdown预览模式下点击
- **其他编辑器**: 查看该编辑器的链接点击方式

### Q3: 链接打开后显示404？

**原因**：新闻链接已失效

**解决**：
- 尝试在搜索引擎中搜索新闻标题
- 查看新闻来源网站的最新版本
- 使用网页快照服务（如Google Cache）

### Q4: 如何在报告中添加自己的链接？

**格式**：
```markdown
[显示文本](URL地址)
```

**示例**：
```markdown
[查看更多](https://example.com)
```
