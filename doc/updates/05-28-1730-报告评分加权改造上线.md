## 一、本次改了什么

把**报告级评分**的 D+N 数值口径，从「纯板块涨幅 sector_pct」改为
「板块涨幅 0.6 + 题材内标的均值涨幅 0.4」的加权合成涨幅 `theme_pct`。

公式：

| 条件 | theme_pct | 含义 |
|---|---|---|
| `sector_pct IS NULL` | NULL | 题材板块未绑定 / 板块当日无数据 |
| `stock_avg_pct IS NULL` | `sector_pct` | 题材当日无标的有效数据，退回纯板块涨幅 |
| 否则 | `0.6·sector_pct + 0.4·stock_avg_pct` | 加权合成 |

`alpha` 字段语义同步切换：`alpha = theme_pct - benchmark_pct`，
取代旧口径 `stock_weighted_pct - benchmark_pct`。

## 二、决策来源（5 项主人锁定）

| Q | 决策 |
|---|---|
| 作用层 | **仅改报告级** `get_report_eval`；题材级第 2 层 / 模板级第 1 层保持 v2 sector_pct 口径不变 |
| 实现路径 | 新增 `theme_pct` 字段 + 迁移 + 重打分（vs 内联 SQL 表达式） |
| 无标的兜底 | 1.0 × sector_pct（不打折） |
| alpha 口径 | 全局切换为 `theme_pct - benchmark_pct` |
| 存量数据 | 重打分（实操：theme_predictions 当前为空，等下次抽题材时自动生效） |
