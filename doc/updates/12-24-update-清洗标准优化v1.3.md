# 清洗标准优化 v1.3

## 版本：v1.3
**更新日期：2025-12-23**

---

## 🎯 优化目标

**问题：** 清洗后的新闻中包含大量小公司的日常运营信息，这些新闻数量多但对整体A股市场影响有限，造成信息噪音。

**解决方案：** 提高筛选门槛，聚焦真正有市场影响力的新闻。

---

## 📋 主要修改

### 1. 资金动向 - 增加影响力门槛

#### 修改前
```
✅ 资金动向：
- 融资事件：IPO、定增、债券发行
- 战略投资：机构入股、产业投资
- 股权变动：控制权变更、大股东增减持
```
❌ **问题：** 保留所有公司的资金动向，包括小公司的小额交易

#### 修改后
```
✅ 资金动向（需满足影响力要求）：
- 融资事件：大型IPO（募资>10亿）、行业龙头定增、重大债券发行
- 战略投资：行业巨头机构入股、产业链重大整合
- 股权变动：市值100亿以上公司的控制权变更、行业龙头大股东增减持
- 金额门槛：单笔金额通常需>5亿元，或对行业有重大影响
```
✅ **优势：** 只关注大额、战略性交易和大公司动向

---

### 2. 去除标准 - 新增小公司过滤

#### 新增规则
```
❌ 小公司动向：
- 中小市值公司（<100亿）的常规业务
- 项目备案、小额合同
- 产能调整等日常经营信息
```

**说明：**
- 明确过滤小市值公司的日常运营信息
- 除非有重大技术突破或行业影响
- 减少个股噪音

---

### 3. 判断原则 - 强化标准

#### 修改前
```
【判断原则】：
1. 宁缺毋滥：不确定时选择保留
2. 关注催化：能否作为投资催化剂
3. 时效性：近期新闻优先保留
4. 完整性：信息完整的新闻优先保留
```

#### 修改后
```
【判断原则】：
1. 影响力优先：优先保留对整体市场/行业有影响的新闻
2. 规模门槛：个股新闻需关注大市值公司（通常>100亿）或行业龙头
3. 关注催化：能否作为投资催化剂或板块轮动信号
4. 金额标准：资金类新闻关注大额（通常>5亿）或战略性投资
5. 时效性：近期新闻优先保留
6. 完整性：信息完整的新闻优先保留
```

**变化：**
- 新增"影响力优先"原则（排第一）
- 新增"规模门槛"要求（市值>100亿）
- 新增"金额标准"要求（>5亿）

## 📊 实际效果对比

### 示例：将被去除的新闻

❌ **莱茵生物：控制权将变更 拟购买北京金康普80%股权**
- 原因：小市值公司（市值约25亿）
- 分类：日常并购重组
- 影响：仅对个股有影响，对市场无影响

❌ **鼎通科技：公司近期已备案高速通讯液冷散热器项目**
- 原因：小公司项目备案
- 分类：常规业务规划
- 影响：无实质进展，纯信息披露

❌ **欧科亿：三季度末钨材料及在产品库存约3.5亿**
- 原因：小公司库存和价格信息
- 分类：日常经营数据
- 影响：个股信息，对行业影响有限

---

### 示例：将被保留的新闻

✅ **中芯国际已经对部分产能实施了涨价 涨幅约为10%**
- 原因：行业龙头（市值2000亿+）
- 分类：行业价格变化
- 影响：影响整个半导体产业链
- ✨ **符合标准：行业龙头 + 价格变化**

✅ **宁德时代定增200亿投资下一代电池**
- 原因：行业龙头（市值万亿级）
- 分类：大额融资（>10亿）
- 影响：引领行业技术方向
- ✨ **符合标准：大市值 + 大额融资 + 技术突破**

✅ **比亚迪完成50亿美元海外融资**
- 原因：行业龙头（市值8000亿+）
- 分类：大额融资（>5亿）
- 影响：国际化战略，影响新能源车板块
- ✨ **符合标准：大市值 + 大额融资 + 战略意义**

✅ **国家发改委发布氢能产业中长期规划**
- 原因：国家级政策
- 分类：行业规划
- 影响：引导产业发展方向
- ✨ **符合标准：政策类新闻**

## 🎯 筛选逻辑

### 个股新闻筛选流程

```
个股新闻
  ↓
【步骤1】检查市值
  → 市值 < 100亿？
    ├─ 是 → 【步骤2】检查是否行业龙头
    │        ├─ 是行业龙头 → 继续判断
    │        └─ 不是 → ❌ 去除
    └─ 否（≥100亿）→ 继续判断
  ↓
【步骤2】检查新闻类型
  → 是否符合保留标准？
    ├─ 技术突破/重大创新 → ✅ 保留
    ├─ 大额融资（>5亿）→ ✅ 保留
    ├─ 重大合同/战略合作 → ✅ 保留
    ├─ 业绩超预期 → ✅ 保留
    └─ 日常运营信息 → ❌ 去除
```

## 🔍 关键标准详解

### 市值门槛：100亿

**为什么是100亿？**
- A股市值100亿以上约800家公司
- 占总上市公司数量约15%
- 但市值占比超过80%
- 能覆盖各行业龙头和重要公司

**例外情况：**
- 行业隐形冠军（细分领域第一）
- 国家战略企业（即使市值小）
- 重大技术突破（颠覆性创新）

---

### 金额门槛：5亿

**为什么是5亿？**
- IPO募资：5亿以下属于小型IPO
- 定增：5亿以下通常是补流动资金
- 合同：5亿以下对大公司业绩影响有限
- 战略性：5亿以上通常涉及战略布局

**例外情况：**
- 战略性投资（即使金额小）
- 产业链关键环节
- 行业并购整合

---

### 行业龙头定义

**判断标准：**
1. 市场份额：行业前3
2. 技术实力：拥有核心技术
3. 品牌影响：行业标杆企业
4. 定价权：影响行业价格

**典型例子：**
- 半导体：中芯国际、华虹公司
- 新能源车：比亚迪、宁德时代
- 光伏：隆基绿能、通威股份
- 白酒：茅台、五粮液
- 银行：工商银行、招商银行

## 💡 使用建议

### 1. 首次使用

**建议步骤：**
1. 使用新标准清洗一批新闻
2. 查看保留率（预计30-35%）
3. 抽查removed文件，确认没有误删重要新闻
4. 查看clear文件，确认信息密度提升

### 2. 标准调整

**如果保留率太低（<25%）：**
- 考虑降低市值门槛至50亿
- 或降低金额门槛至3亿
- 在 `config/cleaning_criteria.json` 中修改

**如果保留率太高（>40%）：**
- 考虑提高市值门槛至200亿
- 或提高金额门槛至10亿
- 更严格定义"行业影响"

### 3. 行业特殊性

**某些行业可能需要特殊考虑：**
- 芯片：小公司也可能有重大突破
- 医药：临床试验进展重要
- 军工：小公司订单也可能重要
- 新材料：技术突破比规模重要

**解决方案：**
- 在保留标准中强调"技术突破"和"国产替代"
- 这些会优先于市值门槛

## ⚠️ 注意事项

1. **误删风险：** 新标准更严格，可能会过滤掉部分有价值的小公司新闻
   - 建议：首次使用后检查removed文件
   - 解决：调整市值门槛或在AI分析时补充

2. **行业差异：** 不同行业的"大公司"定义不同
   - 建议：关注"行业龙头"判断，而非绝对市值
   - 解决：AI会综合判断公司在行业中的地位

3. **动态调整：** 标准不是一成不变的
   - 建议：根据实际使用效果调整门槛
   - 解决：修改 `config/cleaning_criteria.json` 即可
