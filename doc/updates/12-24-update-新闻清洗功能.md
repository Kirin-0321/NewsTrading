## 🔧 技术细节

### 清洗流程

```
选择文件 → 加载数据 → 合并去重 → AI分批判断 → 分类保存 → 生成统计
```

### 文件命名规则

**单次清洗：**
- 保留：`起始月-日-时_结束月-日-时_clear.json`
- 去除：`起始月-日-时_结束月-日-时_removed.json`
- 示例：`12-19-13_12-23-20_clear.json`

**合并后：**
- 合并：`起始月-日_结束月-日_clear.json`
- 示例：`12-23_12-23_clear.json`

### 数据结构

**清洗后的JSON格式：**
```json
{
  "metadata": {
    "type": "cleaned_single",
    "source_files": ["原始文件名"],
    "source_count": 2269,
    "kept_count": 1039,
    "removed_count": 1230,
    "cleaning_time": "2025-12-23 21:14:13",
    "time_range": {
      "start": "2025-12-19 13:00:00",
      "end": "2025-12-23 20:00:00"
    },
    "criteria": "清洗标准前200字符...",
    "ai_provider": "deepseek"
  },
  "news": [
    {
      "title": "新闻标题",
      "time": "2025-12-23 20:00:00",
      "content": "新闻内容...",
      "source": "来源",
      "url": "链接"
    }
  ]
}
```

### AI Prompt设计

**System Prompt：**
- 定义角色：专业金融新闻筛选助手
- 提供清洗标准（保留标准 + 去除标准）
- 明确输出格式

**User Prompt：**
- 每条新闻包含：标题、时间、来源、内容预览
- 要求AI对每条输出：keep 或 remove
- 批量处理，每批500条

## 🐛 已修复的问题

### 问题1：排序时KeyError: 'time'
**原因：**部分新闻缺少 `time` 字段

**修复：**
```python
# 修改前
kept.sort(key=lambda x: x['time'])

# 修改后
kept.sort(key=lambda x: x.get('time', ''))
```

### 问题2：合并失败 - string indices must be integers
**原因：**`DataMerger.merge_cleaned_files` 返回字符串，但调用代码期望字典

**修复：**
```python
# 修改前
return output_file  # 返回字符串

# 修改后
return {
    'success': True,
    'output_file': output_file,
    'merged_count': len(source_files),
    'total_count': merged_count,
    'unique_count': final_count,
    'removed_duplicates': duplicates_removed
}  # 返回字典
```

### 问题3：文件名生成失败
**原因：**时间解析可能失败

**修复：**增加异常处理，失败时使用当前时间

## 📝 使用示例

### 示例1：清洗导出数据
```
1. 打开【🧹 新闻清洗】页面
2. 数据类型选择"导出数据"
3. 点击【📁 选择文件...】
4. 选择 data/exports/export_12-19_13_12-21_14/12-19_13_12-21_14.json
5. 保持默认设置（500条/批，自动合并去重）
6. 点击【🚀 开始清洗】
7. 等待完成（约5-10分钟）
8. 点击【🤖 用于AI分析】直接分析
```

### 示例2：合并多个清洗结果
```
1. 打开【📁 数据管理】页面
2. 文件类型选择"清洗后数据"
3. 确认有多个 _clear.json 文件
4. 点击【🔀 合并去重（清洗数据）】
5. 确认合并
6. 查看合并后的文件
```
