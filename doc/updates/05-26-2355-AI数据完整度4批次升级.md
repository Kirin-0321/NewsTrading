## 一、改造目标

主人导出 26 号盘后 MD 后提出「数据越完整越好」。诊断发现：

- 板块榜只显示 Top 10，跌幅维度完全缺失
- 全市场涨跌家数（`advance` / `decline`）一直是 None
- 全市场主力净流入 / 昨日封板率 / 晋级率明细 / 龙虎榜上榜原因 全空
- 数据完整性段渲染 bug：validator gaps 用 `path` 字段，但 renderer 取 `field` → 显示空键名
- 龙虎榜只看到「中信上海分部」等知名游资，普通席位（沪股通 / 机构 / 大券商）完全不显示

按风险升序拆 4 个 Batch，每个批次完成后立即跑 `export_market_summary.py` 验证。

## 二、Batch 1：纯 renderer 改造（无后端改动）

| 编号 | 改造点 | 改动位置 |
|------|--------|---------|
| A1 | 板块涨幅渲染 `[:10]` → `[:20]`，标题动态读 `len(sectors)` | `renderer._render_sectors_top` |
| A5 | 连板梯队 `_format_ladder_item` 输出 `N板·题材·炸N次` | `renderer._format_ladder_item` |
| A6 | 龙虎榜 TOP5 每条加「上榜原因」详情（≤2 条 + 等 N 条折叠） | `renderer._render_dragon_tiger` |
| A7 | 数据完整性段 gaps 字段名 bug 修复 | `renderer._render_quality` |

### 关键 bug 修复细节（A7）

- validator 产出的 gap 用 `path` 键
- service 手收集的 gap 用 `field` 键
- renderer 之前只取 `g.get('field', '')` → validator gap 全部显示为空

修复后：渲染前 `field = g.get("field") or g.get("path") or ""`，且 reason 缺失时根据 `layer / filled_count / total_count / filled_ratio` 自动合成。

### CLS 板块名 vs DC 板块名 匹配问题

财联社板块名 `证券` / `电力` / `商业零售` 在 dim_sector 里是 `证券概念` / `电力行业` 等细分概念，名字不严格相等会 NULL fallback。

KISS 取舍：用「name = name」精确匹配，命中失败的事件只显示「共 N 只票」，不冒充。`meta.market_shock_match` 记 `{matched: 7, total: 15}` 给运维查看。

## 五、Batch 4：advance/decline 涨跌家数（新 Tushare API + 新表）

| 字段 | 口径 |
|------|------|
| `breadth.advance` / `decline` / `unchanged` | `daily(trade_date=...)` 全市场聚合，pct_chg > 0 / < 0 / = 0 |
| `breadth.advance_5` / `decline_5` | 大涨大跌：pct_chg ≥ 5% / ≤ -5% |
| `breadth.advance_pct` | `advance / total` |
| `breadth.total` | 当日有效样本（pct_chg 非 NULL） |

### 数据流

1. `migrations/004_fact_market_breadth.sql` 建轻量单行表
2. `tushare_fetcher._fetch_market_breadth`：1 次 `daily` API → 内存聚合 → INSERT OR REPLACE
3. `service._read_breadth_and_sentiment` SELECT 该表填 breadth 字段
4. `renderer._render_breadth_sentiment` 输出三行：上涨/下跌/平/样本/占比、大涨大跌、原有封板率行

### 缓存策略

- force_refresh=True：先 `_purge_trade_date`（已把 `fact_market_breadth` 加入清单）→ 重拉
- 缓存命中：跳过 fetch，但 service 直接 SELECT 已有行，无需重新调 API

## 八、AI 决策价值提升

| 维度 | 升级前 | 升级后 |
|------|--------|--------|
| 市场广度 | 仅涨停/跌停/炸板 | + 涨跌家数/平盘/样本/占比/大涨大跌 |
| 板块全貌 | Top 10 单向 | Top 20 涨 + Bottom 10 跌（双向） |
| 主力资金 | 仅北向 + 南向 | + 板块主力净流入合计（带口径） |
| 情绪连续性 | 仅今日封板率 | + 昨日封板率 + 晋级明细（昨涨/今继续/失败） |
| 龙虎榜 | TOP5 净买 + 知名游资 | + 上榜原因 + 其他席位 Top 10（沪深股通/机构/大券商） |
| 板块异动 | 仅时间+方向 | + 当日板块涨跌幅 + 板块主力净流入 |
| 数据透明度 | gaps 字段名 bug | gaps 全字段可读；validator 与手收集 gap 合并 |
