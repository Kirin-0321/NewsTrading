## 一、做了什么

把盘后报告 / GUI 中长期半空的「龙头股 Top3」列从涨停股 LIKE 模糊匹配升级为
**板块真成员当日涨幅 Top3**，并让 GUI 的 split 模式（Top 30 / Bottom 15）
**点击板块行可展开看该板块全部成员股**。

主人本轮上线一共解了 3 个痛点：

| 痛点 | 旧表现 | 新表现 |
|---|---|---|
| 龙头股几乎全空 | 弱势板块没涨停股 → 列显示 "—" | 真成员表 JOIN，所有板块都有领涨/领跌股 |
| 涨停数偏差 | `fact_limit_stock.theme LIKE` 模糊匹配，有时虚高有时虚低 | `dim_sector_stock` 真成员表 JOIN，口径精准 |
| GUI 看板块只能看汇总 | 板块行没法看成员 | 点击 ▶ 展开看全部成员（按当日涨幅 DESC 排） |

顺便：

- 删除 markdown 报告里的「成员」列，`×N` 后缀挂回板块名后（白酒 ×6）
- GUI `sector_table` 列名「龙头股 Top3」→「领涨股」

## 二、技术细节

### 2.1 数据基建

新建表 `dim_sector_stock`（迁移 009）：

```sql
CREATE TABLE dim_sector_stock (
    sector_ts_code TEXT NOT NULL,    -- 板块代码 BK0896.DC
    stock_ts_code  TEXT NOT NULL,    -- 成员股代码 600519.SH
    stock_name     TEXT,             -- 成员股名称（冗余存）
    updated_at     TEXT NOT NULL,
    PRIMARY KEY (sector_ts_code, stock_ts_code)
);
CREATE INDEX idx_secstock_stock ON dim_sector_stock(stock_ts_code);
```

数据源 = Tushare `dc_member` 接口（东方财富板块成份股），CLI 一次性全量
入库（成员变化慢，后续每周覆盖更新即可）。

### 2.2 查询函数（新增）

`services/market/sector_grouping.py`：

| 函数 | 用途 |
|---|---|
| `resolve_dc_sector_ts_code(conn, ts_code)` | ths 板块 → 同组 dc 板块 fallback；dc 板块直接返回自身 |
| `compute_sector_leaders(conn, ts_code, td, *, limit, ascending)` | 板块成员当日涨幅 Top/Bottom N |
| `compute_sector_limit_count(conn, ts_code, td, *, limit_type)` | 板块涨停/跌停股数（真口径） |

`gui/utils/market_db_helper.py`：

| 函数 | 用途 |
|---|---|
| `query_sector_members(sector_ts_code, td, *, limit)` | GUI 懒加载用，返回板块全部成员 + 涨幅 + 状态 |

### 2.3 ths 板块兜底（决策 5 沿用）

ths 源板块 `dc_member` 接口不返回数据。沿用 v1 的 dc fallback 策略：
查同组 `dim_sector` 找一个 dc 源板块的 ts_code，借它的成员表算领涨股 /
涨停数。

实测：白酒概念 [885525.TI] (ths) → 自动 fallback 到白酒 [BK1575.DC]，
拿到同款 Top3（水井坊 / XD舍得酒 / 酒鬼酒）。

### 2.4 服务层接入

`services/market/service.py` 的 `_read_sectors_top` / `_read_sectors_bottom`：

```python
dc_ts = resolve_dc_sector_ts_code(conn, r["ts_code"])
leaders = compute_sector_leaders(conn, dc_ts, td, limit=3) if dc_ts else []
# 旧 leaders 拿不到时回退（避免空表）
if not leaders and _legacy_leaders:
    leaders = _legacy_leaders
# 涨停数走真成员表 JOIN
if dc_ts:
    limit_up_count = compute_sector_limit_count(
        conn, dc_ts, td, limit_type="U",
    )
```

`gui/utils/market_db_helper.py` 的 `query_all_sectors` 也走同款双路径
（v2 路径优先 + LIKE 兜底）。

### 2.5 渲染层

`services/market/renderer.py`：

- 表头：「龙头股 Top3」→「领涨股」、「领跌」→「领跌股」
- 列数：13 列 → **12 列**（删「成员」列）
- `×N` 改挂板块名后：`白酒 ×6`、`影视院线 ×4`
- 聚合语义注脚更新：「板块名后的「×N」表示该行是 N 个同义板块组成的聚类组…」

`_format_leader` 复用，新 leaders 字段 `{ts_code, name, pct_chg, close}`
自动渲染为 `贵州茅台 +2.31%` 格式。
