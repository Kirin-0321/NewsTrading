## 二、改动详情

### Ph1（commit `6dbf802`）

* `gui/pages/data_page.py`
  * 「分析报告」栏目录 `data/analysis` → `data/AI_analysis`
  * `_refresh_md_files` 加 `recursive=True` 选项，AI 报告子目录按 `{月日}/` 分层全部扫到，name 列显示相对路径
  * `_view_md_file` 从 `setPlainText(content[:50000])` → `setMarkdown(content)`，启用 `setOpenExternalLinks`，长报告排版正确且不截断
* `gui/pages/theme_prediction_page.py`
  * 新增模块级常量 `_SECTOR_WEAK_MATCH_CONF = 0.5`
  * 板块列橙色判定 `< 0.7` → `< _SECTOR_WEAK_MATCH_CONF`，与评估页 ⚠ 角标的 0.5 阈值对齐

### Ph2（commit `92d8493`）

* `gui/pages/ai_analysis_page.py`
  * `_build_result_group`：单 `result_browser` 包进 `QTabWidget`
    * Tab 0「📡 实时流式」= 原 `result_browser`（保持 `insertPlainText` 流式追加）
    * Tab 1「📄 成品报告」= 新增 `md_browser`（`setMarkdown` + `setOpenExternalLinks`）
  * `_refresh_for_selected_task`：SUCCESS + 有 `report_file` 时调 `self._render_md(abs_path)`；非成功 / 切任务时清空 md_browser
  * `_clear_lower_panels` 加 `md_browser.clear()`
  * 新增 `_render_md(abs_path)`：读 md 文件 → `setMarkdown`（手动回测页样板的薄壳照搬）

### Ph3（commit `e038040`）

* `services/market/sector_daily_query.py`
  * 新增 `get_sector_names(ts_codes) -> Dict[str, str]`
    * 输入板块代码列表（自动去重 + 过滤空），返回 `{ts_code: name}`
    * 查不到的键不放进字典；market.db 不可用 / dim_sector 无命中时返回空 dict（不抛错）
* `tools/sector_daily_query.py`
  * 加 `--names` 模式：`ts_code` 视为逗号分隔列表，stdout 总输 JSON
  * 退出码：0 = 成功且有命中，1 = 无命中，2 = 参数错
* `gui/pages/theme_prediction_page.py`
  * `_THEME_TABLE_COLS` 第 4 列 `"板块代码"`(90) → `"板块"`(180)
  * `_render_theme_table` 渲染前批量 `get_sector_names` 一次取回全表 ts_code 中文名
  * 新增静态 `_format_sector_cell(name, code, conf)`：
    * 都有 → `酿酒概念 (BK0477.DC 0.95)`
    * 无中文名 → `BK0477.DC (0.95)`（旧格式兜底）
    * 无 conf → 略去括号小数

### Ph4（commit `571478c`）

* `gui/pages/theme_prediction_page.py`
  * `score_detail_browser` 初始占位文案精简
  * `_show_theme_detail` 调 `self._render_score_detail(theme)`
  * 新增 `_render_score_detail(theme)`：调 `scoring_service.get_theme_score_detail(theme.id)` → HTML 渲染
    * 顶部摘要：📊 题材 / 报告日 / 强度（带符号 + 等级）/ 已打分 N 天 / 平均命中率 / 累计方向 ✓/✗
    * 逐日表：偏移 / 交易日 / 板块% / 题材% / 中证1000% / α+N / 命中率（命中数/总数）/ 累计方向
    * AI 评分员评语（如有）单独尾部块
  * 空态三种：`theme.id` 缺失 → 数据异常；`rows=[]` → "尚未打分，去评估页打分"引导；切回时 `_clear_detail` 回到默认空态
  * 新增 4 个格式化辅助 `_fmt_pct_colored / _fmt_pct_plain / _fmt_hit / _fmt_direction`

### Ph5（commit `0fc414b`）

* `services/storage/theme_store.py`
  * `get_by_report` docstring 补充与 `ai_reports.id` 的差异说明
  * 新增 `get_by_ai_report_id(ai_report_id: int) -> List[Dict]`：
    * SQL `JOIN ai_reports ar ON ar.file_path = tp.report_path WHERE ar.id = ?`
    * 排序按 priority_rank ASC + strength_score DESC，与主表自然一致
    * 复用 `_expand` 拉子表（标的 / 新闻）
* `tools/query_themes_by_report.py`（新建）
  * 入参：`ai_report_id`（位置参数）+ `--json` / `--limit`
  * 实跑验证 `id=443` 返回 3 个题材（MLCC/PCB/玻璃基板），`id=999999` 返回空集退出码 1
* `gui/pages/prompt_eval_page.py`
  * signal `theme_drilldown_requested`：`pyqtSignal(str, str)` → `pyqtSignal(str, str, int)`（加 ai_report_id）
  * `_on_tree_double_clicked` emit 第 3 参 `int(data.get("report_id"))`（树节点 payload 早就带 report_id 了）
* `gui/main_window.py`
  * `_on_eval_drilldown(report_date, prompt_id, ai_report_id=0)`：
    * `ai_report_id>0` → 调 `theme_page.load_by_report_id(report_id, hint_date, hint_prompt)`，lock 模式接管
    * `=0` → 走旧路径（仅预选 date+prompt）
    * lock 模式异常时回退到旧路径，不阻塞用户
* `gui/pages/theme_prediction_page.py`
  * `__init__` 加 `self._locked_report_id: Optional[int] = None`
  * viewer 顶部新增 `lock_indicator` QLabel（黄底 + 边框 + 含解除链接）
  * 新增 `load_by_report_id(ai_report_id, *, hint_date, hint_prompt)`：
    * 调 `theme_store.get_by_ai_report_id` 取数据
    * `blockSignals` 同步 date/prompt combo（避免立即被自动解锁逻辑触发）
    * 渲染 lock 指示条 + 题材表 + 清空详情
    * 锁定期间禁用 `delete_btn`（按日期删的语义与 lock 不一致）
  * 新增 `_release_report_lock(reload=True)`：清 lock + 隐藏指示条 + 恢复 delete_btn + 可选触发当前 date/prompt 重渲染
  * `_on_date_changed` / `_on_prompt_changed`：发现 lock 立即自动解锁（reload=False，让原 reload 流程接管）
  * `_reload_themes_for_date` 入口短路：lock 期间直接 return，避免覆盖
