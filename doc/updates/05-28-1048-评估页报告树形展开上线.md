## 一、本次变更速读

把模板评估页下表从「报告级 QTableWidget 平铺」升级为
「**3 级树 QTreeWidget**（📄 报告 → 🎯 题材 → 📈 标的）」，
让主人能从模板均值一路下钻到单股逐日涨跌，复盘链路从"跨页 + 开 SQL"
压缩到"3~4 次点击"。

```
段 1：模板汇总（保持现状）
段 2：报告树（QTreeWidget · 3 级 · 仅顶层支持点击表头排序 · 懒加载）

  ▶ 📄 报告 1  2026-05-22  custom_6  题材14  D+1:+5%  D+5:-8%  [⚡][🗑] xxx.md
  ▼ 📄 报告 2  ...
      ▶ 🎯 人形机器人          强利多   D+1:+8%   D+5:-12%   命中率 33%
      ▼ 🎯 消费电子            中性偏多  D+1:+1%   D+5:+9%   命中率 60%
          📈 XX 龙头  600172.SH  核心   D+1:+5%  D+5:-3%   命中 1/2
          📈 YY 概念  300999.SZ  辐射   D+1:+2%  D+5:+12%  命中 2/2
```

## 二、改动清单

### 2.1 服务层

| 文件 | 变更 |
|------|------|
| `services/scoring/scoring_service.py` | 新增 2 API（无侵入既有 5 API） |
|  | ① `get_theme_eval_for_report(report_id)` —— 返回报告下每题材的 D+N 透视 + stocks_count + scored_pairs |
|  | ② `get_stock_scores_for_theme(theme_id)` —— 返回题材下每只标的的 D+N 涨跌 + 是否命中 |

两个 API 均**只读**，不写任何表；命中既有索引，单查询 < 100ms。

### 2.2 CLI

| 文件 | 变更 |
|------|------|
| `tools/query_eval.py` | `--by` 选项追加 2 个枚举值：`theme_in_report` / `stocks_in_theme` |
|  | 新增 `--report-id` 参数（仅 `theme_in_report` 模式必填） |
|  | 新增 2 个打印函数 `_print_themes_in_report` / `_print_stocks_in_theme` + JSON 输出（字段与 service 完全一致） |

CLI 烟测：
```bash
python tools/query_eval.py --by theme_in_report --report-id 189   # 14 题材
python tools/query_eval.py --by stocks_in_theme --theme-id 1000643 # 14 标的
```

### 2.3 GUI

| 文件 | 变更 |
|------|------|
| `gui/pages/prompt_eval_page.py` | 下半区从 QTableWidget 升级为 QTreeWidget，约 250 行变更 |

主要改动点：

* **新增 `_ReportTreeItem`**（继承 `QTreeWidgetItem`）：重写 `__lt__`，
  顶层按 `Qt.UserRole + 1` 槽里的可比较原始值排序，子级 return False 锁顺序，
  NULL 一律排末尾
* **删除** `_REPORT_COLS` / `_COL_SCORE_BTN` / `_COL_DELETE_BTN` /
  `_COL_FILENAME`；**新增** `_TREE_COLS`（13 列共享 + 5 个层级常量
  `_KIND_REPORT/_THEME/_STOCK`）
* **新增 3 个渲染方法**：
    - `_render_tree_top_level(rows)` — 顶层 📄 节点（每个挂 placeholder 让 ▶ 出现）
    - `_lazy_load_themes(parent, data)` — `itemExpanded` 触发时拉题材
    - `_lazy_load_stocks(parent, data)` — `itemExpanded` 触发时拉标的
* **新增 `_build_report_tail_widget`**：报告父行尾列容器，把
  「⚡ 打分」「🗑 删除」按钮 + 文件名 label 横向塞进同一个 QWidget，
  原本占两列改为只占尾列（13 列 → 比原 16 列省 3 列）
* **改造**：`_render_report_table` → 已替换；
  `_on_report_double_clicked(QTableWidgetItem)` →
  `_on_tree_double_clicked(QTreeWidgetItem, col)` 仅 📄 行响应；
  CSV 导出加 `[报告级]/[题材级]/[标的级]` 三节，导出时强制全量加载（与懒加载缓存 fall-through）
