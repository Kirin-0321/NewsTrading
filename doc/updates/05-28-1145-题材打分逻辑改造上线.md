**日期**：2026-05-28 11:45
**关联设计**：[05-28-1100-题材打分逻辑改造设计](../design/05-28-1100-题材打分逻辑改造设计.md)
**关联施工方案**：[05-28-1115-题材打分逻辑改造施工方案](../design/05-28-1115-题材打分逻辑改造施工方案.md)

## 一、改造目标（一句话）

把题材级 D+N 从「成员股加权均值」改为「板块行情涨跌」，
报告级 D+N 从「等权平均」改为「按 |strength_score| 加权平均（仅看多）」。

## 二、变更范围

### 2.1 数据层（Phase A）

| 模块 | 变更 |
|------|------|
| `services/market/tushare_fetcher.py` | `_fetch_sector_moneyflow` 改为 5 源拉取：`moneyflow_ind_dc` × 3（概念/行业/地域）+ `moneyflow_ind_ths`（同花顺行业）+ `moneyflow_cnt_ths`（**同花顺概念，本次新增**） |
| `_ingest_sector_daily_ths` | 新加 `name_field` / `idx_type` 参数，行业接口传 `industry`，概念接口传 `name` |
| `services/market/sector_daily_sync.py` | 修复 `force=True` 未正确传递的 bug（`force_refresh` 字段 + 强制 DELETE 当日） |
| `tools/sync_daily_market.py` | 通过 fetcher 自动复用 5 源 |

**数据规模**：
- 单日板块数 = 486 概念(dc) + 496 行业(dc) + 31 地域(dc) + 90 同花顺行业(ths) + 386 同花顺概念(ths) ≈ **1489 行**
- 30 天 backfill：**28303 行 / 95 次 API 调用 / 18.6 秒 / 0 失败**
- `dim_sector` 字典从原 506 个 DC 概念扩展到 **1510 个板块**

### 2.2 匹配层（Phase B）

| 模块 | 变更 |
|------|------|
| `services/scoring/matcher.py` | `match_sector_ts_code` 新增 `theme_keywords` / `theme_category` / `force` / `min_conf` 参数；`min_conf` 默认 0.5→0.3；同 conf 时 dc 优先于 ths |
| `services/storage/theme_store.py` | `save_themes` 落库前调用 `_ensure_sector_bound` 强制 fallback（决策点 2·C·A） |
| `tools/backfill_theme_sector_code.py` | **新增 CLI**，回填存量 67 题材 |

**回填效果**：
- 67 题材 → **65 个成功**（97%），剩 2 个真无解（"美伊局势缓和"、"金刚石/散热" 字典确实没对应板块）
- ths 概念新增后，**4 个原 MISS 被救回**：化肥、脑机接口(×2)、中东冲突相关

### 2.3 算法层（Phase C）

| SQL | 变更 |
|------|------|
| `get_template_eval` | `MAX(stock_weighted_pct) → MAX(sector_pct)`；`AVG(d1) → SUM(d1*\|strength\|)/SUM(\|strength\|)`，仅 `strength > 0` 参与 |
| `get_report_eval` | 同上 |
| `get_theme_eval_for_report` | `MAX(stock_weighted_pct) → MAX(sector_pct)`，对齐第 1 层口径；输出加 `sector_match_conf` |

**全量重打分**：
- 备份 → 清空 → `rescore_range(20260427, 20260528, days_back=5)`
- **447 题材 / 433 成功 / 1280 对全 OK / 71.5 秒**
- 备份文件 `.huiye/_backup_theme_prediction_scores_20260528-114053.csv`（145 KB）

### 2.4 GUI 层（Phase D）

`gui/pages/prompt_eval_page.py` 的 `_append_theme_child` 加 4 类角标：

| 角标 | 触发条件 | 含义 |
|------|---------|------|
| 🐻 | `strength_score < 0` | 看空题材，**不参与报告级加权** |
| ⚪ | `strength_score == 0` | 中性，**不参与报告级加权** |
| ⚠ | `sector_match_conf < 0.5` | 弱匹配，D+N 仅供参考 |
| 🚫 | `sector_ts_code IS NULL` | 字典无板块，D+N 永远空 |

每个角标都挂 tooltip，hover 题材名 / 板块列即可看说明。

CSV 导出新增 `sector_match_conf` 字段。

## 四、回滚指引

1. 还原 `services/scoring/scoring_service.py` 三个 SQL 到 git HEAD
2. 用备份恢复打分表：
   ```sql

   -- 从 .huiye/_backup_theme_prediction_scores_20260528-114053.csv 导入
   ```

3. GUI 角标 + tooltip 不影响数据，可保留
