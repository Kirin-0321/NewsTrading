# α+N 列改造上线（评估页 D+N → α+N / D/α+N）

**上线时间**：2026-05-28 22:00
**主人决策时间**：2026-05-28 21:55（确认下方双值「+2.50% / +1.20%」紧凑显示 + 标的级也显示 D/α + 原 α / α-1 列保留）
**实施人**：辉夜
**关联代码**：`services/scoring/scoring_service.py`、`gui/pages/prompt_eval_page.py`

---

## 一、需求与动机

| 项 | 内容 |
|---|---|
| 痛点 | 大盘整体涨/跌时，原始 D+N 看不出"是题材自己强 vs 还是水涨船高"，需要剔除大盘基准 |
| 解决思路 | 单日 α+N = D+N − 当天中证1000 涨跌幅，与原 D+N 同基础逐日剔除 |
| 与现有 α / α-1 关系 | **并列展示，不替换**——原 α（5 天均值/上证综指）和 α-1（D+2~D+5 均值/中证1000）保留 |

口径与 [α-1 指标上线](./05-28-1850-α-1指标上线.md) 一致，都用中证1000 作小盘股基准；
不同的是 α+N 是**逐日单点值**（每个 D+N 对应一个 α+N），α-1 是 D+2~D+5 的 4 天均值。

---

## 二、口径定义（按层级）

| 层级 | API | D+N 基础 | α+N 计算 |
|---|---|---|---|
| 模板级（上方表） | `get_template_eval` | sector_pct（板块涨幅） | 加权 SUM(\|strength\|·(sector−zz1000)) / SUM(\|strength\|)，仅 strength>0 |
| 报告级（下方报告父行） | `get_report_eval` | theme_pct（板块 0.6 + 标的均值 0.4） | 加权 SUM(\|strength\|·(theme−zz1000)) / SUM(\|strength\|)，仅 strength>0 |
| 题材级（下方题材子行） | `get_theme_eval_for_report` | sector_pct | sector_pct − benchmark_zz1000_pct（逐日） |
| 标的级（下方标的孙行） | `get_stock_scores_for_theme` | pct_chg（个股涨跌幅） | pct_chg − benchmark_zz1000_pct（按 score_date join） |

**关键设计**：

- α+N 与 D+N **使用同基础**——题材级 α+N 不用 theme_pct（与 D+N 错位）而用 sector_pct，与该层 D+N 一致
- 标的层 zz1000 借同 (theme_id, score_date) 的 `theme_prediction_scores` 行 join 取，**theme_stock_scores 表不冗余存 zz1000**
- AVG/SUM 的 NULL 兜底保持原行为：基准列缺失则该 (theme,N) 的 α+N 整体不参与聚合

## 三、改动清单

| Phase | 文件 | 改动 |
|---|---|---|
| 1 SQL | `services/scoring/scoring_service.py` | 4 处 SQL 都加 `a1~a5` 字段：① `get_template_eval` per_theme CTE 加 sector−zz1000 透视 + 外层 `a_n_avg` 加权聚合（5 列）；② `get_report_eval` per_theme CTE 加 theme−zz1000 透视 + 外层 `a_n_avg` 加权聚合（5 列）；③ `get_theme_eval_for_report` per_theme_scores CTE 加 sector−zz1000 透视 + 外层 SELECT 直透（5 列）；④ `get_stock_scores_for_theme` per_stock_pivot LEFT JOIN tps + pct_chg−zz1000 透视 + 外层 SELECT 直透（5 列） |
| 2 GUI 上表 | `gui/pages/prompt_eval_page.py` | `_TPL_COLS` 列名 D+1~D+5 → **α+1~α+5**（列宽 75 不变）；`_render_template_table` 渲染从 `d_n_avg` 改读 `a_n_avg`；染色 / 排序辅助槽逻辑沿用（值变了但 c_idx 不变）；CSV [模板汇总] section 5 列改写 `a_n_avg` |
| 3 GUI 下表 | `gui/pages/prompt_eval_page.py` | `_TREE_COLS` 列名 D+1~D+5 → **D/α+1~D/α+5**（列宽 75 → 120 容纳双值）；新增 `_fmt_pct_dual(d, a)` 工具函数；3 处渲染（`_render_tree_top_level` / `_append_theme_child` / `_append_stock_child`）的 5 个单元格改读双字段；染色 / 排序辅助槽继续按 D 值（保持原视觉/排序行为） |
| 4 GUI 标的 | `gui/pages/prompt_eval_page.py` | `_append_stock_child` 5 列单元格也用双值；α / α-1 列继续 "—" 占位（标的层无聚合 α 概念） |
| 5 CSV | `gui/pages/prompt_eval_page.py` | 4 个 section 都补 a_n 字段：[模板汇总] 5 列替换为 a_n_avg；[报告级] 加 5 列 a_n_avg；[题材级] 加 5 列 a_n；[标的级] 加 5 列 a_n_pct |
| 6 docstring | `gui/pages/prompt_eval_page.py` 头注释 + `scoring_service.py` Returns 字段表 | 同步注释新字段语义 + UI 布局图更新 |
