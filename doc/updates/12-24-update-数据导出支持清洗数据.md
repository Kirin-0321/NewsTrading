# 更新日志 - 数据导出支持清洗数据

## 版本：v1.1
**发布日期：2025-12-23**

---

## 🎯 功能概述

数据导出功能新增**清洗数据导出**支持，用户可以选择导出经过AI筛选的高价值新闻。

---

## ✨ 新增功能

### 1. 数据来源选择

**UI位置：** 数据导出页面 → 导出参数 → 数据来源

**选项：**
- ⚪ **原始数据 (data/raw)** - 默认选项，导出爬取的原始新闻
- ⚪ **清洗后数据 (data/cleaned)** - 新增选项，导出AI筛选后的新闻

**说明：**
- 点选单选按钮切换数据源
- 原始数据：读取所有 `.json` 文件
- 清洗数据：仅读取 `_clear.json` 文件（不读取 `_removed.json`）

---

### 2. 清洗数据支持

**功能特性：**
- ✅ 自动合并所有 `_clear.json` 文件
- ✅ 按时间范围筛选新闻
- ✅ 自动去重（基于标题+时间）
- ✅ 保持时间排序
- ✅ 支持 JSON/Markdown/TXT 三种格式导出

**数据结构处理：**
```json
// 清洗数据结构（自动识别）
{
  "metadata": {
    "type": "cleaned_single",
    "kept_count": 1039,
    ...
  },
  "news": [...]  // ← 提取这部分
}
```

---

### 3. 文件命名规则

#### 原始数据导出（保持不变）

```
      ├── 12-19_13_12-23_20_summary.md
      └── 12-19_13_12-23_20_titles.txt
```

#### 清洗数据导出（新增后缀）
```
data/exports/
  └── export_12-19_13_12-23_20_cleaned/
      ├── 12-19_13_12-23_20_cleaned.json
      ├── 12-19_13_12-23_20_cleaned_summary.md
```

**命名规则：**
- 目录名后缀：`_cleaned`
- 文件名后缀：`_cleaned`
- 便于区分不同数据源的导出结果

## 🔧 技术实现

### 修改文件
- `gui/pages/export_page.py`

### 修改内容

#### 1. 导入模块
```python
from PyQt5.QtWidgets import (..., QRadioButton, QButtonGroup)
```

#### 2. UI添加数据源选择
```python
# 数据来源选择
source_layout = QHBoxLayout()
source_layout.addWidget(QLabel("数据来源:"))

self.source_group = QButtonGroup()
self.raw_radio = QRadioButton("原始数据 (data/raw)")
self.cleaned_radio = QRadioButton("清洗后数据 (data/cleaned)")
self.raw_radio.setChecked(True)

self.source_group.addButton(self.raw_radio)
self.source_group.addButton(self.cleaned_radio)
```

#### 3. 修改 load_and_merge_json()
```python
# 根据选择确定数据源目录和文件模式
if self.cleaned_radio.isChecked():
    source_dir = 'data/cleaned'
    file_pattern = '_clear.json'  # 只读取_clear文件
else:
    source_dir = 'data/raw'
    file_pattern = '.json'  # 所有json文件

# 处理不同的JSON结构
if isinstance(data, dict) and 'metadata' in data and 'news' in data:
    news_list = data['news']  # 清洗数据结构
elif isinstance(data, list):
    news_list = data  # 原始列表结构
else:
    news_list = data.get('news', [])  # 原始字典结构
```

#### 4. 修改文件名生成
```python
# 确定文件名后缀
if self.cleaned_radio.isChecked():
    suffix = "_cleaned"
else:
    suffix = ""

export_name = f"export_{start.strftime('%m-%d_%H')}_{end.strftime('%m-%d_%H')}{suffix}"
filename_base = f"{start.strftime('%m-%d_%H')}_{end.strftime('%m-%d_%H')}{suffix}"
```

#### 5. 优化提示信息
```python
# 成功提示
data_source = "清洗后数据（AI筛选）" if self.cleaned_radio.isChecked() else "原始数据"
success_msg = f"导出完成！\n\n数据来源: {data_source}\n..."

# Markdown头部
content.append(f"\n**数据来源**: {data_source}")
```
