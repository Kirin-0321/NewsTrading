# 任务流功能说明

## 📌 功能概述

任务流是一个自动化工作流系统，可以自动执行多个步骤的复杂任务，支持定时执行和手动触发。

---

## 🎯 核心特性

### 1️⃣ 自动化工作流
- ✅ 支持多步骤任务串联执行
- ✅ 自动文件传递和数据流转
- ✅ 完整的错误处理和日志记录
- ✅ 执行历史和统计信息

### 2️⃣ 执行方式
- ✅ **定时执行**：设定时间自动运行
- ✅ **手动执行**：点击按钮立即执行
- ✅ **参数可调**：支持自定义执行参数

### 3️⃣ 独立模块化
- ✅ Python类 + JSON配置
- ✅ 调用现有接口
- ✅ 删除不影响系统稳定性

## 🚀 第一个任务流：每日新闻分析流程

### 功能说明

自动执行完整的新闻分析流程：

```
爬取新闻 → 清洗数据 → 导出数据 → AI分析
```

### 执行步骤

| 步骤 | 动作 | 说明 |
|------|------|------|
| 1 | 爬取新闻 | 使用爬虫获取最新新闻，支持自动停止 |
| 2 | 清洗数据 | 使用AI过滤无关新闻 |
| 3 | 导出数据 | 导出为Markdown格式 |
| 4 | AI分析 | 使用短线模板进行分析 |

### 默认参数

```json
{
  "crawler": {
    "scroll_times": 36,
    "wait_seconds": 6,
    "auto_stop": true
  },
  "cleaner": {
    "ai_provider": "deepseek",
    "batch_size": 500
  },
  "export": {
    "source": "cleaned",
    "format": "markdown",
    "time_range_hours": 24
  },
  "analyzer": {
    "template": "short_term",
    "auto_sectors": true,
    "auto_stocks": true,
    "summary_mode": "auto"
  }
}
```

## 💻 使用方法

### 1️⃣ 打开任务流管理

1. 启动程序：`python main.py`
2. 进入"定时任务"页面
3. 切换到"🔄 任务流"选项卡

### 2️⃣ 查看任务流列表

界面显示：
- ✅ 任务流名称和描述
- ✅ 执行时间设置
- ✅ 运行统计（次数、成功率）
- ✅ 最近执行状态

### 3️⃣ 手动执行任务流

1. 点击"立即执行"按钮
2. 配置执行参数（或使用默认配置）
3. 配置盘后总结：
   - **自动模式**：自动读取前日盘后总结
   - **手动模式**：选择指定文件
4. 点击"立即执行"
5. 等待执行完成（显示进度对话框）

### 4️⃣ 查看执行详情

点击"详情"按钮查看：
- 📊 执行统计信息
- ⚙️ 执行步骤配置
- 📈 历史执行记录

### 5️⃣ 查看执行日志

点击"日志"按钮查看：
- 📋 完整的执行日志
- ⏱️ 每步骤的耗时
- ❌ 错误信息（如果有）

### 6️⃣ 启用/禁用任务流

点击"ON/OFF"按钮切换任务流的启用状态

## ⚙️ 配置说明

### 任务流配置文件

位置：`workflows/configs/daily_news_flow.json`

### 主要配置项

#### 1. 基本信息
```json
{
  "workflow_id": "daily_news_flow",
  "name": "每日新闻分析流程",
  "description": "自动执行爬取、清洗、导出、AI分析的完整流程",
  "enabled": true
}
```

#### 2. 定时设置
```json
{
  "schedule": {
    "enabled": true,
    "time": "09:00",
    "description": "每天早上9点自动执行"
  }
}
```

#### 3. 执行参数
```json
{
  "params": {
    "crawler": {
      "scroll_times": 36,       // 滚动次数
      "wait_seconds": 6,         // 等待秒数
      "auto_stop": true          // 自动停止
    },
    "cleaner": {
      "ai_provider": "deepseek", // AI服务商
      "batch_size": 500          // 批量大小
    },
    "export": {
      "source": "cleaned",       // 数据源
      "format": "markdown",      // 导出格式
      "time_range_hours": 24     // 时间范围（小时）
    },
    "analyzer": {
      "template": "short_term",  // 分析模板
      "auto_sectors": true,      // 自动板块数
      "auto_stocks": true,       // 自动股票数
      "summary_mode": "auto",    // 盘后总结模式
      "summary_file": ""         // 手动指定文件
    }
  }
}
```

#### 4. 错误处理
```json
{
  "error_handling": {
    "on_step_error": "abort",   // abort: 停止, continue: 继续
    "retry_times": 0,            // 重试次数
    "retry_interval": 60         // 重试间隔（秒）
  }
}
```

#### 5. 历史记录（自动更新）
```json
{
  "history": {
    "last_run": "2025-12-26 09:00:00",
    "last_status": "success",
    "last_error": null,
    "last_duration": 420.5,
    "total_runs": 15,
    "success_count": 14,
    "failure_count": 1
  }
}
```

## 🔧 开发指南

### 创建新的任务流

#### 1. 创建Python类

在 `workflows/` 目录下创建新文件（例如 `my_workflow.py`）：

```python
from .base import WorkflowBase

class MyWorkflow(WorkflowBase):
    """我的任务流"""
    
    workflow_id = "my_workflow"
    name = "我的任务流"
    description = "描述你的任务流"
    
    def execute(self, params):
        """执行任务流"""
        results = {}
        
        # Step 1: 第一步
        self.log("Step 1: 开始第一步...")
        # ... 你的代码 ...
        results['step1_result'] = "结果"
        self.log("Step 1: ✓ 完成")
        
        # Step 2: 第二步
        self.log("Step 2: 开始第二步...")
        # ... 你的代码 ...
        results['step2_result'] = "结果"
        self.log("Step 2: ✓ 完成")
        
        return results
```

#### 2. 创建配置文件

在 `workflows/configs/` 目录下创建JSON文件（例如 `my_workflow.json`）：

```json
{
  "workflow_id": "my_workflow",
  "name": "我的任务流",
  "description": "描述你的任务流",
  "enabled": true,
  "schedule": {
    "enabled": false,
    "time": "10:00"
  },
  "params": {
    "param1": "value1",
    "param2": "value2"
  },
  "history": {
    "last_run": null,
    "last_status": null,
    "total_runs": 0,
    "success_count": 0,
    "failure_count": 0
  }
}
```

#### 3. 重启程序

重启程序后，新任务流会自动加载并出现在列表中。

## 📝 使用技巧

### 1️⃣ 盘后总结的两种模式

#### 自动模式
- 自动读取 `盘后总结/前一天日期.md`
- 适合定时执行
- 例如：今天12-26，自动读取 `盘后总结/2025_12_25.md`

#### 手动模式
- 在执行对话框中手动选择文件
- 适合立即执行时指定特定日期的总结
- 可以选择任意日期的盘后总结文件

### 2️⃣ 参数调整建议

#### 爬取新闻
- **滚动次数**：默认36次，可根据需求调整
- **自动停止**：建议保持启用，避免重复数据

#### AI清洗
- **批量大小**：500条是平衡点
  - 太小：调用次数多，慢
  - 太大：可能超过token限制

#### 分析参数
- **自动板块数/股票数**：建议保持启用
- **分析模板**：
  - `short_term`：短线交易
  - 其他模板根据需要选择

### 3️⃣ 日志查看技巧

- 最新日志始终保存在 `latest.log`
- 历史日志按时间戳命名
- 可以在GUI中选择不同日期的日志查看

## ⚠️ 注意事项

### 1. 执行时间

单次完整流程预计耗时：**5-10分钟**
- 爬取：2-3分钟
- 清洗：1-2分钟
- 导出：几秒钟
- 分析：2-5分钟

### 2. Token消耗

每次执行会消耗token：
- 清洗：约10K-30K tokens
- 分析：约15K-50K tokens

### 3. 错误处理

- 任何步骤失败会中止整个流程
- 错误信息记录在日志中
- 可在日志中查看详细堆栈信息

### 4. 文件输出

执行完成后会生成以下文件：
- `data/raw/12-26-09_new.json` - 爬取的原始数据
- `data/cleaned/12-26-09_clear.json` - 清洗后的数据
- `data/exports/12-26-09_workflow_export.md` - 导出的Markdown
- `data/analysis/analysis_2025-12-26_workflow.md` - 分析结果

## 🐛 故障排查

### 问题1：任务流无法加载

**症状**：任务流列表为空

**解决方法**：
1. 检查 `workflows/configs/` 目录是否存在
2. 检查配置文件格式是否正确
3. 查看终端错误信息

### 问题2：执行失败

**症状**：显示"执行失败"

**解决方法**：
1. 点击"日志"按钮查看详细错误
2. 检查各个模块是否正常工作
3. 确认AI服务商配置正确

### 问题3：找不到盘后总结

**症状**：日志中显示"未找到盘后总结文件"

**解决方法**：
1. 检查 `盘后总结/` 目录
2. 确认文件命名格式：`YYYY_MM_DD.md`
3. 或使用手动模式指定文件
