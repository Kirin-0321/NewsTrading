# 提示词更新 - 短线交易模板优化

## 📅 更新时间
2025-12-24

## 🎯 更新目标
将短线交易提示词从简单的"题材炒作"模式升级为专业的"市场结构分析 + 次日策略推演"模式。

---

## 📊 核心改进

### 1. **分析框架升级** ⭐

| 维度 | 旧版本 | 新版本 |
|------|--------|--------|
| **定位** | 短线题材炒作 | **资深短线策略分析师** |
| **分析方法** | 简单筛选热点新闻 | **三段式逻辑推演框架** |
| **输出内容** | 题材 + 股票推荐 | **市场诊断 + 持续性推演 + 次日策略** |
| **可执行性** | 中 | **高（具体操作预案）** |

---

### 2. **三段式分析框架** 🔍

#### **第一段：信息提炼与结构化**
```
├─ 量能与情绪指标
│  ├─ 成交额对比
│  ├─ 涨跌停数据
│  └─ 主力资金流向
├─ 最强与最弱方向
│  ├─ 领涨板块识别
│  └─ 风险板块标注
└─ 市场结构分析
   ├─ 最高标位置
   ├─ 连板梯队完整度
   └─ 新强势板块涌现
```

#### **第二段：综合分析与次日推演**
```
├─ 市场生态诊断
│  ├─ 指数个股同步/分化
│  └─ 情绪判断（亢奋/谨慎/退潮）
├─ 主线持续性推演
│  ├─ 驱动逻辑可持续性
│  ├─ 龙头晋级预判
│  └─ 风险板块影响评估
└─ 资金流向推演
   └─ 潜在轮动方向识别
```

#### **第三段：次日策略与观察清单**
```
├─ 总体策略定调
├─ 核心观察锚点
│  ├─ 情绪锚点（最高标）
│  ├─ 板块锚点（龙头晋级）
│  └─ 资金锚点（北向/主力）
├─ 操作预案
│  ├─ 情景A：情绪修复
│  ├─ 情景B：分歧加剧
│  └─ 情景C：新主线启动
└─ 风险提示
```

---

## 🆚 前后对比

### 旧版本输出结构
```markdown
📊 高热度新闻筛选
├─ 政策突发
├─ 技术爆点
└─ 事件驱动

💡 题材机会分析
├─ 题材1: XXX
│   ├─ 炒作逻辑
│   ├─ 市场情绪
│   ├─ 推荐标的（3-5只）
│   ├─ 进出场点位
│   └─ 目标位
└─ 题材2...

⚡ 交易策略
├─ 优先级排序
└─ 止盈止损
```

**问题**：
- ❌ 缺少市场整体环境判断
- ❌ 没有主线持续性分析
- ❌ 缺少次日具体操作预案
- ❌ 风险提示不够具体

---

### 新版本输出结构
```markdown
📊 一、信息提炼与结构化
├─ 市场环境：成交额X亿，情绪XXX
├─ 最强方向：XXX板块（涨停XX家）
├─ 最弱方向：XXX板块（回调）
└─ 市场结构：
    ├─ 最高标：XX（X板）
    ├─ 完整梯队：XXX题材
    └─ 新强势：XXX板块

🔍 二、综合分析与次日推演
├─ 市场诊断：分化/同步，情绪XXX期
├─ 主线推演：
│   ├─ 领涨板块XXX：逻辑可持续，次日预计继续走强
│   ├─ 梯队完整的XXX：新主线潜力高，关注龙头晋级
│   └─ 高位风险XXX：可能拖累情绪
└─ 资金流向：预计流入XXX板块（低位+逻辑）

🎯 三、次日策略与观察清单
├─ 总体定调：谨慎参与，重点观察XXX
├─ 核心锚点：
│   ├─ 情绪锚点：XXX（最高标）能否晋级
│   ├─ 板块锚点：XXX龙头的表现
│   └─ 资金锚点：北向资金流向
├─ 操作预案：
│   ├─ 情景A（情绪修复）：参与XXX板块龙头，XX价位进场
│   ├─ 情景B（分歧加剧）：观望为主，避开XXX
│   └─ 情景C（新主线）：低吸XXX板块
└─ 风险提示：警惕XXX板块高位回落连锁反应
```

**优势**：
- ✅ 市场整体环境清晰
- ✅ 主线持续性有逻辑推演
- ✅ 次日策略具体可执行
- ✅ 多情景预案应对变化
- ✅ 风险提示具体明确

---

## 💡 核心改进点

### 1. **强调逻辑推演**
```
旧版："XXX板块有短线机会"
新版："XXX板块涨停XX家，核心驱动是政策XXX，逻辑可持续性强，
      预计次日龙头XXX能晋级XX板，跟风活跃，建议关注"
```

### 2. **基于文本推理**
```
旧版：直接推荐标的
新版：从新闻中提取"量能、涨停数、连板梯队"等信息，
      基于这些信息进行市场诊断和推演
```

### 3. **次日可执行策略**
```
旧版："短期目标位XX元"
新版："情景A：情绪修复时，XX价位参与XXX标的，止损XX
      情景B：分歧加剧时，观望为主，避开高位XXX
      情景C：新主线启动时，低吸XXX板块前排"
```

### 4. **三层观察锚点**
```
情绪锚点 → 最高标表现（判断整体情绪）
板块锚点 → 龙头晋级情况（判断主线强度）
资金锚点 → 北向/主力流向（判断资金态度）
```

## 🎯 适用场景

### 新版本特别适合：

1. **盘后复盘** ✅
   - 梳理今日市场结构
   - 推演明日走势
   - 制定操作计划

2. **结合盘后总结使用** ⭐
   - 如果提供了盘后总结，AI会从中提取关键信息
   - 分析连板梯队、涨停家数、资金流向等
   - 给出更精准的次日策略

3. **波动市场** 📈📉
   - 市场分化时，识别主线和轮动方向
   - 情绪转折时，提供多情景应对预案
   - 高位风险时，明确风险提示

---

## 📝 使用建议

### 1. **提供盘后总结获得最佳效果**
```
在"盘后总结"输入框中提供：
- 今日市场概况（成交额、涨跌停数）
- 连板梯队情况
- 主要板块表现
- 资金流向观察

AI会结合新闻和盘后总结进行综合分析
```

### 2. **使用"自动"模式**
```
板块数：自动
推荐股数：自动

AI会根据市场分化程度灵活调整：
- 主线明确 → 3-4个板块
- 分化明显 → 5-6个板块
```

### 3. **关注三大锚点**
```
次日开盘后，重点观察AI指出的：
- 情绪锚点（最高标）
- 板块锚点（龙头）
- 资金锚点（流向）

根据锚点表现，执行相应的操作预案
```
