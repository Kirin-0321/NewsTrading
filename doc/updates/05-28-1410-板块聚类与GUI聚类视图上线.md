## 三、聚类工作流（两阶段 LLM）

### 3.1 一阶段：保守拆分

```bash
python tools/cluster_sectors.py cluster --apply
```

- 输入：1510 个板块 → DeepSeek V4 Pro 单次（max_tokens 拉满 384K）
- 输出：1229 组（Prompt 加 `rationale` 字段强制 chain-of-thought，质量闸门 4 层防偷懒）
- 自动消歧：63 个跨源同名组（如「家用电器（DC）」/「家用电器（THS）」）

### 3.2 二阶段：近义合并

```bash
python tools/cluster_sectors.py merge-pass --dry-run   # 预览
python tools/cluster_sectors.py merge-pass --apply     # 落库
```

- 输入：1229 组的 name 清单 → DeepSeek V4 Pro
- 输出：256 条合并 → **826 组**（人工剔除 F5G←5G 错合并）

## 四、中位算法

> 决策点 `median_def=lower_median`：n 个成员 ASC 排序后取第 `(n+1)/2` 项

| n | 取值 | 说明 |
|---|---|---|
| 1 | 第 1 项 | 唯一行 |
| 2 | 第 1 项 | 较小者 |
| 3 | 第 2 项 | 中间 |
| 4 | 第 2 项 | 排序后第二小 |
| 5 | 第 3 项 | 中间 |
| 6 | 第 3 项 | 排序后第三 |

实测验证（2026-05-27 数据）：

- 「白酒 ×6」中位 = `BK0477.DC 酿酒概念 +1.44%`（[0.55, 0.74, **1.44**, 3.14, 3.14, 3.37]）
- 「电力 ×4」中位 = `BK1374.DC 风力发电 +1.00%`（[0.95, **1.00**, 1.15, 2.94]）
- 「影视院线 ×4」中位 = `881274.TI +1.94%`（[1.25, **1.94**, 2.13, 2.38]）

## 五、GUI 截图说明

聚类后视图位置：盘后数据 → 板块 Tab → 视图 ComboBox 第 2 项「🎯 聚类后 ~815 组」。

- **顶层行**：组名 ×N + 中位涨幅（红/绿染色）+ 中位主力 + 中位代表板块的龙头股
- **子级行**：组内全部成员（×>1 时才有展开），中位代表前缀 ★ + 斜体
- **搜索框**：搜组名 → 整组显示；搜成员名/ts_code → 隐藏组下其他成员
- **tooltip**：顶层行 hover 第 2 列显示「组员数 + 中位代表 + 中位定义」
