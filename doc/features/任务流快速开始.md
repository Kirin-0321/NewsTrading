# 任务流快速开始指南

## 🚀 5分钟上手

### 第一步：启动程序
```bash
python main.py
```

### 第二步：进入任务流管理
1. 点击 **定时任务** 标签
2. 切换到 **任务流** 子标签

### 第三步：查看任务流
你会看到两个任务流：

| 任务流 | 说明 | 推荐场景 |
|--------|------|----------|
| 每日新闻分析流程 | 4步流程（无合并去重） | 每天执行一次 |
| **增强版新闻分析流程** | 5步流程（含合并去重） | 一天多次执行 ⭐️ |

### 第四步：执行任务流
1. 找到 "增强版新闻分析流程"
2. 点击 **立即执行** 按钮
3. 在弹出的对话框中：
   - 可以修改参数（建议首次使用默认值）
   - 点击 **开始执行**
4. 观察实时日志输出
5. 等待执行完成（约2-5分钟）

### 第五步：查看结果
执行完成后，可以在以下位置找到生成的文件：

```
data/
├── raw/                    # 原始爬取数据
├── cleaned/                # 清洗和合并后的数据
├── exports/                # 导出的Markdown文件
└── AI_analysis/            # AI分析报告 ⭐️
```

重点查看：`data/AI_analysis/` 目录下的最新分析报告

## 🔄 设置定时自动执行

### 方法1：在GUI中设置（推荐）
1. 点击任务流的 **详情** 按钮
2. 找到 "定时设置" 部分
3. 勾选 "启用定时"
4. 设置执行时间（如：09:30）
5. 保存

### 方法2：修改配置文件
编辑 `workflows/configs/enhanced_news_flow.json`：

```json
{
  "schedule": {
    "enabled": true,
    "time": "09:30",
    "description": "每天早上9点30分自动执行"
  }
}
```

**注意**：定时任务需要程序保持运行状态才能生效。

## 📊 参数调优建议

### 如果你希望：

**获取更多新闻**
```json
"crawler": {
  "scroll_times": 60,      // 增加滚动次数
  "wait_seconds": 8,       // 增加等待时间
  "auto_stop": false       // 关闭自动停止
}
```

**更快速执行**
```json
"crawler": {
  "scroll_times": 20,      // 减少滚动次数
  "wait_seconds": 4,       // 减少等待时间
  "auto_stop": true        // 启用自动停止
}
```

**分析更多历史数据**
```json
"export": {
  "time_range_hours": 48   // 导出最近48小时
}
```

**合并所有历史文件**
```json
"merger": {
  "mode": "all"            // 合并所有文件（耗时较长）
}
```

## ❓ 常见问题快速解决

### Q1: 执行失败了怎么办？
1. 点击 **日志** 按钮查看详细错误
2. 检查是否配置了AI API密钥
3. 检查网络连接是否正常

### Q2: 如何只执行特定步骤？
任务流不支持单步执行，但你可以：
- **爬取新闻**: 爬虫管理页面
- **清洗数据**: 新闻清洗页面
- **合并去重**: 数据管理页面
- **导出数据**: 数据导出页面
- **AI分析**: AI分析页面

### Q3: 合并去重后文件变少了？
这是正常的，系统会：
1. 合并多个清洗文件
2. 全局去重（10分钟窗口+60%相似度）
3. 按天分割保存
4. 删除旧文件

### Q4: 如何修改去重规则？
编辑 `core/semantic_dedup.py` 中的默认参数：
```python
default_deduplicator = SemanticDeduplicator(
    time_window_minutes=10,  # 时间窗口
    similarity_threshold=0.6  # 相似度阈值
)
```

## 🎯 使用场景示例

### 场景1：早盘前准备
**目标**：每天早上9:30分析昨晚和今早的新闻

**配置**：
```json
{
  "schedule": {
    "enabled": true,
    "time": "09:30"
  },
  "params": {
    "export": {
      "time_range_hours": 12  // 导出最近12小时
    }
  }
}
```

### 场景2：盘中追踪
**目标**：每隔2小时执行一次，追踪最新消息

**方案**：
- 使用系统定时任务功能设置多个执行时间
- 或使用外部定时工具（如Windows任务计划程序）

### 场景3：盘后全面分析
**目标**：每天收盘后分析全天新闻

**配置**：
```json
{
  "schedule": {
    "enabled": true,
    "time": "15:30"  // 收盘后
  },
  "params": {
    "merger": {
      "mode": "recent",
      "recent_count": 10  // 合并今天的所有文件
    },
    "export": {
      "time_range_hours": 24  // 导出全天新闻
    }
  }
}
```
