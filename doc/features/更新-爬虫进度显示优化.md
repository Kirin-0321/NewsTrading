# 更新 - 爬虫进度显示优化

## 📅 更新时间
2025-12-24

## 🎯 更新内容

在爬虫滚动进度中**添加最新新闻时间显示**，方便用户实时判断爬取进度。

---

## ✨ 新增功能

### 进度信息增强

**修改前**：
```
[11:58:30] [1/36] 第 1/36 次滚动 | 新增: +100 | 总计: 131
[11:58:37] [2/36] 第 2/36 次滚动 | 新增: +100 | 总计: 231
```

**修改后**：
```
[11:58:30] [1/36] 第 1/36 次滚动 | 新增: +100 | 总计: 131 | 最远: 2025-12-24 11:58:15
[11:58:37] [2/36] 第 2/36 次滚动 | 新增: +100 | 总计: 231 | 最远: 2025-12-24 11:20:30
[11:58:43] [3/36] 第 3/36 次滚动 | 新增: +100 | 总计: 331 | 最远: 2025-12-24 10:45:20
```

**说明**：
- "最远"显示的是**当前已爬取的最旧新闻的时间**
- 随着滚动，时间会**逐渐往前推进**（越来越早）
- 可以看出爬取的深度进展

## 🔧 技术实现

### 核心代码

**文件**：`core/news_crawler_scroll.py` (第174-198行)

```python
# 获取最新一条新闻的时间
latest_time_str = ""
if news_items_list:
    first_item = news_items_list[0]
    ptime_elem = first_item.find('span', class_='ptime')
    if ptime_elem:
        try:
            timestamp = int(ptime_elem.text)
            latest_dt = datetime.fromtimestamp(timestamp)
            latest_time_str = latest_dt.strftime('%Y-%m-%d %H:%M:%S')
        except:
            latest_time_str = ""

# 报告进度
msg = f"第 {i+1}/{scroll_times} 次滚动 | 新增: +{new_items} | 总计: {current_count}"
if latest_time_str:
    msg += f" | 最新: {latest_time_str}"
```

## 📊 信息完整性

### 完整的进度信息

现在每次滚动显示：

| 信息项 | 示例 | 说明 |
|--------|------|------|
| **时间戳** | `[11:58:30]` | 爬取操作的时间 |
| **进度** | `[1/36]` | 当前/总滚动次数 |
| **新增** | `新增: +100` | 本次新增新闻数 |
| **总计** | `总计: 131` | 累计爬取新闻数 |
| **最远** | `最远: 2025-12-24 11:58:15` | **新增**：最旧一条新闻的时间（爬取深度） |
| **状态** | `✓` or `⚠` | 是否有新增 |

## 📝 注意事项

1. **时间格式**：`YYYY-MM-DD HH:MM:SS`
2. **时区**：使用系统本地时区
3. **异常处理**：如果无法解析时间，不显示该字段
4. **性能影响**：几乎无性能影响（仅提取第一条新闻）
