# 📤 导出功能优化 - 默认位置和一键导出

## ✨ 新增功能

### 1. 默认导出位置
- 📁 设置默认导出目录：`data/exports`
- 💾 界面显示完整路径，方便用户查找
- 🔄 自动创建目录（如果不存在）

### 2. 一键导出按钮
- ⚡ 绿色"一键导出"按钮
- 🚀 无需选择位置，直接导出到默认目录
- ⏱️ 快速便捷，适合日常使用

### 3. 选择位置导出
- 📁 蓝色"选择位置导出"按钮
- 🎯 可自定义保存位置
- 📂 默认打开 `data/exports` 目录

---

## 🎨 界面布局

### 按钮排列
```
┌─────────────────────────────────────────────┐

└─────────────────────────────────────────────┘

💾 默认导出位置: F:\爬虫\data\exports
```

|------|------|------|----------|
| ⚡ 一键导出 | 绿色 | 直接导出到默认位置 | 日常快速导出 |
| 📁 选择位置导出 | 蓝色 | 选择自定义位置 | 需要特定位置 |

## 📝 使用方法

### 方式1: 一键导出（推荐）
```
1. 选择时间范围
2. 选择导出格式（JSON、MD、TXT）
3. 点击 "⚡ 一键导出"
4. 完成！文件保存在 data/exports
```

**优势**:
- ✅ 快速方便
- ✅ 无需选择位置
- ✅ 文件统一管理

---

### 方式2: 选择位置导出
```
1. 选择时间范围
2. 选择导出格式
3. 点击 "📁 选择位置导出"
4. 选择保存目录
5. 确认导出
```

**优势**:
- ✅ 自定义位置
- ✅ 灵活控制
- ✅ 特殊需求

## 🎯 典型场景

### 场景1: 日常导出
```
需求: 每天导出最新24小时数据
操作: 
  1. 设置时间范围（最近24小时）
  2. 点击 "⚡ 一键导出"
  3. 完成！
优势: 快速，文件统一在 data/exports
```

### 场景2: 备份到U盘
```
需求: 将数据备份到外部存储
操作:
  1. 设置时间范围
  2. 点击 "📁 选择位置导出"
  3. 选择U盘目录（如 E:\backup）
  4. 确认导出
优势: 灵活选择存储位置
```

### 场景3: 分享给同事
```
需求: 导出数据分享
操作:
  1. 使用一键导出
  2. 进入 data/exports
  3. 压缩目录发送
优势: 位置固定，便于查找
```

## 🔍 技术细节

### 默认路径处理
```python
default_dir = os.path.abspath('data/exports')
os.makedirs(default_dir, exist_ok=True)
```

**特点**:
- 使用绝对路径
- 自动创建目录
- 跨平台兼容

### 对话框初始目录
```python
save_dir = QFileDialog.getExistingDirectory(
    self,
    "选择导出目录",
    default_dir,  # ← 默认打开此目录
    QFileDialog.ShowDirsOnly
)
```

**优势**:
- 用户选择位置时默认在 data/exports
- 快速切换到其他位置
- 提升用户体验
