# AI分析 - 智能数量决策功能说明

## 📌 功能概述

**问题**：以前需要手动设置分析多少个板块、每个板块推荐多少只股票。但不同的新闻数据情况不同，有时设置太多会显得臃肿，设置太少又会遗漏机会。

**解决方案**：现在新增了"自动"选项，让AI根据新闻数据的实际情况，智能决定：
- ✅ 应该分析多少个板块
- ✅ 每个板块应该推荐多少只股票

---

## 🎯 功能特点

### 1️⃣ 板块数量自动决策

**传统模式**：固定分析6个板块
- ❌ 新闻质量高时，6个板块不够
- ❌ 新闻质量低时，6个板块太多，会出现凑数的板块

**自动模式**：AI根据实际情况决定
- ✅ 重点新闻多时，可能分析8-10个板块
- ✅ 重点新闻少时，可能只分析3-5个板块
- ✅ 宁缺毋滥，只推荐有充分依据的板块

---

### 2️⃣ 推荐股数自动决策

**传统模式**：每个板块固定推荐5只股票
- ❌ 有的板块龙头明显，5只太多
- ❌ 有的板块标的分散，5只不够

**自动模式**：AI根据每个板块的实际情况决定
- ✅ 龙头集中的板块，可能只推荐3-4只
- ✅ 标的分散的板块，可能推荐6-8只
- ✅ 根据新闻支撑强度灵活调整

---

## 💻 使用方法

### 界面操作

1. **打开AI分析页面**

2. **找到"分析参数"部分**，你会看到：

```
🎯 分析参数

最多板块数: [6] ☑ 自动
每板块推荐股数: [5] ☑ 自动
```

3. **勾选"自动"复选框**：
   - ✅ 勾选后，数字输入框会变灰（禁用）
   - ✅ AI将根据新闻数据自动决定数量
   - ✅ 可以只勾选一个，或两个都勾选

4. **点击"开始分析"**

## 🤖 AI决策逻辑

### 板块数量决策

AI会综合考虑：

1. **重点新闻数量**
   - 10条以下：3-5个板块
   - 10-30条：5-7个板块
   - 30条以上：7-10个板块

2. **行业分布**
   - 集中在少数行业：减少板块数
   - 分散在多个行业：增加板块数

3. **催化强度**
   - 有多个重磅政策/突破：增加板块数
   - 大多是常规动态：减少板块数

4. **新闻时效性**
   - 近期热点集中：增加板块数
   - 分散在较长时间：减少板块数

---

### 推荐股数决策

AI会根据每个板块的具体情况：

1. **龙头集中度**
   - 龙头明显（如茅台、宁德）：推荐3-4只
   - 群雄逐鹿（如半导体设备）：推荐6-8只

2. **新闻支撑**
   - 某个公司被多次提及：必选
   - 只有行业利好无个股新闻：推荐龙头

3. **市场地位**
   - 行业前3名：优先推荐
   - 细分领域龙头：补充推荐

4. **投资价值**
   - 有明确催化剂：增加推荐数
   - 仅跟随行情：减少推荐数

## 🔍 常见问题

### Q1：自动模式会不会推荐太多或太少？

**A**：不会。AI有内置的合理范围：
- 板块数量：3-10个
- 推荐股数：3-10只/板块

并且AI会优先考虑质量，宁缺毋滥。

---

### Q2：如果我不满意AI的数量选择怎么办？

**A**：可以取消"自动"，手动设置你想要的数量，重新分析。

---

### Q3：自动模式会增加Token消耗吗？

**A**：不会。自动模式只是在提示词中给AI更多决策权，不会额外增加输入或输出。

---

**A**：AI通过以下信息综合判断：
1. 提示词中的指导（"根据新闻数据的实际情况自动确定"）
2. 新闻数据的实际内容
3. 自身的投资分析经验
4. 建议的合理范围（3-10个）

## 📚 技术实现

### 提示词设计

自动模式时，提示词会这样描述：

```
【分析要求】
1. 识别 根据新闻数据的实际情况自动确定（建议3-10个） 个最有潜力的投资板块
2. 每个板块需包含：
   - 核心催化剂（来自重点新闻）
   - 投资逻辑链条
   - 根据每个板块的实际情况自动确定（建议3-10只） 只龙头股票推荐
   ...
```

AI看到这样的描述，就知道自己有决策权。

---

### 参数传递

```python
# 用户勾选"自动"
max_sectors = 'auto'
stocks_per_sector = 'auto'

# 传递给AI
analyzer.analyze(
    file_path=file_path,
    max_sectors=max_sectors,  # 'auto' 或 整数
    stocks_per_sector=stocks_per_sector  # 'auto' 或 整数
)
```

---

### 智能转换

在构建提示词时，系统会自动转换：

```python
if max_sectors == 'auto':
    max_sectors_text = "根据新闻数据的实际情况自动确定（建议3-10个）"
else:
    max_sectors_text = str(max_sectors)  # 例如 "6"
```

AI看到的就是自然语言描述，而非具体数字。
