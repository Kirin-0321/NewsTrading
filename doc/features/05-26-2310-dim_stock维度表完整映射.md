## 改动

### 新增

- **`services/market/tushare_fetcher.py` 新增方法**
  - `fetch_dim_stock_full(*, include_delisted=False) -> dict` —
    调 Tushare `stock_basic` 接口，1 次 API 拉全市场约 5400 只在市股
    （可选 +1 次拉退市股）；返回 `{"L": n, "D": n, "total": n}`
  - `_ingest_dim_stock(rows) -> int` — 把 stock_basic 行 INSERT OR REPLACE
    入 `dim_stock`；字段对齐 schema：`ts_code, name, market, industry, list_date`

- **`tools/dim_stock_sync.py`（新 CLI 入口）**
  - `python tools/dim_stock_sync.py` — 首次 / 月度同步在市股
  - `--include-delisted` — 同时拉退市股（历史 ts_code 也能反查）
  - `--dry-run` — 预览不真拉
  - 输出对比 before/after 行数

- **`services/market/service.py` `MarketSummaryService._ensure_dim_stock_initialized()`**
  - `build()` 在调 fetcher 之前调用一次
  - 若 `dim_stock.COUNT(*) == 0` → 自动 `fetcher.fetch_dim_stock_full()` 兜底
  - 失败时只 warn，不打断主流程（GUI 仍能走 raw_json fallback）
  - 让首次用户开箱即用，无需手动跑 CLI
