# 题材预测页 · 板块走势 Tab

## 一、是什么

在「🎯 题材预测库」页面的题材详情区，**「📊 打分明细」Tab 右边新增一个「📈 板块走势」Tab**。

选中一个题材后，该 Tab 展示该题材所属板块（`theme_predictions.sector_ts_code`）的完整历史每日表现：

- **顶部迷你折线图**（自绘 sparkline）：板块每日 `pct_chg`，正红负绿，0 基线灰虚线，
  报告日 `report_date` 位置画一条橙色竖线，**D+1 ~ D+5 评估窗口**用浅黄色背景带标出
- **底部明细表**：4 列 ——
  | 列 | 含义 |
  |---|---|
  | 交易日 | YYYY-MM-DD |
  | 偏移 | 相对报告日，如 `D`、`D+3`、`D-7` |
  | 涨跌幅 % | 正红负绿 |
  | 主力净流入（亿） | 正红负绿 |
  | 当日排名 | `fact_sector_daily.rank_today` |

表格按交易日**降序**（最新在前），报告日 D 那行底色浅橙、D+1~D+5 行底色浅黄，与折线图对齐。

## 二、为什么做

- 「打分明细」Tab 暂未上线（依赖 plan M3 打分系统），中间留了大段空 UI
- 选中一个题材后，主人之前**没有快捷入口看板块本身这几天到底走得怎么样**——
  题材表只显示当日涨跌幅一个数字，无法判断"刚出公告时板块已经涨过了 vs 报告捕捉到拐点"
- 板块每日行情数据 `fact_sector_daily` 早就同步好了（506 个板块 / 15146 行），就缺一个查询/展示入口

## 五、CLI 入口示例

```bash
# 全量取酿酒概念（升序）
python tools/sector_daily_query.py BK0477.DC

# 限定区间 + 降序输出
python tools/sector_daily_query.py BK0477.DC \
    --start 20260101 --end 20260527 --order desc

# JSON 输出（字段对齐 SectorDailyHistory.to_dict）
python tools/sector_daily_query.py BK0477.DC --json --limit 5
```

退出码：`0` 成功 / `1` 该板块无数据 / `2` 参数错误。

## 六、边界与降级（四种状态，22:05 修订）

`SectorDailyHistory` 增加 `in_dim`/`idx_type` 字段后，service 层能区分以下四种状态：

| 状态 | `sector_ts_code` | `in_dim` | `count` | GUI 表现 |
|---|---|---|---|---|
| **无关联板块** | 空串 / None | — | — | "题材「xxx」未匹配到板块代码，无走势可展示" |
| **板块代码不存在** | 有但 dim 找不到 | `False` | 0 | 红字提示"板块代码不存在于 dim_sector 字典"，建议补跑 `_fetch_sector_dict` |
| **数据源未覆盖**（典型行业板块） | dim 有名字 | `True` | 0 | 顶栏正常显示板块名 + 类型标签；解释"`moneyflow_ind_dc` 只覆盖概念板块，行业板块需后续补抓 `moneyflow_ind_ths` / `moneyflow_ind_sw`" |
| **正常有数据**（概念板块） | dim 有名字 | `True` | > 0 | sparkline + 明细表正常渲染，顶栏显示蓝色 `[概念板块]` 标签 |

其他边界：

| 场景 | 行为 |
|---|---|
| 报告日不在 rows 范围内 | 不画橙色竖线、不画评估窗口背景；表格也不染色 |
| 个别交易日 `pct_chg IS NULL` | 折线图自动断段；表格那行显示 `—` |
| market.db 损坏 / 不可读 | service 层 log warning 返回空 history；GUI 显示「板块行情查询失败：…」 |

## 六·B、数据源覆盖痛点（22:05 发现）

`fact_sector_daily` 当前**只覆盖 506 / 1033 = 49% 的板块**：

- ✅ **概念板块**（约 506 个）：Tushare `moneyflow_ind_dc`（东方财富资金流）正常返回
- ❌ **行业板块**（约 527 个，如稀土 / 钴 / 镍 / 锂 / 钨 / 被动元件 / 磁性材料 / 综合Ⅲ 等）：
  `moneyflow_ind_dc` 接口**不返这类板块**

主人的实际案例：选中题材「MLCC/被动元件」（板块代码 `BK1339.DC`），
但 `BK1339.DC` 是"行业板块"，`fact_sector_daily` 全无数据，因此 Tab 显示空。

修复路径（**未开工**，主人定优先级）：

1. 补抓 Tushare `moneyflow_ind_ths`（同花顺行业板块资金流）
2. 或抓 `moneyflow_ind_sw`（申万行业资金流）
3. 入库后字段对齐 `fact_sector_daily` 现有 schema，
   `sector_daily_sync.py` 新增 sync hook，GUI 端无需任何改动自动有数据

## 七、未来扩展（不做）
