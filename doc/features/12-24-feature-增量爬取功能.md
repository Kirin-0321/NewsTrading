# 爬虫 - 增量爬取功能说明

## 📅 实现时间
2025-12-24

## 🎯 功能概述

新增**智能增量爬取**功能，自动检测数据库中已有的新闻，避免重复爬取，提高效率并自动去重。

---

## ✨ 核心特性

### 1. **自动停止检测**
- ✅ 爬取前自动读取数据库最新新闻
- ✅ 爬取时检测是否遇到已有新闻
- ✅ 两种停止条件：
  - 标题完全匹配
  - 时间到达边界（当前新闻时间 ≤ 最新新闻时间）

### 2. **智能去重**
- ✅ 内部去重：爬取结果自身去重（语义去重：10分钟 + 60%）
- ✅ 数据库去重：与所有已存在新闻比对去重
- ✅ 保留新增部分：只保存真正的新增新闻

### 3. **独立文件保存**
- ✅ 不修改原有文件
- ✅ 新命名规则：`MM-DD-HH_MM-DD-HH_new.json`
- ✅ 便于手动查看和AI清洗

---

## 🖥️ 使用方法

### 界面选项

![爬虫页面](image)

在爬虫管理界面，新增**"自动停止"**复选框：

```
参数设置：
├─ 滚动次数: 36 次
├─ 等待时间: 6 秒
├─ 无数据停止: 3 次
├─ [✓] 无头模式
└─ [✓] 自动停止  ← 新增（默认开启）
```

**说明**：
- ✅ 勾选：启用增量爬取模式
- ❌ 不勾选：传统完整爬取模式

## 📊 工作流程

### 完整流程图

```
开始爬取
    ↓
检查"自动停止"选项
    ↓
[已开启]
    ↓
读取数据库最新新闻
    ├─ 有最新新闻 → 记录时间和标题
    └─ 数据库为空 → 完整爬取模式
    ↓
执行爬取（正常流程）
    ↓
爬取完成
    ↓
增量处理
    ├─ 读取所有爬取的新闻
    ├─ 检测停止点（标题或时间匹配）
    ├─ 截断已有新闻之后的部分
    └─ 保留新增新闻
    ↓
去重处理
    ├─ 内部去重（语义去重）
    ├─ 与数据库比对去重
    └─ 提取新增新闻
    ↓
保存文件（新命名规则）
    ↓
删除临时文件
    ↓
完成
```

### 文件命名规则

```
格式: MM-DD-HH_MM-DD-HH_new.json
示例: 12-24-09_12-24-10_new.json

说明:
- 前半部分: 起始时间（月-日-时）
- 后半部分: 结束时间（月-日-时）
- _new: 标识这是增量爬取的新增文件
```

### 场景1：日常增量更新 ⭐ **推荐**

```
  - Token消耗少
```

## 💡 技术细节

### 停止条件判断

```python
# 条件1: 标题匹配
if current_title == latest_title:
    停止爬取

# 条件2: 时间边界
if current_time <= latest_time:
    停止爬取
```

### 去重策略

```
第1层: 爬取结果内部去重
  └─ 语义去重（10分钟窗口 + 60%相似度）

第2层: 与数据库比对去重
  └─ 加载所有历史新闻
  └─ 整体语义去重
  └─ 提取新增部分（通过ID比对）
```

### 文件命名逻辑

```python
start_time = news_list[-1]['datetime']  # 最早新闻
end_time = news_list[0]['datetime']     # 最新新闻

filename = f"{start_dt:%m-%d-%H}_{end_dt:%m-%d-%H}_new.json"
```

## ⚠️ 注意事项

### 1. **时间格式**
- 新闻必须有有效的时间字段（`datetime` 或 `time`）
- 时间格式：`YYYY-MM-DD HH:MM:SS`

### 2. **数据库要求**
- 数据库文件位于 `data/raw/*.json`
- 新闻列表按时间倒序排列（最新在前）

### 3. **去重准确性**
- 依赖语义去重算法（60%相似度）
- 极少数情况可能漏删或误删
- 建议定期手动检查

### 4. **文件管理**
- 增量文件（`*_new.json`）可独立使用
- 可手动合并到主数据库
- 定期清理旧的增量文件

## 🔧 故障排查

### 问题1：无法停止，爬取了很多旧新闻
**原因**：数据库最新新闻时间格式异常
**解决**：检查数据库文件的时间字段格式

### 问题2：显示"数据库为空"但实际有文件
**原因**：文件格式不正确或读取失败
**解决**：
1. 检查 `data/raw/` 目录下的JSON文件
2. 确认文件有 `news` 字段
3. 查看错误日志

### 问题3：去重后没有新闻
**原因**：爬取的都是重复新闻
**解决**：
1. 确认网站确实有新闻更新
2. 增加滚动次数
3. 尝试完整爬取模式
