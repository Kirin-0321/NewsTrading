# 增强版任务流使用说明

## 📋 功能概述

**增强版新闻分析流程** (`enhanced_news_flow`) 是在原有任务流基础上新增了**数据合并去重**步骤的完整自动化流程。

### 与原任务流的对比

| 任务流 | 流程步骤 | 适用场景 |
|--------|---------|----------|
| **daily_news_flow**<br>(原版) | 爬取 → 清洗 → 导出 → AI分析 | 单次快速分析 |
| **enhanced_news_flow**<br>(增强版) | 爬取 → 清洗 → **合并去重** → 导出 → AI分析 | 多次累积数据，需要全局去重 |

## 🔄 完整流程

### Step 1: 爬取新闻
- 自动滚动加载新闻页面
- 支持自动停止（避免重复爬取）
- 生成原始新闻文件

### Step 2: 清洗数据
- 使用AI智能过滤无关新闻
- 只保留有投资价值的信息
- 生成清洗后的文件 (`_clear.json`)

### Step 3: 合并去重 ⭐️ 新增
- **功能**: 合并多个清洗文件，全局去重
- **算法**: 语义去重（10分钟时间窗口 + 60%相似度）
- **输出**: 按天分割的清洗文件（如 `01-08_clear.json`）

**去重规则**:
- 在10分钟时间窗口内
- 标题相似度 ≥ 60%
- 则判定为重复，保留较早的新闻

**合并模式**:
- `recent`: 合并最近N个文件（默认5个）
- `all`: 合并所有清洗文件
- `time_range`: 合并指定时间范围内的文件

### Step 4: 导出数据
- 从合并去重后的数据导出
- 支持时间范围筛选（默认24小时）
- 导出为Markdown格式

### Step 5: AI分析
- 使用指定模板进行分析
- 自动读取前日盘后总结
- 生成投资分析报告

## 📝 使用方法

### 方法1: 在GUI中使用

1. 打开程序，进入 **定时任务** 页面
2. 切换到 **任务流** 标签
3. 找到 "增强版新闻分析流程"
4. 点击 **立即执行** 按钮
5. 在弹出的对话框中配置参数（或使用默认值）
6. 点击 **开始执行**
7. 查看实时日志和执行结果

### 方法2: 通过代码执行

```python
from core.workflow_engine import get_workflow_engine

# 获取引擎
engine = get_workflow_engine()

# 执行任务流（使用配置文件中的默认参数）
result = engine.execute_workflow('enhanced_news_flow')

# 或者自定义参数执行
params = {
    'crawler': {
        'scroll_times': 50,
        'wait_seconds': 8,
        'auto_stop': True
    },
    'cleaner': {
        'ai_provider': 'deepseek',
        'batch_size': 100
    },
    'merger': {
        'mode': 'recent',  # 合并模式
        'recent_count': 10  # 合并最近10个文件
    },
    'export': {
        'time_range_hours': 48  # 导出最近48小时
    },
    'analyzer': {
        'template': 'short_term'
    }
}
result = engine.execute_workflow('enhanced_news_flow', params)

print(result)
```

### 方法3: 设置定时执行

1. 在GUI中找到该任务流
2. 点击 **详情** 按钮
3. 在 "定时设置" 中配置执行时间
4. 启用定时执行
5. 保存配置

配置文件位置: `workflows/configs/enhanced_news_flow.json`

```json
{
  "schedule": {
    "enabled": true,
    "time": "09:30",
    "description": "每天早上9点30分自动执行"
  }
}
```

## ⚙️ 参数配置说明

### 爬虫参数 (crawler)
- `scroll_times`: 滚动次数，默认36次
- `wait_seconds`: 每次滚动等待秒数，默认6秒
- `auto_stop`: 是否自动停止（遇到已爬取的新闻就停止），默认true

### 清洗参数 (cleaner)
- `ai_provider`: AI服务商，可选 `deepseek`、`openai`、`volcengine`
- `batch_size`: 每批处理数量，默认100条

### 合并去重参数 (merger) ⭐️ 新增
- `mode`: 合并模式
  - `recent`: 合并最近N个文件
  - `all`: 合并所有文件
  - `time_range`: 按时间范围合并
- `recent_count`: 当mode为recent时，合并最近几个文件，默认5
- `time_range_hours`: 当mode为time_range时，合并最近几小时内的文件

### 导出参数 (export)
- `source`: 数据源，默认 `cleaned`（清洗后的数据）
- `format`: 导出格式，默认 `markdown`
- `time_range_hours`: 导出时间范围（小时），默认24小时

### 分析参数 (analyzer)
- `template`: 分析模板
  - `short_term`: 短线策略
  - `custom_6`: 自定义模板6
  - 其他自定义模板
- `summary_mode`: 盘后总结模式
  - `auto`: 自动读取前日盘后总结
  - `none`: 不使用盘后总结
  - 其他: 手动指定文件
- `summary_file`: 手动指定盘后总结文件路径

**注意**: `auto_sectors` 和 `auto_stocks` 参数已弃用，系统会自动处理板块和股票数量。

## ⚠️ 注意事项

1. **首次使用建议**
   - 先手动执行一次，确认流程正常
   - 检查各步骤生成的文件
   - 根据实际情况调整参数

2. **合并去重说明**
   - 合并会删除旧的清洗文件，只保留按天分割的文件
   - 建议定期备份重要数据
   - `mode=all` 会合并所有历史文件，耗时较长

3. **AI分析注意**
   - 确保配置了AI服务商的API密钥
   - 分析大量新闻会消耗较多tokens
   - 建议使用时间范围限制导出的新闻数量

4. **盘后总结路径**
   - 系统会自动查找 `分析数据/盘后总结/{月}.{日}/` 目录
   - 如果没有找到，分析时不会使用盘后总结
   - 也可以手动指定盘后总结文件

## 🆚 选择哪个任务流？

### 使用 `daily_news_flow`（原版）适合：
- ✅ 每天固定时间执行一次
- ✅ 不需要累积历史数据
- ✅ 追求执行速度

### 使用 `enhanced_news_flow`（增强版）适合：
- ✅ 一天内多次执行
- ✅ 需要合并多天的数据
- ✅ 需要全局去重
- ✅ 数据管理需求较高

## 🐛 常见问题

**Q: 为什么没有生成合并后的文件？**
A: 检查 `data/cleaned` 目录是否有 `_clear.json` 文件，至少需要1个文件才能合并。

**Q: 合并去重后文件数量变少了？**
A: 这是正常的，系统会将多个文件合并并按天分割，同时删除旧文件。

**Q: 如何查看去重了哪些新闻？**
A: 查看执行日志，日志中会详细记录去重前后的数量。

**Q: 可以只执行某一步吗？**
A: 目前不支持，但可以在各个页面单独执行对应功能（如单独执行清洗、导出等）。

**Q: 如何设置循环自动运行？**
A: 在配置文件中设置 `schedule` 字段，或在GUI的任务流详情中配置定时执行时间。
