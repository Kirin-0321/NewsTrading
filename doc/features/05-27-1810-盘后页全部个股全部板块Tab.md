## 一、为什么做

之前盘后数据页 **9 个 Tab** 全部聚焦在「重点结构化指标」（涨停、连板、龙虎榜、Top 10 板块、异动时间线…），但 **缺一个「兜底浏览」入口**：

- 主人想看某只股今天涨多少 / 收盘多少 → 现状只能去 ai_inference 或者翻 fact_stock_daily 命令行
- 主人想看某板块今天涨幅 / 主力净流入 → 只有 Top 20 + Bottom 10 总共 30 个，剩下 ~450 个板块查不到
- Phase 1 已经把 `fact_stock_daily`（5500 只 × 30 天）+ `fact_sector_daily`（486 个 × 30+ 天）入库，**数据底座完全就绪**，没用上等于浪费

## 四、调用链

```
MarketSummaryPage._populate_all()
  ├─ _populate_sectors(summary)
  │    └─ 按 sector_mode_combo.currentData()：
  │         ├─ "split" → stack idx=0：
  │         │      ├─ Top 20 = backend_sectors_top + helper 补 11~20
  │         │      └─ Bottom 10 = query_sectors_extended(0, 10).bottom
  │         └─ "all"   → stack idx=1：
  │                ├─ rows = query_all_sectors(td)  ~480 行
  │                └─ 注入后端催化：cat_map[ts_code] → catalysts/source/match
  └─ _populate_all_stocks(summary)
       └─ query_all_stocks(td)
            ├─ SQL: fact_stock_daily LEFT JOIN dim_stock LEFT JOIN fact_limit_stock
            ├─ 23ms 拿 5504 条
            └─ GUI 填表 ~180ms（含 setSortingEnabled 默认排序）

GUI 交互信号
  ├─ sector_mode_combo.currentIndexChanged → _on_sector_mode_changed → 重渲染 + 切 stack
  ├─ sector_search.textChanged             → _apply_sector_search_filter (板块名/ts_code 双路过滤；ts_code 存 col=1 UserRole)
  └─ stock_search.textChanged              → _apply_stock_search_filter
```

## 五、性能实测

| 项 | 行数 | 耗时 | 备注 |
|---|---|---|---|
| `query_all_stocks` SQL | 5504 | **23ms** | LEFT JOIN dim_stock + fact_limit_stock |
| `query_all_sectors` SQL | 486 | **33ms** | 含 486 次 _derive_sector_leaders LIKE |
| `_populate_all_stocks` 填表 | 5504 | **180ms** | setUpdatesEnabled(False) 包围 + 排序 |
| 搜索过滤（5504 → 1 行） | — | < 50ms | setRowHidden 遍历 |
| 模式切换（top20 → bottom10 → all） | 20→10→486 | < 100ms | 单次重查 + 重填 |

主流配置（i7 + SSD）下，**全流程主人无感**。

## 六、CLI 入口（CLI-First 纪律）

按 `.cursor/rules/cli-first-development.mdc`，新增 services / helper 公开方法必须有 CLI 入口。本次新增：

| CLI | 用途 |
|---|---|
| `tools/query_all_stocks.py` | 命令行查全 A 股，支持 `--filter U/Z/D` `--search` `--top` `--json` |
| `tools/query_all_sectors.py` | 命令行查全板块，支持 `--top` `--bottom` `--search` `--json` |
| `tools/test_query_all.py` | 5 用例回归（基本功能 / 排序 / 涨停标 / 边界） |

示例::

```bash
# 看今天涨幅 Top 5
python tools/query_all_stocks.py --date 20260526 --top 5

# 只看涨停股
python tools/query_all_stocks.py --date 20260526 --filter U

# 搜索茅台
python tools/query_all_stocks.py --date 20260526 --search 茅台 --json

# 全部板块 Top 20
python tools/query_all_sectors.py --date 20260526 --top 20
```
