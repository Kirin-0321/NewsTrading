## 🎯 去重策略

### 唯一标识
```python
unique_key = f"{datetime}_{title}"
```

### 去重逻辑
```
新闻A: "2025-12-20 10:00:00_美联储加息"
新闻B: "2025-12-20 10:00:00_美联储加息"  ← 重复，丢弃
新闻C: "2025-12-20 10:01:00_美联储加息"  ← 时间不同，保留
新闻D: "2025-12-20 10:00:00_欧洲央行"    ← 标题不同，保留
```

**原则**: 相同时间相同标题 = 重复

## 💻 技术细节

### 核心算法
```python
# 1. 按日期分组
for news in all_news:
    date = news['datetime'].split()[0]
    news_by_date[date][unique_key] = news

# 2. 去重（使用OrderedDict）
unique_key = f"{datetime}_{title}"

# 3. 排序
news_list.sort(key=lambda x: x['timestamp'], reverse=True)

# 4. 保存
output_data = {
    "date": date,
    "merge_time": now,
    "total": len(news_list),
    "news": news_list
}
```

## 🔄 与导出功能的区别

### 合并去重（数据管理）
```
目的: 整理原始数据
位置: data/raw/
操作: 就地合并，删除旧文件
结果: 每天一个JSON
```

### 数据导出
```
目的: 按需生成报告
位置: data/exports/
操作: 读取原始数据，生成新文件
结果: 可选格式（JSON/MD/TXT）
```

**区别**: 
- 合并去重 = 整理原始数据
- 数据导出 = 生成报告文件
