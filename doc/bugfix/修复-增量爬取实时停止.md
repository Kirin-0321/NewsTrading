# 修复 - 增量爬取实时停止功能

## 📅 修复时间
2025-12-24

## 🐛 问题描述

增量爬取功能未能实时停止，爬取会一直滚动到设定的次数才结束。

### 问题现象

```
数据库最新: 2025-12-24 09:15:09

[6/36] 最远: 2025-12-24 09:45:07  ← 已超过边界
[7/36] 最远: 2025-12-24 09:45:07
[8/36] 最远: 2025-12-24 09:22:27  ← 已超过边界
[9/36] 最远: 2025-12-24 09:03:59  ← 继续爬取（不应该）
[10/36] 最远: 2025-12-24 08:45:15 ← 继续爬取（不应该）
[11/36] 最远: 2025-12-24 08:22:14 ← 继续爬取（不应该）
```

**预期行为**：在第8或第9次滚动时，检测到时间边界应立即停止。

---

## 🔍 问题根因

### 1. 缺少实时检测逻辑

原代码只在爬取**完成后**的处理阶段检测重复，而不是在爬取**过程中**实时检测。

**问题代码位置**：
- `gui/workers/crawler_worker.py` 的 `_process_incremental()` 方法
- 只在爬取后才检查，无法提前停止

### 2. 检测逻辑分离

- **爬取逻辑**：`core/news_crawler_scroll.py` 负责滚动爬取
- **去重逻辑**：`gui/workers/crawler_worker.py` 负责后处理

这种分离导致无法在爬取过程中实时判断。

---

## ✅ 修复方案

### 核心改动：在爬取过程中实时检测

#### 1. 在 `GuZhangNewsCrawlerScroll` 添加自动停止参数

**文件**：`core/news_crawler_scroll.py`

```python
class GuZhangNewsCrawlerScroll:
    def __init__(self, ...):
        # ... 原有代码 ...
        
        # 增量爬取参数
        self.auto_stop_enabled = False
        self.db_latest_time = None
        self.db_latest_title = None
    
    def set_auto_stop(self, enabled, latest_time, latest_title):
        """设置自动停止参数"""
        self.auto_stop_enabled = enabled
        self.db_latest_time = latest_time
        self.db_latest_title = latest_title
```

#### 2. 在滚动循环中实时检测

**文件**：`core/news_crawler_scroll.py` (第183-235行)

```python
for i in range(scroll_times):
    # ... 滚动并获取新闻 ...
    
    # 获取最旧新闻的时间
    oldest_timestamp = None
    should_stop = False
    
    if news_items_list:
        last_item = news_items_list[-1]
        oldest_timestamp = int(last_item.find('span', class_='ptime').text)
        
        # 【核心】实时检测是否应该停止
        if self.auto_stop_enabled and self.db_latest_time:
            # 检查标题匹配
            for item in news_items_list:
                title = item.find('h2').text.strip()
                if title == self.db_latest_title:
                    print("[自动停止] 遇到已有新闻（标题匹配）")
                    should_stop = True
                    break
            
            # 检查时间边界
            if not should_stop and oldest_timestamp:
                db_timestamp = int(self.db_latest_time.timestamp())
                if oldest_timestamp <= db_timestamp:
                    print("[自动停止] 时间到达边界")
                    should_stop = True
    
    # 【核心】立即退出循环
    if should_stop:
        break
    
    # ... 继续滚动 ...
```

#### 3. 在 `NewsCrawler` 包装类中传递参数

**文件**：`core/news_crawler_scroll.py` (第844-920行)

```python
class NewsCrawler:
    def __init__(self):
        self.progress_callback = None
        self.crawler = None
        
        # 增量爬取参数
        self.auto_stop_enabled = False
        self.db_latest_time = None
        self.db_latest_title = None
    
    def set_auto_stop(self, enabled, latest_time, latest_title):
        """设置自动停止参数"""
        self.auto_stop_enabled = enabled
        self.db_latest_time = latest_time
        self.db_latest_title = latest_title
    
    def run(self, ...):
        # 创建爬虫实例
        self.crawler = GuZhangNewsCrawlerScroll(...)
        
        # 【核心】应用自动停止设置
        if self.auto_stop_enabled:
            self.crawler.set_auto_stop(
                self.auto_stop_enabled,
                self.db_latest_time,
                self.db_latest_title
            )
        
        # 执行爬取
        result = self.crawler.crawl(...)
```

#### 4. 在 Worker 中调用设置

**文件**：`gui/workers/crawler_worker.py` (第48-62行)

```python
# 创建爬虫实例
crawler = NewsCrawler()

# 【核心】如果启用自动停止，设置参数
if self.auto_stop and latest_news:
    latest_time = parse_news_time(latest_news)
    latest_title = latest_news.get('title', '')
    crawler.set_auto_stop(True, latest_time, latest_title)
    self.log_message.emit(f"[增量模式] 已启用实时自动停止")

# 运行爬虫
files = crawler.run(...)
```

## 📝 技术细节

### 检测时机

- **每次滚动后**：立即检查最旧新闻
- **双重检测**：标题匹配 OR 时间边界
- **提前退出**：`break` 跳出滚动循环

### 参数传递链路

```
crawler_page.py (UI)
  ↓ auto_stop=True
crawler_worker.py (Worker Thread)
  ↓ crawler.set_auto_stop(True, time, title)
NewsCrawler (Wrapper)
  ↓ self.crawler.set_auto_stop(...)
GuZhangNewsCrawlerScroll (Core)
  ↓ 在滚动循环中检测
实时停止 ✅
```

### 边界判断逻辑

```python
# 条件1：标题完全匹配
if current_title == db_latest_title:
    stop = True

# 条件2：时间到达或超过边界
if current_timestamp <= db_timestamp:
    stop = True
```
