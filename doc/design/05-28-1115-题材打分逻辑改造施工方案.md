## 二、技术选型

| 项 | 选型 | 理由 |
|----|------|------|
| Tushare 接口 | `moneyflow_ind_dc` (新加 `content_type="行业"/"地域"`) + `moneyflow_ind_ths` | 决策点 1·D |
| dim_sector 扩展 | 加 ts_code 后缀 `.THS`（同花顺源），原 `UNIQUE(name, src)` 已支持同名共存 | 复用现有 schema |
| matcher 强化 | 现有 `_score_match` 加权重逻辑，**置信度阈值降到 0.3 + theme_keywords 参与匹配** | 现有 fuzzy match 框架够用 |
| 加权 SQL | `SUM(d_n × |strength|) / SUM(|strength|) WHERE strength > 0` | 决策点 3 |
| backfill 范围 | **30 天**（22 个交易日，约 ~88 次 API：22×2 dc 行业地域 + 22×2 ths 行业概念）| 评估窗口够用，避免一次性打爆 API 配额 |
| 重打分批次 | 380 题材 × D+1~D+5 ≈ 1900 行 scores，全量串行 ~5 分钟 | 一次性 run，不分批 |

### 3.3 关键接口签名

**matcher.py** 强化：

```python
def match_sector_ts_code(
    theme_name: str,
    *,
    theme_category: Optional[str] = None,        # 新增
    theme_keywords: Optional[List[str]] = None,  # 新增（题材关键词列表）
    force: bool = False,                          # 新增（True=强制返回最高 conf 哪怕<0.5）
    min_conf: float = 0.3,                        # 调低（原默认 0.5）
    sectors: Optional[List[Tuple[str, str, str]]] = None,  # 加 idx_type
) -> Tuple[Optional[str], float]:
    """改造点：
    1. 阈值 0.5 → 0.3（更宽松）
    2. force=True 时返回最高 conf 哪怕 < min_conf
    3. theme_keywords 参与匹配（每个 keyword 都对 sector.name 跑一次 _score_match）
    4. theme_category 用于"概念板块 vs 行业板块"打分加成
    5. 同名 .DC / .THS 选优：dc > ths（dc 数据更稳）
    """
```

**theme_store.save_themes** 改造：

```python
# 落库前对每个 theme：
if not theme.get("sector_ts_code"):
    code, conf = match_sector_ts_code(
        theme["theme_name"],
        theme_category=theme.get("theme_category"),
        theme_keywords=theme.get("keywords"),
        force=True,           # 强制必返回
    )
    theme["sector_ts_code"] = code
    theme["sector_match_conf"] = conf
```

**script_scorer.score_theme_on_date** 改造（题材级 D+N 不再用 stock_weighted_pct）：

```python
# stock_weighted_pct 保留写库（标的级展示用）
# 新增：score 主表的"题材级 D+N"逻辑下沉到 SQL 层（直接读 sector_pct）
# 也就是说 script_scorer 几乎不改，主要改 scoring_service 的 SQL
```

**scoring_service.get_report_eval** 改造（核心 SQL）：

```sql
-- 题材级 D+N 用 sector_pct 替换 stock_weighted_pct
-- 报告级用 |strength_score| 加权（仅 strength > 0）
WITH per_theme AS (
    SELECT
        tp.id AS theme_id,
        tp.report_path,
        tp.strength_score,
        MAX(CASE WHEN tps.days_offset=1 THEN tps.sector_pct END) AS d1,
        ...
    FROM theme_predictions tp
    LEFT JOIN theme_prediction_scores tps ON tps.theme_id = tp.id
    GROUP BY tp.id, tp.report_path, tp.strength_score
)
SELECT
    ar.id AS report_id,
    ar.report_date,
    ...
    -- 加权平均：仅 strength > 0 的题材参与
    SUM(CASE WHEN per_theme.strength_score > 0
             THEN per_theme.d1 * ABS(per_theme.strength_score) END)
        / NULLIF(SUM(CASE WHEN per_theme.strength_score > 0
                          THEN ABS(per_theme.strength_score) END), 0)
        AS d1_avg,
    ...
FROM ai_reports ar
LEFT JOIN per_theme ON per_theme.report_path = ar.file_path
...
```
