## 二、技术选型

| 维度 | 选择 | 理由 |
|------|------|------|
| GUI 控件 | `PyQt5.QtWidgets.QTreeWidget` | 原生支持多级展开 + setSortingEnabled + setItemWidget(按钮) |
| 排序粒度 | 重写 `__lt__` + 仅顶层 sortItems | QTreeWidget 默认全树递归排，子级要锁顺序需 hack |
| 子节点占位 | 加一个空 child 让 ▶ 出现，`itemExpanded` signal 时替换 | Qt 标准懒加载范式 |
| 数据访问 | 复用 `services/scoring/scoring_service.py` + 新增 2 API | 严格走 service 层，禁止 GUI 直接 SQL |
| CLI 入口 | `tools/query_eval.py` 追加 2 个 `--by` 子模式 | 不开新文件，复用现有 argparse |
| 测试 | `tools/test_scoring_eval.py` 追加 4 用例 | 与原 16 用例同夹具，沿用 `_PREFIX="TEST_EV_"` |

不引入新依赖；不改数据库 schema；不加索引。

## 三、接口签名（service 层）

### 3.1 `get_theme_eval_for_report(report_id, ...)`

```python
def get_theme_eval_for_report(
    report_id: int,
    *,
    hit_threshold_pct: float = DEFAULT_HIT_THRESHOLD_PCT,
) -> List[Dict]:
    """按 ai_reports.id 取该报告下每个题材的聚合打分。

    每行 1 个题材，已按 D+1~D+5 透视 + 跨 score_date 聚合。

    Args:
        report_id: ai_reports.id
        hit_threshold_pct: 透传给上层用（本身不参与查询）

    Returns:
        每行 dict（按 theme_id ASC 排序）::

            {
                "theme_id": 999,
                "theme_name": "人形机器人",
                "theme_category": "硬科技",
                "strength_score": 75,        # -100~+100
                "strength_level": "较强利多",
                "priority_rank": 1,
                "duration": "中线",
                "expectation_gap": "高",
                "is_cold": 0,
                "sector_ts_code": "BK0871.DC",
                "stocks_count": 6,           # theme_stocks 行数（懒加载用）
                "scored_pairs": 5,           # theme_prediction_scores 行数
                "d1_avg": ..., "d5_avg": ...,
                "alpha_avg": None,
                "hit_rate_avg": None,
                "direction_correct_rate": None,
                "sector_pct_avg": None,      # 板块涨跌幅均值
            }
    """
```

**SQL 草稿**：

```sql
WITH per_theme_scores AS (
    SELECT
        tps.theme_id,
        MAX(CASE WHEN tps.days_offset=1 THEN tps.stock_weighted_pct END) AS d1,
        MAX(CASE WHEN tps.days_offset=2 THEN tps.stock_weighted_pct END) AS d2,
        MAX(CASE WHEN tps.days_offset=3 THEN tps.stock_weighted_pct END) AS d3,
        MAX(CASE WHEN tps.days_offset=4 THEN tps.stock_weighted_pct END) AS d4,
        MAX(CASE WHEN tps.days_offset=5 THEN tps.stock_weighted_pct END) AS d5,
        AVG(tps.alpha) AS alpha_avg,
        AVG(tps.hit_rate) AS hit_rate_avg,
        AVG(CASE WHEN tps.direction_correct IS NOT NULL
                 THEN CAST(tps.direction_correct AS REAL) END) AS dir_rate,
        AVG(tps.sector_pct) AS sector_pct_avg,
        COUNT(tps.id) AS scored_pairs
    FROM theme_prediction_scores tps
    GROUP BY tps.theme_id
),
stock_count AS (
    SELECT theme_id, COUNT(*) AS n
    FROM theme_stocks
    GROUP BY theme_id
)
SELECT
    tp.id AS theme_id, tp.theme_name, tp.theme_category,
    tp.strength_score, tp.strength_level, tp.priority_rank,
    tp.duration, tp.expectation_gap, tp.is_cold,
    tp.sector_ts_code,
    COALESCE(sc.n, 0) AS stocks_count,
    COALESCE(pts.scored_pairs, 0) AS scored_pairs,
    pts.d1, pts.d2, pts.d3, pts.d4, pts.d5,
    pts.alpha_avg, pts.hit_rate_avg, pts.dir_rate AS direction_correct_rate,
    pts.sector_pct_avg
FROM ai_reports ar
INNER JOIN theme_predictions tp ON tp.report_path = ar.file_path
LEFT JOIN per_theme_scores pts ON pts.theme_id = tp.id
LEFT JOIN stock_count sc ON sc.theme_id = tp.id
WHERE ar.id = ?
ORDER BY tp.id ASC
```

### 3.2 `get_stock_scores_for_theme(theme_id)`

```python
def get_stock_scores_for_theme(theme_id: int) -> List[Dict]:
    """按 theme_id 取该题材下每只标的的逐日涨跌 + 命中标记。

    Returns:
        每行 dict（按 theme_stock_id ASC 排序）::

            {
                "theme_stock_id": 1234,
                "stock_name": "XX龙头",
                "stock_code": "600172",
                "normalized_code": "600172.SH",
                "role": "核心",
                "reason": "AI 给的理由",
                "d1_pct": 5.2, "d2_pct": ..., "d5_pct": ...,
                "d1_hit": 1, "d2_hit": 0, ..., "d5_hit": 1,
                "scored_days": 3,            # theme_stock_scores 行数
            }
    """
```

**SQL 草稿**：

```sql
WITH per_stock_pivot AS (
    SELECT
        tss.theme_stock_id,
        MAX(CASE WHEN tss.days_offset=1 THEN tss.pct_chg END) AS d1_pct,
        MAX(CASE WHEN tss.days_offset=2 THEN tss.pct_chg END) AS d2_pct,
        MAX(CASE WHEN tss.days_offset=3 THEN tss.pct_chg END) AS d3_pct,
        MAX(CASE WHEN tss.days_offset=4 THEN tss.pct_chg END) AS d4_pct,
        MAX(CASE WHEN tss.days_offset=5 THEN tss.pct_chg END) AS d5_pct,
        MAX(CASE WHEN tss.days_offset=1 THEN tss.is_hit END) AS d1_hit,
        MAX(CASE WHEN tss.days_offset=2 THEN tss.is_hit END) AS d2_hit,
        MAX(CASE WHEN tss.days_offset=3 THEN tss.is_hit END) AS d3_hit,
        MAX(CASE WHEN tss.days_offset=4 THEN tss.is_hit END) AS d4_hit,
        MAX(CASE WHEN tss.days_offset=5 THEN tss.is_hit END) AS d5_hit,
        COUNT(tss.id) AS scored_days
    FROM theme_stock_scores tss
    WHERE tss.theme_id = ?
    GROUP BY tss.theme_stock_id
)
SELECT
    ts.id AS theme_stock_id,
    ts.stock_name, ts.stock_code, ts.normalized_code,
    ts.role, ts.reason,
    psp.d1_pct, psp.d2_pct, psp.d3_pct, psp.d4_pct, psp.d5_pct,
    psp.d1_hit, psp.d2_hit, psp.d3_hit, psp.d4_hit, psp.d5_hit,
    COALESCE(psp.scored_days, 0) AS scored_days
FROM theme_stocks ts
LEFT JOIN per_stock_pivot psp ON psp.theme_stock_id = ts.id
WHERE ts.theme_id = ?
ORDER BY ts.id ASC
```

### 5.4 懒加载与排序

```python
class _NodeKind:
    REPORT = "report"
    THEME = "theme"
    STOCK = "stock"

# QTreeWidgetItem.data(0, Qt.UserRole) 存 dict:
#   {"kind": "report"|"theme"|"stock", "loaded": bool, "data": original_dict}

def _on_item_expanded(self, item: QTreeWidgetItem):
    payload = item.data(0, Qt.UserRole) or {}
    if payload.get("loaded"):
        return
    if payload.get("kind") == _NodeKind.REPORT:
        self._lazy_load_themes(item, payload["data"])
    elif payload.get("kind") == _NodeKind.THEME:
        self._lazy_load_stocks(item, payload["data"])
    payload["loaded"] = True
    item.setData(0, Qt.UserRole, payload)
```

**排序锁子级顺序**：

```python
class _ReportTreeItem(QTreeWidgetItem):
    """只让顶层报告参与排序；子级 __lt__ 永远返回 False（保插入序）。"""

    def __lt__(self, other):
        # 子级（题材/标的）保持原序
        if self.parent() is not None:
            return False
        # 顶层按当前点击的列做数值/字符串比较
        col = self.treeWidget().sortColumn()
        a = self.data(col, Qt.UserRole + 1)  # +1 存可比较的原始值
        b = other.data(col, Qt.UserRole + 1)
        if a is None and b is None:
            return False
        if a is None:
            return False  # NULL 末尾
        if b is None:
            return True
        return a < b
```

* 排序触发：`tree.setSortingEnabled(True)` + 默认按 _COL_NAME（报告日期）DESC
* 子级在 `_on_item_expanded` 时填，子级 `__lt__` 直接返回 False 锁定顺序
* `Qt.UserRole + 1` 存"可比较原始值"（float / int / str），避免字符串排序 "+5.20%" vs "+10.5%" 出错

### 5.5 染色

提取 `_paint_pct_cell(item, col, val)` 辅助方法：

* `val > 0` → 红
* `val < 0` → 绿
* `val is None` → 灰

题材级 / 标的级命中标记：✓ 浅红（#fff1f0）/ ✗ 浅绿（#f6ffed）

未打分行（📄 / 🎯）整行字色 #999。

### 5.6 CSV 导出改造

3 节扁平输出：

```csv
[报告级]
report_id, report_date, prompt_id, ..., d1_avg, ..., file_path
1, 20260522, custom_6, ..., 5.2, ..., data/AI_analysis/...

[题材级]
report_id, theme_id, theme_name, strength_level, ..., d1, ..., d5
1, 999, 人形机器人, 较强利多, ..., 8.0, ..., -12.0

[标的级]
theme_id, theme_stock_id, stock_name, normalized_code, role, d1_pct, ..., d5_hit
999, 1234, XX龙头, 600172.SH, 核心, 5.2, ..., 1
```

**导出策略**：导出时**强制全量加载**所有未展开的子节点（即调一遍 service 层），保证数据完整；GUI 显示走懒加载，导出走全量，互不干扰。

## 七、风险登记

| 风险 | 影响 | 应对 |
|------|------|------|
| QTreeWidget 排序默认全树递归，可能影响子级顺序 | 中 | 重写 `_ReportTreeItem.__lt__`：parent 非 None 时 return False |
| 懒加载首次展开慢（DB 冷启动）| 低 | service 层 SQL 都命中索引，单查询 < 100ms |
| 按钮控件 setItemWidget 在排序后丢失 | 中 | 排序结束后重绑：`tree.itemChanged` 时检查并补 setItemWidget |
| 列共享导致语义混淆 | 中 | 每行第一列加图标前缀（📄/🎯/📈），让主人一眼识别 |
| 导出 CSV 全量加载可能卡住 GUI | 低 | 数据量典型 < 200 节点，主线程跑 < 500ms 不卡顿 |
| `theme_stock_scores` 表为空时（标的层无打分）的退化态 | 低 | LEFT JOIN + COALESCE 0；GUI 显示 "—" |
