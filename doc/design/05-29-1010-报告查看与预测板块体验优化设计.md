# 块 A · 分析报告的查看与联动

## A1、是什么 / 现在为什么难受

主人每天会生成多份 AI 分析报告（日常分析 + 模板回测），它们既是一份份 Markdown 文稿，也在库里有索引。但**现在想"翻一份旧报告看正文"非常别扭**：

| # | 现状 | 难受在哪 |
|---|------|---------|
| A-1 | 报告分散在「AI 分析页 / 手动回测页 / 模板评估页 / 题材预测页 / 数据管理页」5 处，**没有统一的"报告浏览"入口** | 想翻历史报告无从下手，只能靠记忆找当时哪个页面生成的 |
| A-2 | **AI 分析页只显示流式纯文本**，看排版后的成品报告得另开外部编辑器（Typora） | 手动回测页明明能在页内直接看排版好的报告，AI 分析页却不行，体验两套 |
| A-3 | 评估页双击某份报告"联动跳转"时，**只带了"日期 + 模板"两个信息，没带具体是哪一份报告** | 同一天、同一个模板若跑了多份报告，跳过去后它们的题材**全混在一张表里**，只能靠"时间"列肉眼区分 |
| A-4 | 数据管理页里"分析报告"那一栏，**扫的目录和报告真实存放的位置对不上** | 数据管理页基本看不到真实报告；偶尔能看到的也是无排版纯文本，还被截断 |
| A-5 | "删报告"这件事散在 3 个页面各做各的 | 容易删了文件没删索引、或删了索引没删文件，留下"孤儿" |

## A2、做完后主人能怎么爽（预期效果）

按三档由轻到重：

**🟢 快赢档**
- AI 分析页跑完一份报告，**当场就能在页内看到排版好的成品**（跟手动回测页一样），不用再开 Typora。
- 数据管理页"分析报告"栏**能正确列出真实报告**，点开即看排版正文，不截断。

**🟡 中改档**
- 评估页双击某份报告跳到题材页时，**精确落到这一份报告**，同日同模板的多份报告不再混表。

**🔴 大型档**
- 多一个**统一的"报告浏览中心"**：一个列表，按日期 / 模板 / 真实还是回测筛，点一行右边就出排版正文，旁边一键跳"看评估"或"看题材"；删除也统一从这里走，不再留孤儿。

## A3、决策点（块 A，请主人勾选）

| 编号 | 决策 | 选项 | 辉夜推荐 |
|---|---|---|---|
| **A-决策1** | AI 分析页要不要补"页内排版预览"？ | A 要（对齐回测页）/ B 不要，继续用外部编辑器 | **A** |
| **A-决策2** | 数据管理页"分析报告"栏要修吗？ | A 修目录 + 改排版渲染 / B 干脆从数据管理页移除这栏（统一去报告中心看）/ C 先不动 | **A**（快赢，顺手） |
| **A-决策3** | 评估页双击联动要不要精确到"单份报告"？ | A 要（解决混表）/ B 维持现状只到"日期+模板" | **A** |
| **A-决策4** | 要不要做"统一报告浏览中心"？ | A 要（独立新页，含列表 + 预览 + 跳转 + 统一删除）/ B 暂不做，先把上面几项快赢清掉 | 看主人精力，**可缓** |

# 块 B · 预测板块的筛选与查看

## B0、先澄清一个容易混的概念

项目里"板块"这个词被两套数据共用，主人筛选时经常会混：

| 叫法 | 它其实是 | 在哪看 |
|---|---|---|
| **AI 预测板块 / 题材** | AI 从分析报告里抽出来的"题材"，再绑定到一个板块代码上 | 题材预测页、模板评估页 |
| **市场板块行情** | 当天真实市场上各板块涨了多少、资金流多少 | 盘后数据页"全部板块"Tab |

主人说的"**预测板块筛选查看**"主要指**第一套（AI 预测）**，但两套之间"对不上号"也是痛点之一，所以下面一并谈。

## B1、现在为什么难受

| # | 现状 | 难受在哪 |
|---|------|---------|
| B-1 | 题材预测页的筛选**只有"报告日期 + 模板"两个维度** | 想按"题材名/板块名搜一搜"、"只看强度高的"、"只看真实别看回测"全做不到 |
| B-2 | 题材预测页里那个「打分明细」Tab **至今是一句占位文案**，真正的命中率 / 方向准不准全在评估页 | 选中一个题材想知道"它当初预测得准不准"，得切去评估页重新一层层点开 |
| B-3 | **没有"跨日看一个板块"的视角** | 只能一天一天翻报告，无法回答"这个板块这一个月被预测过几次、平均准不准" |
| B-4 | 题材表里只显示一串板块代码（像 `BK0477.DC`），**不显示板块中文名** | 得脑内翻译代码，或者再点进走势 Tab 才看得到名字 |
| B-5 | AI 预测板块和盘后真实行情**完全不联动** | 不能从"今天涨最猛的板块"反查"哪些报告预测中了它"，也不能从预测题材一键跳去看它今天真实行情 |
| B-6 | 同一个"弱匹配"判断，题材页和评估页用的**松紧标准不一样**（一处更松一处更严） | 同一个题材在两个页面一个标黄一个不标，看着像 bug（其实是阈值没对齐）—— 强迫症暴击 |

## B2、做完后主人能怎么爽（预期效果）

**🟢 快赢档**
- 题材表多一列**板块中文名**，不用再认代码。
- 两处"弱匹配"判断标准**对齐成同一个**，不再一黄一不黄。

**🟡 中改档**
- 题材预测页选中一个题材，**右边「打分明细」Tab 直接显示命中率 / 方向准不准 / 逐日表现**，不用切去评估页。
- 题材预测页加一条**筛选栏**：能按题材名/板块名搜、按强度区间筛、按"真实 / 回测"切换。

**🔴 大型档**
- 多一个**"预测板块跨日总览"**视角：按某个板块或某个题材聚合，一眼看到"它历史上被预测过几次、平均命中率多少、方向准不准"。
- **预测 ↔ 真实行情双向跳**：盘后某个板块行右键能查"哪些报告预测过它"；预测题材一键跳到盘后看它当天真实涨跌。

主人虽然全选了，但一锅端风险大、周期长。辉夜建议**分批交付**，每批都能独立验收、独立爽：

| 批次 | 包含 | 价值 | 预估 |

| **第 4 批·大型功能** | A-决策4（报告中心）、B-决策5（跨日总览）、B-决策6（双向联动） | 体验质变，但须单独再出设计 | 须二次设计 |

## 四、Q&A（预想主人会问）

**Q1：第 4 批为什么不在这轮直接拍方案？**
A：报告中心 / 跨日总览 / 双向联动每一个都是"新增页面或新增跨模块交互"，体量够格单独走一遍双文档流程。塞进这轮会让文档失焦、施工排期也不可控。先把前 3 批落地见效，第 4 批等主人确认要做时再单独设计。

**Q2：这些改动会动到现有的分析 / 打分 / 抓数据逻辑吗？**
A：第 1~3 批**只动"查看与展示"层**，不碰分析生成、打分计算、数据抓取的核心逻辑——纯前端体验增强 + 把已有数据接到该显示的地方。风险可控。

**Q3：题材页「打分明细」的数据现在到底有没有？**
A：有，命中率 / 方向 / 逐日表现这些数据评估页早就在用了，只是题材页那个 Tab 当初留了个占位没接上。B-决策3 就是把现成数据接过去，不是从零造数据。

**Q4：辉夜整体推荐怎么勾？**
A：
- 块 A：**A-决策1 / 2 / 3 全 A**；A-决策4（报告中心）缓到第 4 批单独设计。
- 块 B：**B-决策1 / 2 / 3 全 A**，**B-决策4 四个维度全要**；B-决策5 / 6 缓到第 4 批单独设计。
- 推进节奏：**先做第 1、2 批**。
