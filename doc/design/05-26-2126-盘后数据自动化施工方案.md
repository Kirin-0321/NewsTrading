## 0. 设计原则（先于代码）

1. **零新依赖**：用 `urllib + sqlite3 + json` 实现，**不引入 `tushare` SDK / `pandas` / `jsonschema` / `pyyaml`**。原因：项目要打包成 EXE，依赖越少越稳。YAML frontmatter 用手写解析器即可（格式固定）。
2. **service 层风格对齐**：跟 `services/clean_sync_service.py`、`services/analysis_service.py` 同款——`@dataclass Result` + `Service.method() -> Result` + 顶层 `def xxx_sync(**kwargs) -> Result` 兼容老调用。
3. **Tushare 字段严格按审计文档**：见 [`doc/reports/05-26-2126-Tushare接口字段审计.md`](../reports/05-26-2126-Tushare接口字段审计.md) §3；任何字段不一致以审计为准。
4. **CLS 优先、AI 兜底**：板块催化、涨停原因首选 `cls_stock_shock`，AI 只补 cls 没覆盖的板块。
5. **单位统一**：fetcher 内部把所有金额归一化到 **亿元**、所有涨跌幅归一化到 **百分比**，下游不碰原始单位。
6. **失败不阻塞主流程**：北向数据缺失、AI 服务挂了等情况降级为 `tushare-only`，附 `gaps[]` 告知下游，**不抛异常**。
7. **GUI 独立成页**：盘后数据可独立查看 / 重新获取，**不依赖 AI 分析页**；分析页只是"消费方"。
8. **纯数据全部入库**：Tushare 行情、盘后总结、AI patch、游资别名 → `data/market.db`；AI 分析 md 保留文件 + 在 `news.db.ai_reports` 建元数据索引。
9. **Prompt 文件化**：所有 AI 模板拆到 `prompts/{category}/{id}.md`，用 MD + YAML frontmatter 格式，支持 `{{include:xxx}}` 复用片段。

### 2.2 schema_version 管理

- 顶层 `schema_version` 字段。V1 = `"1.0"`。
- schema 不兼容升级时（如字段重命名/层级变化），版本号 minor++。
- 旧版本 patch 文件标 stale（仅显示，不参与重放）。

### 2.3 持久化策略（核心改动）

| 数据 | 落到哪 | 备注 |
|------|-------|------|
| 完整 JSON | `market.db.market_summaries.summary_json` | TEXT 列存完整 JSON 字符串 |
| compact md | `market.db.market_summaries.summary_md` | TEXT 列，由 renderer 渲染 |
| 常用字段冗余 | `market.db.market_summaries.{limit_up_count, seal_rate, ...}` | 索引/查询友好，避免每次解 JSON |
| Tushare 原始响应 | `market.db.fact_*.raw_json` 列 | 每个 fact 表都有 raw_json 兜底 |
| AI patch | `market.db.ai_enrich_patches.patch_json` | 含 token 数、prompt 版本号、模型名 |
| **不落文件** | 取消 `data/tushare_cache/` 和 `data/market_summary/*.md` | 全靠 DB |

## 3. 数据库设计

### 3.1 单库 vs 双库决策

**最终采用双库物理隔离**：
- `data/news.db` — 新闻语料 + 题材预测 + AI 报告索引（既有，新增 1 张表）
- `data/market.db` — Tushare 行情 + 盘后总结 + AI patch + 游资别名（全新）

**理由**：
1. 业务边界清晰（语料 vs 行情）
2. WAL 锁竞争隔离（爬虫/清洗/AI 分析 vs 每日 16 次 Tushare 写入）
3. 体积差异大（news.db ~100MB / market.db 1~3GB 一年）
4. 可重建性差异（market.db 完全可重建，news.db 不可重建）
5. 故障隔离（行情库损坏不影响新闻业务）
6. SQLite ATTACH 原生支持跨库 JOIN，使用零成本

### 3.3 维度表 DDL

```sql
-- 交易日历
CREATE TABLE dim_trade_calendar (
    trade_date    TEXT PRIMARY KEY,      -- YYYYMMDD
    is_open       INTEGER NOT NULL,      -- 1=交易日 0=休市
    pretrade_date TEXT,
    cal_date      TEXT                   -- 自然日 YYYYMMDD
);
CREATE INDEX idx_calendar_open ON dim_trade_calendar(is_open, trade_date DESC);

-- 板块字典（dc/ths/sw 都进这里，按 src 区分）
CREATE TABLE dim_sector (
    ts_code        TEXT PRIMARY KEY,     -- BK0917.DC
    name           TEXT NOT NULL,
    idx_type       TEXT NOT NULL,        -- 概念板块/行业板块
    src            TEXT NOT NULL,        -- dc/ths/sw
    list_date      TEXT,
    last_seen_date TEXT,
    UNIQUE(name, src)
);
CREATE INDEX idx_sector_name ON dim_sector(name);

-- 个股字典
CREATE TABLE dim_stock (
    ts_code   TEXT PRIMARY KEY,
    name      TEXT NOT NULL,
    market    TEXT,                       -- 主板/创业板/科创板/北证
    industry  TEXT,
    list_date TEXT
);
CREATE INDEX idx_stock_name ON dim_stock(name);

-- 游资席位别名（取代 config/trader_seat_aliases.json）
CREATE TABLE dim_trader_alias (
    exalter    TEXT PRIMARY KEY,         -- 营业部全名
    alias      TEXT NOT NULL,            -- 拉萨天团
    is_famous  INTEGER DEFAULT 0,        -- 是否知名游资
    notes      TEXT,
    updated_at TEXT
);
CREATE INDEX idx_alias_famous ON dim_trader_alias(is_famous, alias);
```

### 3.8 数据库连接管理 + 迁移

```python
# services/market/market_db.py
class MarketDB:
    def __init__(self, db_path: Path = Path("data/market.db")):
        self.path = db_path
        self._ensure_schema()

    def _ensure_schema(self) -> None:
        """启动时检查 schema_migrations 版本号，若落后则跑 migrations。"""
        with self.connect() as conn:
            self._create_migration_table(conn)
            current = self._get_current_version(conn)
            for ver, name, sql_path in self._list_pending(current):
                self._apply_migration(conn, ver, name, sql_path)

    @contextmanager
    def connect(self):
        """提供 with-conn 上下文，自动启用 WAL 模式 + foreign_keys。"""
        conn = sqlite3.connect(self.path, timeout=30)
        conn.execute("PRAGMA journal_mode=WAL")
        conn.execute("PRAGMA foreign_keys=ON")
        conn.row_factory = sqlite3.Row
        try:
            yield conn
            conn.commit()
        except Exception:
            conn.rollback()
            raise
        finally:
            conn.close()

    def attach_to(self, foreign_conn: sqlite3.Connection, alias: str = "m") -> None:
        """把 market.db ATTACH 到外部连接（用于 news.db 跨库 join）。"""
        foreign_conn.execute(f"ATTACH DATABASE '{self.path}' AS {alias}")
```

**迁移文件命名**: `services/market/migrations/{NNN}_{name}.sql`。所有 SQL 都是幂等的（`CREATE TABLE IF NOT EXISTS`）。

**初始迁移**:
- `001_initial.sql` — 13 张表 + 索引
- `002_seed_trader_aliases.sql` — 初始 30~50 条游资别名 INSERT

```python
    name: str

    """统一 Prompt 加载器。线程安全（用 RLock）。"""

    def __init__(self, root: Path = Path("prompts")):
        self.root = root
        self._cache: dict[str, PromptTemplate] = {}
        self._shared_cache: dict[str, str] = {}
        self._lock = threading.RLock()

    def get(self, category: str, prompt_id: str) -> PromptTemplate:
        """加载 + 缓存。"""

    def list_category(self, category: str) -> list[PromptTemplate]:
        """列出某类别下的所有模板。"""

    def list_all(self) -> dict[str, list[PromptTemplate]]:
        """全量列出。"""

    def reload(self) -> None:
        """清空缓存，GUI 编辑器保存后调用。"""

    def save(self, category: str, prompt_id: str, raw_text: str) -> PromptTemplate:
        """GUI 保存接口，写入文件 + 重新加载。"""

    def validate_all(self) -> list[str]:

          - frontmatter 必填字段

        """
```

**解析步骤**:
1. 读文件 → split frontmatter（`---` 之间）/ body
2. 手写 YAML 子集解析器（只支持 `key: value` 和 `key:\n  - item` 两种语法）

5. 构造 `PromptTemplate` 并缓存

```python
@dataclass
class MarketSummaryResult:
    ok: bool = False
    trade_date: str | None = None
    prev_trade_date: str | None = None
    summary_json: dict | None = None
    summary_md: str | None = None
    completeness: float = 0.0
    gaps: list[dict] = field(default_factory=list)
    warnings: list[str] = field(default_factory=list)
    elapsed_ms: int = 0
    api_call_count: int = 0
    cancelled: bool = False
    error: str | None = None


class MarketSummaryService:
    def __init__(self):
        self.db = MarketDB()
        self.client = TushareClient()
        self.prompt_loader = PromptLoader()
        self.fetcher = TushareMarketFetcher(self.client, self.db)
        self.cls_enricher = CLSEnricher()
        self.ai_enricher = AIEnricher(AIConfig(), get_raw_store(), self.prompt_loader)
        self.trader_matcher = TraderAliasMatcher(self.db)
        self.merger = MarketSummaryMerger()
        self.validator = MarketSummaryValidator(Path("config/market_summary_schema.json"))
        self.renderer = MarketSummaryRenderer()

    def build(
        self,
        trade_date: str | None = None,
        mode: Literal["tushare-only", "hybrid", "ai-full"] = "hybrid",
        top_sector_n: int = 10,
        force_refresh: bool = False,
        cancel_check: Callable | None = None,
        progress_callback: Callable | None = None,
    ) -> MarketSummaryResult:
        """主入口。失败不抛异常，全部塞进 MarketSummaryResult.error。"""

    def get(self, trade_date: str) -> MarketSummaryResult:
        """从 market_summaries 表读取已生成的盘后数据。"""

    def list_dates(self) -> list[str]:
        """列出所有已生成的日期（DESC）。"""

    def delete(self, trade_date: str) -> bool:
        """删除某天数据（GUI 用，用于重新拉取前清理）。"""


def build_market_summary(**kwargs) -> MarketSummaryResult:
    """顶层函数。"""
    return MarketSummaryService().build(**kwargs)
```

**`build()` 内部流程**:
```
1. progress_callback("解析交易日...")
   trade_date, prev_trade_date = resolve_trade_date(client, trade_date)

2. 如已存在 market_summaries[trade_date] 且不 force_refresh → return get()

3. progress_callback("Tushare 拉取中...")
   fetch_result = fetcher.fetch(trade_date, prev_trade_date, ...)
   _raise_if_cancelled(cancel_check)

4. progress_callback("派生指标计算...")
   metrics_data = metrics.compute_all_from_db(db, trade_date)

5. progress_callback("CLS 数据匹配...")
   cls_result = cls_enricher.enrich(db, trade_date, top_sectors)

6. if mode in ("hybrid", "ai-full"):
       progress_callback("AI 兜底补全...")
       ai_patch = ai_enricher.enrich(cls_result.unmatched_sectors, ...)

7. progress_callback("合并 & 校验...")
   summary = merger.merge(db, trade_date, cls_result, ai_patch, trader_matcher)
   report = validator.validate(summary)
   summary["quality"] = report.to_dict()

8. md_text = renderer.render_compact(summary)
   db.save_summary(trade_date, summary, md_text, meta, ai_patch)

9. return MarketSummaryResult(ok=True, ...)
```

### 6.5 Worker：`gui/workers/market_fetch_worker.py`

```python
class MarketFetchWorker(QThread):
    progress = pyqtSignal(str)
    finished = pyqtSignal(dict)
    error = pyqtSignal(str)
    cancelled = pyqtSignal()

    def __init__(self, trade_date, mode, force_refresh):
        super().__init__()
        self.trade_date = trade_date
        self.mode = mode
        self.force_refresh = force_refresh
        self._cancel_requested = False

    def request_cancel(self):
        self._cancel_requested = True

    def run(self):
        from services.market.service import MarketSummaryService
        try:
            result = MarketSummaryService().build(
                trade_date=self.trade_date,
                mode=self.mode,
                force_refresh=self.force_refresh,
                cancel_check=lambda: self._cancel_requested,
                progress_callback=lambda msg: self.progress.emit(msg),
            )
            if result.cancelled:
                self.cancelled.emit()
            elif result.ok:
                self.finished.emit({
                    "trade_date": result.trade_date,
                    "summary_json": result.summary_json,
                    "summary_md": result.summary_md,
                    "completeness": result.completeness,
                    "warnings": result.warnings,
                    "elapsed_ms": result.elapsed_ms,
                    "api_call_count": result.api_call_count,
                })
            else:
                self.error.emit(result.error or "未知错误")
        except Exception as e:
            self.error.emit(f"{type(e).__name__}: {e}")
```

```python
    trade_date: Optional[str] = None,    # 🆕
    ...,
) -> AnalysisResult:
    ...
    if auto_market and not market_summary:
        try:
            from services.market.service import MarketSummaryService
            ms_result = MarketSummaryService().build(
                trade_date=trade_date,
                mode="hybrid",
                cancel_check=cancel_check,
                progress_callback=progress_callback,
            )
            if ms_result.ok:
                market_summary = ms_result.summary_md
                if progress_callback:
                    progress_callback(f"已自动获取盘后数据（完整性 {ms_result.completeness:.0%}）")
            else:
                if progress_callback:
                    progress_callback(f"⚠️ 自动获取盘后数据失败: {ms_result.error}（继续分析，仅基于新闻）")
        except Exception as e:
            if progress_callback:
                progress_callback(f"⚠️ 盘后数据模块加载失败: {e}")
    ...
```

**约束**:
- 手填 `market_summary` 非空时不调 auto_market
- 自动获取失败不阻塞 analyze，仅写 progress 提示

## 11. 错误处理矩阵

| 情景 | 处理 |
|------|------|
| Tushare token 缺失 | `MarketSummaryService.__init__` 探测，抛 RuntimeError |
| Tushare 网络断 | retry 3 次（2s/4s/8s）→ `result.error="Tushare 网络不可用"` |
| Tushare 限频 | retry 3 次 → 仍失败则该字段进 gaps，**不抛** |
| Tushare 参数错（如非交易日） | 自动 fallback 到 pretrade_date，`meta.fallback_to_prev_trade_date=true` |
| `moneyflow_hsgt` T 日空 | 兜底 pretrade_date + `north_is_delayed=true` |
| AI 服务挂了 | 降级 `tushare-only`，gaps 加"AI 补全未执行" |
| AI 返回非法 JSON | 复用 `core/theme_extractor.py` 的四级 JSON 修复策略 |
| AI 试图改 L1 数值 | merger 拒绝 + 写入 `conflicts[]` |
| Prompt 文件缺失 | PromptLoader 抛 `PromptNotFoundError`，启动时 validate_all 提前发现 |
| Prompt include 循环 | PromptLoader 检测，抛 `CircularIncludeError` |
| DB 文件不存在 | MarketDB 自动 create + 跑 migrations |
| DB schema 版本落后 | MarketDB 自动跑 pending migrations + 升级前备份 |
| DB 损坏 | GUI 提示用户用备份恢复，提供"💾 备份数据库"按钮 |
| `completeness < block_threshold` | `result.ok=False`，error="完整性过低" |
| `completeness < warn_threshold` 但 >= block | `result.ok=True` + warnings |
| 用户终止（cancel_check） | `result.cancelled=True`，已写入的 DB 数据保留 |
| 同 trade_date 重复 build | 默认命中 `market_summaries` 行；`force_refresh=True` 删除后重拉 |
