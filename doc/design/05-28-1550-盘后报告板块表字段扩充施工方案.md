## 二、技术选型

### 2.1 数据源选择

| 字段 | 来源 | 备注 |
|---|---|---|
| 总市值 | `dc_index.total_mv`（单位**万元**，落库前 ÷ 1e4 转**亿元**） | 跟 v1 审计一致 |
| 换手率 | `dc_index.turnover_rate`（单位 %） | 直接落库 |
| 上涨家数 | `dc_index.up_num` | int |
| 下跌家数 | `dc_index.down_num` | int |
| 超大单 | `fact_sector_daily.main_elg_yi`（**已存在**） | 零迁移 |

### 2.2 库版本 / 依赖

- 无新增依赖
- Tushare API 新增 `dc_index` 三次调用（概念/行业/地域），每日总 31→34 次
- 已有 `TushareClient.call("dc_index", params={"idx_type": "..."})` 能力，无需新封装

### 2.3 dc 源 fallback 实现思路（决策 5）

聚合表 `_SECTOR_GROUPED_MEDIAN_SQL` 当前每组只 SELECT 中位代表那一行。新增 4 列时：

- **若中位代表已是 dc 源** → 直接 SELECT s.total_mv / s.turnover_rate / s.up_num / s.down_num
- **若中位代表是 ths 源** → 用 LATERAL-style 子查询从**同组的另一行 dc 源**取这 4 字段（SQLite 用 correlated subquery + LIMIT 1）

实现为新加一个 CTE：

```sql
-- 在 ranked 之后加：
dc_fallback AS (
    SELECT gkey,
           MAX(total_mv)        FILTER (WHERE src='dc') AS total_mv,
           MAX(turnover_rate)   FILTER (WHERE src='dc') AS turnover_rate,
           MAX(up_num)          FILTER (WHERE src='dc') AS up_num,
           MAX(down_num)        FILTER (WHERE src='dc') AS down_num
    FROM keyed
    GROUP BY gkey
)
-- SELECT 时 LEFT JOIN dc_fallback USING(gkey)
-- 取 COALESCE(ranked.total_mv, dc_fallback.total_mv)
```

> ⚠️ SQLite 3.30+ 才支持 `FILTER`，需 fallback 写法：`MAX(CASE WHEN src='dc' THEN total_mv END)`。

### Phase 2：fetcher 新增 dc_index 拉取（2h）

- 新增方法 `_ingest_dc_index_to_fact_sector_daily(rows, trade_date, idx_type)`：
  - 对每行 `r`，按 `(trade_date, r["ts_code"])` UPDATE fact_sector_daily SET total_mv=?, turnover_rate=?, up_num=?, down_num=?

  - 单位转换：`total_mv ÷ 1e4` 落"亿元"
- 调用顺序：先跑 moneyflow_ind_dc 三类，再跑 dc_index 三类（确保行已经存在）

**关键代码骨架**：

```python
# _fetch_sector_moneyflow 内 dc 三类循环后追加：
for content_type, idx_type in self._DC_SECTOR_VARIANTS:
    try:
        rows = self.client.call(
            "dc_index",
            params={"trade_date": result.trade_date, "idx_type": idx_type},
        )
    except TushareError as exc:
        result.warnings.append(f"dc_index({idx_type}): {exc}")
        continue
    updated = self._merge_dc_index_to_fact_sector_daily(
        rows, result.trade_date, idx_type=idx_type,
    )
    result.ingested.setdefault("fact_sector_daily.dc_index", 0)
    result.ingested["fact_sector_daily.dc_index"] += updated
```

### Phase 3：聚合 SQL 加 dc fallback（1.5h）

**改 `services/market/sector_grouping.py`**：

修改 `_SECTOR_GROUPED_MEDIAN_SQL`：

```sql
WITH base AS (
    SELECT s.ts_code, s.pct_chg, s.main_net_yi, s.main_elg_yi,
           s.main_lg_yi, s.pct_chg_5d, s.rank_today,
           s.total_mv, s.turnover_rate, s.up_num, s.down_num,  -- ← 新加
           d.name AS sector_name, d.idx_type, d.src,
           d.group_id,
           g.name AS group_name,
           g.members_count
    FROM fact_sector_daily s
    LEFT JOIN dim_sector d ON d.ts_code = s.ts_code
    LEFT JOIN dim_sector_group g ON g.id = d.group_id
    WHERE s.trade_date = ?
), keyed AS (
    SELECT *,
           COALESCE('g' || group_id, 's' || ts_code) AS gkey
    FROM base
), ranked AS (
    SELECT *,
           ROW_NUMBER() OVER (
               PARTITION BY gkey
               ORDER BY pct_chg ASC NULLS LAST, ts_code
           ) AS rn,
           COUNT(*) OVER (PARTITION BY gkey) AS cnt_in_data
    FROM keyed
), dc_fallback AS (  -- ← 新加：每组从 dc 源板块取这 4 字段
    SELECT gkey,
           MAX(CASE WHEN src='dc' THEN total_mv      END) AS dc_total_mv,
           MAX(CASE WHEN src='dc' THEN turnover_rate END) AS dc_turnover_rate,
           MAX(CASE WHEN src='dc' THEN up_num        END) AS dc_up_num,
           MAX(CASE WHEN src='dc' THEN down_num      END) AS dc_down_num
    FROM keyed
    GROUP BY gkey
)
SELECT r.ts_code, r.pct_chg, r.main_net_yi, r.main_elg_yi,
       r.main_lg_yi, r.pct_chg_5d, r.rank_today,
       r.sector_name, r.group_name,
       COALESCE(r.group_name, r.sector_name) AS display_name,
       r.cnt_in_data,
       r.members_count,
       COALESCE(r.total_mv,      f.dc_total_mv)      AS total_mv,       -- ← 新加（dc fallback）
       COALESCE(r.turnover_rate, f.dc_turnover_rate) AS turnover_rate,
       COALESCE(r.up_num,        f.dc_up_num)        AS up_num,
       COALESCE(r.down_num,      f.dc_down_num)      AS down_num
FROM ranked r
LEFT JOIN dc_fallback f USING (gkey)
WHERE r.rn = (r.cnt_in_data + 1) / 2
ORDER BY r.pct_chg DESC NULLS LAST
```
