## 📋 需求分析

### 1. 核心需求
基于爬取的新闻数据，使用AI进行深度分析，生成A股投资建议报告。

### 2. 功能需求

#### 2.1 数据输入（支持多种格式）

**方式1: 导出文件（推荐）**
- ✅ JSON格式: 完整的新闻结构化数据（标题+内容+时间+来源）
- ✅ Markdown格式: 人类可读的新闻摘要
- ✅ TXT格式: 极简标题列表（时间+标题）

**方式2: 原始数据**
- ✅ 原始JSON文件（单日数据）
- ✅ 自定义时间范围

**方式3: 影响分析结果**
- ✅ 读取影响分析报告（只分析重点新闻，节省token）

#### 2.2 AI分析功能
1. **板块机会识别**
   - 自动识别当前热点板块
   - 分析催化剂事件
   - 构建投资逻辑链条

2. **龙头股票推荐**
   - 为每个板块推荐3-5只龙头股
   - 给出介入时机建议
   - 预测目标涨幅

3. **风险提示**
   - 政策风险
   - 估值风险
   - 市场情绪风险
   - 个股风险

4. **投资策略建议**
   - 优先级排序
   - 介入时机窗口
   - 仓位配置建议

#### 2.3 输出格式
- ✅ Markdown格式报告
- ✅ 包含板块分析、龙头股、策略建议
- ✅ 自动保存到 `data/AI_analysis/` 目录
- ✅ 支持使用Typora查看

## 🎯 技术方案

### 1. AI服务商选择

#### 方案A: OpenAI API（推荐）
```python
优势:
✅ 分析质量最高
✅ 输出格式稳定
✅ 支持多种模型（GPT-4, GPT-3.5）
✅ 文档完善

劣势:
❌ 需要API Key
❌ 有使用成本
❌ 可能需要VPN

适用场景: 对分析质量要求高的用户
```

#### 方案B: 国产大模型API
```python
支持的服务商:
- 智谱AI (GLM-4)
- 通义千问 (Qwen)
- 文心一言 (ERNIE)
- 讯飞星火 (SparkDesk)

优势:
✅ 国内访问稳定
✅ 价格相对便宜
✅ 不需要VPN

劣势:
❌ 分析质量可能略低
❌ 输出格式需要调优

适用场景: 国内用户、成本敏感用户
```

#### 方案C: 本地模型（可选）
```python
支持的模型:
- Ollama + Llama 3
- GPT4All
- LocalAI

优势:
✅ 完全免费
✅ 隐私安全
✅ 无网络限制

劣势:
❌ 需要较强硬件（显卡）
❌ 分析质量相对较低
❌ 安装配置复杂

适用场景: 对隐私要求高、有硬件条件的用户
```

### 2. 推荐方案
**优先级1**: OpenAI API (GPT-4)
**优先级2**: 智谱AI (GLM-4)
**优先级3**: 本地模型（Ollama）

## 💰 成本估算

### OpenAI API成本
```
模型: GPT-4
输入: $0.03 / 1K tokens
输出: $0.06 / 1K tokens

单次分析:
- 输入新闻数据: ~5000 tokens
- 输出分析报告: ~2000 tokens
- 成本: $0.03 × 5 + $0.06 × 2 = $0.27

每月50次分析: $13.5
每月100次分析: $27
```

### 智谱AI成本
```
模型: GLM-4
价格: ¥0.1 / 1K tokens（输入输出同价）

单次分析:
- 总tokens: ~7000 tokens
- 成本: ¥0.1 × 7 = ¥0.7

每月50次分析: ¥35
每月100次分析: ¥70
```

### 本地模型成本
```
硬件要求:
- 显卡: RTX 3060 (12GB) 或以上
- 内存: 16GB+
- 硬盘: 20GB+

成本: 免费（一次性硬件投入）
```

## 🎨 数据流程

```
1. 用户配置
   ↓
   选择数据源（导出文件/影响分析/原始数据）
   ↓
2. 格式识别
   ↓
   自动检测: JSON / Markdown / TXT
   ↓
3. 数据加载
   ↓
   JSON → 完整数据结构
   Markdown → 解析格式化内容
   TXT → 提取时间和标题
   ↓
4. 数据预处理
   ↓
   去重 → 排序 → Token优化 → 格式化
   ↓
5. 提示词构建
   ↓
   系统提示词 + 新闻数据 + 分析要求
   ↓
6. AI分析
   ↓
   调用API → 流式返回 → 实时显示
   ↓
7. 结果处理
   ↓
   格式化 → 生成Markdown → 保存文件
   ↓
8. 报告查看
   ↓
   使用Typora打开 → 用户阅读
```

## 📊 性能优化

### 1. 数据预处理
```python

- 压缩新闻内容（保留核心信息）
- 去除重复信息
- 限制总token数
```

### 2. API调用优化
```python
- 支持流式输出（实时显示）
- 批量分析（多个时间段）
- 结果缓存（相同数据不重复分析）
- 并发限制（避免超额费用）
```
