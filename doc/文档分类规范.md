# 📚 文档分类规范

> 本文档定义了项目文档的分类标准和命名规范，确保所有生成的文档能够自动归类到正确的目录。

---

## 📂 目录结构说明

```
doc/
├── bugfix/          # Bug修复文档
├── design/          # 设计文档
├── features/        # 功能特性说明
├── guides/          # 使用指南
├── reports/         # 分析报告
├── updates/         # 更新日志
└── 其他/            # 其他杂项文档
```

---

## 🏷️ 分类标准

### 1. `bugfix/` - Bug修复文档

**适用场景**：
- 修复了某个具体bug
- 问题排查和解决方案
- 错误修正说明

**命名规范**：
```
{日期}-bugfix-{简短描述}.md
例如：2025-01-08-bugfix-数据库锁定问题修复.md
```

**内容要求**：
- 问题描述
- 问题原因分析
- 解决方案
- 影响范围
- 测试验证

---

### 2. `design/` - 设计文档

**适用场景**：
- 新功能的设计方案
- 架构设计说明
- 技术选型说明
- 接口设计文档

**命名规范**：
```
{日期}-design-{功能模块名称}.md
例如：2025-01-08-design-工作流引擎架构.md
```

**内容要求**：
- 需求背景
- 设计目标
- 技术方案
- 架构图/流程图
- 接口定义
- 风险评估

---

### 3. `features/` - 功能特性说明

**适用场景**：
- 新增功能说明
- 功能增强说明
- 功能使用方法
- 功能实现细节

**命名规范**：
```
{日期}-feature-{功能名称}.md
例如：2025-01-08-feature-自动化报告生成.md
```

**内容要求**：
- 功能概述
- 使用场景
- 操作步骤
- 参数说明
- 注意事项
- 示例演示

---

### 4. `guides/` - 使用指南

**适用场景**：
- 入门教程
- 操作手册
- 配置指南
- 最佳实践
- FAQ常见问题

**命名规范**：
```
{日期}-guide-{主题}.md
例如：2025-01-08-guide-定时任务配置指南.md
```

**内容要求**：
- 目标受众说明
- 前置条件
- 详细步骤
- 截图说明
- 常见问题
- 相关链接

---

### 5. `reports/` - 分析报告

**适用场景**：
- 系统分析报告
- 性能测试报告
- 代码审查报告
- 项目总结报告
- 数据统计报告

**命名规范**：
```
{日期}-report-{报告主题}.md
例如：2025-01-08-report-系统性能优化分析.md
```

**内容要求**：
- 报告目的
- 分析方法
- 数据统计
- 结论和建议
- 附录资料

---

### 6. `updates/` - 更新日志

**适用场景**：
- 版本更新说明
- 功能迭代记录
- 优化改进说明
- 变更日志

**命名规范**：
```
{日期}-update-{更新主题}.md
例如：2025-01-08-update-v2.1版本更新说明.md
```

**内容要求**：
- 版本号
- 更新时间
- 新增功能
- 优化改进
- Bug修复
- 已知问题
- 升级指南

---

### 7. `其他/` - 其他杂项

**适用场景**：
- 不属于以上分类的文档
- 临时性文档
- 备忘录
- 待分类文档

**命名规范**：
```
{日期}-{简短描述}.{扩展名}
例如：2025-01-08-会议纪要.txt
```

## 🤖 AI自动分类规则

### 关键词匹配规则

AI在生成文档时，会根据以下关键词自动判断分类：

| 分类 | 关键词 |
|------|--------|
| **bugfix/** | 修复、bug、错误、问题、故障 |
| **design/** | 设计、架构、方案、技术选型 |
| **features/** | 功能、特性、新增、增强、实现 |
| **guides/** | 指南、教程、手册、配置、使用 |
| **reports/** | 报告、分析、统计、总结、评估 |
| **updates/** | 更新、版本、变更、优化、改进 |
| **其他/** | 其他、杂项、临时、备忘 |

### 自动判断流程

```
1. 分析文档标题和内容
   ↓
2. 提取关键词
   ↓
3. 匹配分类规则
   ↓
4. 确定目标目录
   ↓
5. 生成标准化文件名
   ↓
6. 保存到指定目录
```

## 📝 文档模板

### Bug修复模板

```markdown
# Bug修复：[问题简述]

## 问题描述
[详细描述bug的表现]

## 问题原因
[分析问题的根本原因]

## 解决方案
[说明修复方法]

## 测试验证
[验证结果]

## 影响范围
[说明影响的模块和功能]
```

### 功能说明模板

```markdown
# 功能：[功能名称]

## 功能概述
[简要说明功能作用]

## 使用场景
[说明适用场景]

## 使用方法
[详细操作步骤]

## 参数说明
[参数列表和说明]

## 示例
[使用示例]

## 注意事项
[重要提示]
```

### 使用指南模板

```markdown
# 使用指南：[主题]

## 简介
[说明本指南的目的]

## 前置条件
[需要的环境和准备]

## 操作步骤

### 步骤1：[标题]
[详细说明]

### 步骤2：[标题]
[详细说明]

## 常见问题
[FAQ列表]

## 相关资源
[相关链接]
```

## 🎯 使用建议

### 对于开发者

1. **创建新文档时**，先确定文档类型，使用标准命名格式
2. **写文档前**，参考对应的模板结构
3. **完成后**，检查是否放在了正确的目录

### 对于AI助手

1. **自动分类**：根据关键词匹配规则自动选择目录
2. **标准命名**：按照规范生成文件名
3. **模板应用**：根据文档类型使用对应模板
4. **提示确认**：如果分类不确定，向用户确认

### 示例对话

**用户**："生成一个关于定时任务配置的使用说明"

**AI响应**：
```
好的，我将创建使用指南类文档：
- 分类：guides/
- 文件名：2025-01-08-guide-定时任务配置.md
- 使用模板：使用指南模板
```
