========================================
  打包说明
========================================

1. 运行打包脚本
   双击 "一键打包.bat"

2. 等待打包完成
   - 检查Python环境
   - 检查PyInstaller
   - 清理旧文件
   - 执行打包
   - 复制Chrome浏览器
   - 创建目录结构

3. 输出位置
   dist\新闻爬虫系统\

4. 打包大小
   约 400-500 MB (包含Chrome浏览器)

========================================
  使用说明
========================================

打包后的程序可以直接复制到其他电脑使用：

1. 复制整个 "dist\新闻爬虫系统" 目录

2. 在目标电脑上：
   - 无需安装Python
   - 无需安装任何依赖
   - 直接双击 "新闻爬虫系统.exe" 即可运行

3. 首次运行：
   - 配置 AI API Key (config/ai_config.json)
   - 检查 Chrome 浏览器是否正常

========================================
  注意事项
========================================

✓ 确保 chrome-win64 目录完整
✓ 确保 Typora 目录完整
✓ 确保 config 目录中的配置文件存在
✓ 打包后首次运行可能较慢 (程序解压)
✓ 建议使用无头模式运行爬虫 (节省资源)

========================================
  常见问题
========================================

Q: 打包后程序无法启动？
A: 检查是否有杀毒软件拦截，尝试添加信任

Q: Chrome浏览器启动失败？
A: 确保 chrome-win64 目录在 exe 同级目录

Q: AI分析报错？
A: 检查 config/ai_config.json 中的 API Key

Q: 程序体积太大？
A: 主要是 Chrome 浏览器 (~300MB)，必需组件
