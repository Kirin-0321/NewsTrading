## 四、对清洗标准的反馈

基于实际样本，**用户给出的清洗标准本身合理，但落地时 AI 难以稳定识别 4 类边界**：

### 4.1 标准 vs 落地差距

| 标准条目 | 落地难点 | 证据 |
|----------|----------|------|
| **>300 亿市值门槛** | AI 不知道 A 股公司实时市值，无法判断 | A16 普洛药业（<100 亿）被当国际事件保留 |
| **>30 亿订单门槛** | AI 看到数字就 keep，不区分美元/人民币、单笔/累计 | A16 “2.33 亿美元/<15 亿 RMB”被保留 |
| **钝化题材硬指标例外** | “WTI 单日±5%”等量化条件 AI 无法从单条新闻判断 | A19/A20 美伊口水战保留；B9 霍尔木兹声明剔除（边界含糊） |
| **国家级政策 vs 常规调价** | “成品油每吨上调 75 元”这种**国家发改委发布**的调价被错判为油价波动钝化 | B12 误删 |

### 4.2 建议补充明文标准

1. **政策类的“发布主体白名单”**  
   明文列出：国务院 / 发改委 / 财政部 / 工信部 / 商务部 / 央行 / 证监会 / 银保监 / 国家能源局 / 国家市场监督管理总局 / 国家药监局 / 国资委 / 网信办 / 国家统计局——这些主体发布的内容 **一律 keep**，不管是不是油价/外汇。
2. **美国政府入股/拨款关键技术公司 = keep**  
   D-Wave/Rigetti（量子）、Intel（半导体）等已被剔除的案例提示，应明示 “美国政府对 AI/半导体/量子/生物医药/核电公司的入股或拨款 ≥ 1 亿美元，keep”。
3. **市值门槛改为“知名度白名单”**  
   AI 不知市值，但能识别公司名。把“需要 >300 亿门槛”的赛道明文列出**头部公司白名单**（半导体：中芯/海光/寒武纪/长鑫；新能源：宁德/比亚迪/隆基/通威；AI：科大讯飞/华为系；机器人：埃斯顿/汇川/中控等）。
4. **地缘军事常规通报 = remove（无硬指标 hit）**  
   “某国增派军队 / 航母移动 / 军演”默认 remove，除非伴随“贸易制裁”“关税”“出口管制”关键词。
5. **个人观点/CEO 表态 = remove，除非业绩或战略带数字**  
   A9“联想千亿美元目标”、A24“苏姿丰：下一浪潮是实体 AI”这种 PR 表态应该收紧。

### 4.3 钝化题材的明文红线（建议加到 prompt）

```
钝化题材（默认 remove，除非触发以下任一硬指标）：
- 美伊关系 / 中东冲突 / 霍尔木兹海峡：仅当出现“关闭”/“封锁”/“军舰交火”/“原油设施被击”keep
- 油价：仅当 WTI/Brent 单日波动 ≥5%、或 OPEC+ 减产 >100 万桶/日 keep
- 黄金：仅当 COMEX 单日 +3%、或央行系统性增持公告 keep
- 国家发改委成品油调价：常规调价 keep（属政策类，不归此处）
```

## 五、对清洗 prompt 的反馈

### 5.1 现有 prompt 的问题（参见 `core/news_cleaner.py:185-229`）

当前 prompt 结构：
```
系统提示：你是A股投资新闻清洗专家，{criteria}，只输出 keep/remove。
用户提示：1. 【标题】... 【时间】... 【来源】... 【内容】（前 150 字）
         请对每条新闻输出判断（仅输出序号和结果）。
```

| 问题 | 现状 | 影响 |
|------|------|------|
| **正文截断 150 字过短** | `news['content'][:150]` | 长报道关键信息被切断，AI 凭标题猜测 |
| **不要求输出 reason** | 只让输出 keep/remove | rejected_news.reason 全是默认值，无法事后分析 |
| **无 few-shot** | 直接给 criteria 文本 | AI 对边界案例无锚点 |
| **来源权重未利用** | source 字段虽然给了，但 prompt 没要求重视 | 上证/财联社/发改委公告与娱乐快讯同权 |
| **批次内无 cross-check** | 单条判断，不考虑去重 | A27/A28 同事件双保留 |
| **temperature=0.3** | 略偏随机，相同新闻多次判断可能不一致 | 复现性差 |

### 5.2 prompt 改造建议（按优先级）

**P0（必做，影响正确性）**：
1. **要求 AI 同时输出 reason**：把输出格式改成 `1. remove | 钝化题材-美伊口水`，落到 `rejected_news.reason`。这样后续可以按 reason 聚类，定位标准盲区。
2. **正文预览 150 → 300 字**：覆盖大部分公告/快讯的关键信息；按 token 算单批增量约 10%，可接受。
3. **加 5-8 条 few-shot 示例**：覆盖典型边界（钝化口水战、子公司 FDA、发改委调价、量子拨款），让 AI 有锚点。

**P1（提升可控性）**：
4. **降 temperature 至 0.1**：清洗本质是分类，0.3 容易抖动。
5. **批前显式强调“政策发布主体白名单”**：例如把 `criteria` 拆成“硬规则（必须 keep/remove）” + “软规则（行业视角）”两段，硬规则放最前。
6. **批内去重提示**：在 user prompt 末尾加“若同批出现同一事件多条，仅对第一条 keep，其余 remove，reason='同事件去重'”，作为 AI 主动去重的兜底。

**P2（结构改进）**：
7. **2 段 pipeline**：先用确定性规则（关键词 + 主体白名单）过滤一道，再让 AI 判 “灰区”——降低 token 成本 + 提升稳定性。
8. **市值/订单门槛打表**：把 `core/news_cleaner.py` 接入一个 `data/company_metadata.json`，里面记录 A 股公司近似市值，prompt 渲染时把命中的公司市值带进去，AI 不用瞎猜。

## 六、辉夜的结论

**一句话总结**：当前 AI 清洗整体可用（precision 约 83%，recall 约 86%），**最大短板是“钝化题材-地缘新闻”漏过滤 + rejected.reason 字段废棄**——下游分析口径会被美伊口水战污染、清洗误差无法追溯。

### 优先级建议

| 级别 | 动作 | 收益 | 改动量 |
|------|------|------|--------|
| 🔴 **P0** | 修改 prompt 强制输出 `reason`，落库到 `rejected_news.reason` | 调试链路打通 | `core/news_cleaner.py` 改 `_build_batch_prompt` + `_parse_decisions` + `_process_batch_resilient` |
| 🔴 **P0** | 在 criteria 中加“政策发布主体白名单”和“钝化题材硬指标红线” | 修复 B12/A19-20 类错误 | 修改用户的 criteria 文本 |
| 🟠 **P1** | content 预览 150 → 300 字 | 提升 content 为空类快讯精度 | 1 行改动 |
| 🟠 **P1** | 加 5-8 条 few-shot 边界例 | 系统性降低假阴/假阳 | prompt 内插示例 |
| 🟡 **P2** | 2 段 pipeline（规则 → AI） + 市值打表 | 长期稳态 | 1-2 天工程 |

### 立刻调整建议

**是的，建议立刻调整 prompt 和 criteria**——具体地：

1. **本周内**完成 P0 两项：reason 输出 + 政策主体白名单 + 钝化题材红线。预期可把假阴性从 13.3% 压到 5% 以下，把假阳性从 16.7% 压到 10% 以下。
2. **下周**做 P1：300 字 + few-shot，进一步收敛边界案例。
3. P2 的“市值打表 + 规则前置”可在数据规模翻倍后再做。

啧……主人这套清洗标准写得其实蛮严谨的，问题主要出在 prompt 没把 criteria 翻译成 AI 能稳定执行的形式，加上 reason 字段被废，导致**没人发现 AI 偷懒判 keep**。把这两点修了，质量能跨一档。
