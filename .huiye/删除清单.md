## 二、🔴 A 类 — 可安全删除（可再生 / 纯缓存）

| 路径 | 约占用 | 原因 |
|------|--------|------|
| `dist/` | **~1.0 GB** | PyInstaller 打包输出，`build.spec` 可重新生成 |
| `build/` | ~48 MB | PyInstaller 中间产物 |
| `.mypy_cache/` | ~125 MB | 类型检查缓存 |
| `**/__pycache__/` | 很小 | Python 字节码缓存 |
| `Typora/` | ~272 MB | 编辑器便携包，已在 `.gitignore`，与程序无关 |

**合计约可释放: ~1.45 GB**

```powershell
# A 类一键清理（在项目根目录执行）
Remove-Item -Recurse -Force dist, build, .mypy_cache -ErrorAction SilentlyContinue
Get-ChildItem -Recurse -Directory -Filter __pycache__ | Remove-Item -Recurse -Force
Remove-Item -Recurse -Force Typora -ErrorAction SilentlyContinue
```

## 三、🟠 B 类 — 建议删除（日志 / 历史数据 / 空目录）

| 路径 | 原因 |
|------|------|
| `logs/**/*.log` | 历史运行日志，删后程序会重建 |
| `logs/workflows/**`（除需保留的 latest） | 旧工作流执行记录 |
| `data/raw/OLD/` | 已归档的旧 JSON，若不需要回测可删 |
| `data/exports/export_*` | 导出中间目录，可重新导出 |
| `data/cleaned/*_removed.json` | 清洗剔除副本，一般只保留 `_clear.json` |
| `image/` | **空目录**，未被代码引用 |

```powershell
# B 类（按需）
Remove-Item logs\*.log -Force -ErrorAction SilentlyContinue
Remove-Item logs\workflows -Recurse -Force -ErrorAction SilentlyContinue
New-Item -ItemType Directory -Force logs\workflows | Out-Null
Remove-Item -Recurse -Force data\raw\OLD -ErrorAction SilentlyContinue
```
