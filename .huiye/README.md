## 五、文件命名约定

- 形如 `XXX-初步设计.md` = 第一稿设计，可能已被同主题的「功能说明 + 施工方案」取代
- 形如 `_xxx.md`（下划线前缀）= 临时 / 快照 / 调试参考，不参与核心说明
- 形如 `XXX-功能说明.md` = 主人视角，讲清楚最终要什么、按什么使用
- 形如 `XXX-施工方案.md` = 辉夜视角，讲清楚怎么落地、按什么顺序施工
